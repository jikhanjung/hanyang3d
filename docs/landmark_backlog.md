# 건물 추가 목록

18세기 중엽(1750년 무렵)에 있었고 도성 안이거나 지도 가장자리에 걸리는 후보를 차례로 추가한다. 한 번에 하나씩 원도에서 위치를 읽고, 모형·팝업 정보·검사를 갖춘 뒤 배포한다. 추가를 마친 항목은 [건물·시설 안내](landmarks.md)로 옮긴다.

## 조사가 더 필요한 후보

전옥서, 전의감은 위치를 아직 확인하지 못했다. 선혜청·사역원·대보단은 부분도에서 읽어 넣었다.

## 넣지 않는 대상

선희궁(1764), 규장각(1776), 장용영(1793)은 지도 기준 시점보다 뒤에 생겼다.
