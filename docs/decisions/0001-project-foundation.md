# 0001 — 출처 중심의 파일럿부터 시작

- 날짜: 2026-09-08
- 상태: 초기 작업 기준. 파일럿 경계·역사 시점·CRS·배포 라이선스는 후속 결정.
- 근거: 초기 조사 문서의 시간축, provenance, 파일럿 및 재현성 원칙.

기관 전체 자료 수집보다 작은 구역에서 전체 과정을 검증하는 것을 우선합니다. 초기 카탈로그는 CSV 한 벌을 원본으로 관리하고 중복 JSON은 실제 내보내기가 필요할 때 생성합니다. 사료와 파일을 분리하여 파일별 권리를 추적합니다.

GIS 편집본은 향후 GeoPackage로 만들고, 검토·교환에 필요한 작은 GeoJSON을 내보냅니다. 대용량 원본과 생성물은 일반 Git에 넣지 않습니다. 초기부터 데이터베이스 서버나 특정 웹 렌더러에 의존하지 않습니다.

협업 충돌·조회량 증가 시 DB 도입을, 배포 크기 증가 시 LFS/외부 저장소를, 뷰어 요구 확정 시 프런트엔드 기술을 재검토합니다. 이 결정은 구현 완료나 외부 서비스 검증을 뜻하지 않습니다.
