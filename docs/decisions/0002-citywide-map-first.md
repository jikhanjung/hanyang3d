# 0002 — 도성 전체의 지도 개관 우선

- 날짜: 2026-09-09
- 상태: 사용자 요청에 따라 채택
- 관련: [초기 결정](0001-project-foundation.md), [실행 계획](../plan.md), [범위](../scope.md)

사용자는 관인방–경행방 등 세부 도엽 정합보다 한양 도성 전체의 대략적인 모습을 먼저 보고 싶다는 방향을 제시했다. 특히 도성대지도를 사대문 안의 길과 하천 구조를 파악하는 기본 자료로 활용한다.

도성대지도 전체도와 기존 현대 지형·TPS 화면을 중심으로 전체 배치를 검토한다. 사용자가 추가로 제시한 3D 지형 위 지도 오버레이를 첫 시각화 목표로 삼는다. 실제 고도 데이터로 지형을 만들고 원도를 표면에 입혀 기울이거나 회전해 볼 수 있게 한다. 주요 길·하천·성곽 판독은 순차 추가한다. 현재 평면 배경 타일만으로 3D 지형이 구현된 것으로 간주하지 않는다. 건물 복원은 별도 근거를 마련한 후 진행한다. 1908–1912 지적도 연결은 보존할 세부 실험이며 전체 개관의 선행 조건에서 제외한다.

초기 결정 0001의 작은 구역부터 완주하는 우선순위를 이 결정으로 변경한다. 출처·시간·불확실성 추적, 원본과 가공 결과 분리, 재현성 원칙은 계속 적용한다. 대략적 전체 지도를 정밀 측량 결과로 취급하지 않는다. 웹 프레임워크는 사용자 요청에 따라 Django로 구현되어 있다.

2026-09-09 사용자 확인: 기존 Leaflet·OSM 위 5점 배치는 사대문 안에서 비교적 정확했다. 이를 개관용 기준 배치로 채택하여 3D 지형 표시로 이어간다. 이 확인은 사용자의 시각적 평가이며 독립 검사점에 의한 수치 정확도 검증과 구분한다. 도성 밖·산지의 배치 정확도까지 확인된 것으로 확대하지 않는다.
