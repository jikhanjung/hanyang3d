# 작업 방법론

1. **등록:** 사료를 `sources.csv`에 등록하고 제작 시기·대상 시기·기관 설명을 구분합니다.
2. **취득:** 개별 파일은 `assets.csv`에서 권리, 원본 URL, 취득일, 경로, SHA-256으로 추적합니다.
3. **판독:** 사료 노트에 페이지·도엽·이미지 영역, 판독문, 해석, 이견을 기록합니다.
4. **정합:** 원본을 보존하고 기준점·변환 설정·독립 검사 결과를 저장합니다.
5. **벡터화:** 원도 판독 geometry와 보정 geometry를 분리하고 둘의 관계를 기록합니다.
6. **시기 해석:** 자료 제작 시기와 객체 존속 시기를 구분하고 후대 자료를 소급한 논거를 남깁니다.
7. **3D:** 위치·평면·높이·외형 각각의 근거를 연결하고 추정 부분을 표시합니다.
8. **검토·내보내기:** 참조 무결성, 공간·시간 오류, 재현성, 공개 가능한 파일 목록을 확인합니다.

원문 조사본의 A–D 자료 등급은 조사 우선순위의 참고 기준입니다. 발굴도면이나 실측도라는 이유만으로 특정 시점의 위치·높이에 최고 신뢰도를 자동 부여하지 않습니다. 실제 축척, 층위, 정합 오차, 대상 시기 적합성을 객체별로 평가합니다.

신뢰도는 확률이 아니라 작업용 서열입니다. `1.0` 직접 확인, `0.8` 독립 자료 일치, `0.6` 단일 근거, `0.4` 간접 추정, `0.2` 유형 추정, `0.0` 판단 불가를 기본값으로 사용하고 이유를 기록합니다. 미평가 값은 null로 두어 판단 불가와 구분합니다.

파생물마다 입력 파일 checksum, 실행 명령 또는 수작업 절차, 도구 버전, 설정, 작업자, 날짜, 출력 경로를 기록합니다. 자동 추출 결과는 사람의 검토 전까지 확정 데이터로 승격하지 않습니다.
