## 판단 요약

종로는 낮은 전통 상점과 보행자가 이어지는 거리 위에 전차선·전주·일부 서양식 건물이 들어온 모습으로 잡는다. 육조거리는 넓은 비포장 공간 양편에 긴 기와 행랑과 관청 출입구가 이어지고 북쪽 끝에 광화문이 보이는 모습으로 잡는다. 사진의 관찰과 복원 제안을 구분하며, 1900년대 사진을 촬영연도 1907년으로 확정하지 않는다.

현재 사용 중인 1907년 최신경성전도 범례를 직접 확대 판독했다. **가는 붉은 실선은 電氣鐵道(전기철도/전차)**다. 검은 이중 경계는 도로, 붉은 톱니는 성벽, 별도 굵은 교대 기호는 철도선로다. 붉은 행정경계와 전차선은 선종으로 구분해야 한다. 빨간 선을 도로 중심선으로 일괄 해석하면 안 된다. [소장 지도](https://museum.seoul.go.kr/www/relic/RelicView.do?cdLanguage=KOR&mcseqno1=015439&mcseqno2=00000&mcsjgbnc=PS01003026001)

## 종로: 확인 자료와 시각적 구성

[서울역사박물관 상설전시 안내서, 2쪽의 ‘개화의 거리 종로’](https://museum.seoul.go.kr/www/down/pdf/exh/per/renewal_2zone.pdf)에 **보신각 주변 종로와 전차**, **종로대로와 한성전기회사** 사진이 있다. PDF를 열어 사진을 직접 확인했다.

사진에서 확인할 수 있는 것은 넓은 흙·자갈성 노면, 레일, 가공선과 전주, 길가의 낮은 기와 건물, 밝은 옷을 입은 보행자, 그 사이에 두드러지는 양식 회사 건물이다. 정확한 노면 재료·옷 색·건물 치수는 흑백사진만으로 확정하지 않는다. 안내서는 1896년 가을 가건물 철거와 이후 전차·전주·가로등 도입을 설명한다. 따라서 1750년 시전 모델을 1907년 도로 중앙까지 그대로 복제하지 않는다.

[‘서울의 전차’ 전시](https://museum.seoul.go.kr/www/board/NR_boardView.do?bbsCd=1002&seq=20191212214706826&sso=ok)는 대한제국기 종로 전차 사진, 1902년 이후 한성전기회사 사옥, 보스트위크 사진첩의 소재와 소장처(한국전력공사 전기박물관)를 알려준다. 개별 차량의 측면·집전장치 검토에는 이 사진군을 우선한다. 정확한 사진 번호·촬영연도와 재이용 조건은 개별 유물 단계에서 추가 확인한다.

재현 제안:

- 상점은 낮고 연속적인 처마선, 크기가 조금씩 다른 출입구와 열린 판매면을 기본으로 한다. 개별 상호는 신문 광고·사진 판독으로 확인된 것만 넣는다.
- 전차·전주·가공선이 1750년 장면과 가장 뚜렷한 차이가 되게 한다.
- 사람은 전통 복식 위주로 구성하되 사진에서 확인되는 차림의 다양성을 반영한다. 성별·직업별 비율을 사진 한 장으로 통계화하지 않는다.
- 한성전기회사 사옥은 별도 랜드마크 후보로 잡는다. 현존 후대 전력회사 건물을 대신 복제하지 않는다.
- YMCA 기관과 유명한 완성 회관을 구분한다. 종로 회관은 1907년 착공, 1908년 12월 3일 개관이므로 **1907년 완공 건물로 넣지 않는다**. [한국학중앙연구원](https://encykorea.aks.ac.kr/Article/E0065210)

## 육조거리: 건물은 이어지지만 관청 이름은 바뀐다

[서울시 ‘사람과 사람을 잇는 도시’](https://love.seoul.go.kr/articles/7895)의 1900년대 초 광화문 사진을 직접 확인했다. 넓고 포장되지 않은 전경, 양편의 낮은 긴 기와 건물, 보행자와 말, 북쪽 광화문이 보인다. 사진은 뷘슈 관련 자료로 소개되며 1907년 특정 날짜의 모습은 아니다. 사진만으로 관청의 개별 명칭을 확정하지 않는다.

배치의 핵심 자료는 국가기록원 **광화문외제관아실측평면도**다. [도면 해설](https://theme.archives.go.kr/next/place/observatory.do?flag=02)은 제작 시기를 **1907~1909년**으로 추정하고 축척 1:600, 정북 기준, 필지·건물·광화문 월대·개천 표시를 설명한다. 기관 배치는 다음과 같다(북→남).

| 서쪽 | 동쪽 |
|---|---|
| 근위대대 | 내부 |
| 경시청 | 법무원 |
| 군부 | 학부 |
| 법부 | 탁지부 |
| 통신관리국 | 법관양성소 |

표는 나란한 같은 위도를 뜻하지 않고 각 측의 나열 순서다. 경시청 개칭은 1907년 7월 27일, 근위보병대 편제는 같은 해 8월 26일이다. 그러므로 도면 기관명을 1907년 초에 소급하지 않는다. 건물 외형의 존속기간과 기관 입주기간을 별도로 기록해야 한다.

같은 해설은 육조거리를 남북으로 관통하는 **광화문선이 1917년 공사용으로 개설되고 1918년 여객 운행**을 시작했다고 설명한다. **1907년 육조거리에는 이 전차선을 배치하지 않는다.** 1917~1922년 도면은 후대 변화 비교용이다.

의정부 발굴에서는 정본당·협선당·석획당과 행랑·연지 등의 유구가 확인되었고 근대 도면과 배치가 비교되었다. 육조거리 관청은 큰 상자 하나보다 마당·문·행랑·주요 전각의 조합이 적합하다. [서울역사박물관 발굴 해설](https://museum.seoul.go.kr/www/board/NR_boardView.do?bbsCd=1159&seq=20201229152257165&sso=ok&tr_code=sweb)

사용자가 앞서 알려준 [오픈랩 육조거리 자료](https://openlab.eseoul.go.kr/gallery/viewStoryMapContent.do?scid=NJDK-f3GQKD_3BA4XkZM5g)는 보조 비교 대상으로 유지한다. 이번 조사에서 동적 본문을 충분히 읽지는 못했으므로 복원 그림의 기준연대를 새로 확인했다고 주장하지 않는다. 1750년 배치와 1907년 도면을 혼합하지 않는다. 도면의 ‘실측’ 역시 현대 좌표계 정확도를 자동 보증하지 않으며 독립 검사점을 둔다.

## 주변 건물 재현을 위한 우선 조사 — 사용자 범위 정정

사용자가 말한 종로·육조거리의 ‘모습’은 **길 양옆 건물의 외형과 배치**다. 건물 조사를 주 과제로, 전차는 별도 요청된 병행 계획으로 둔다.

| 구역·유형 | 확인한 외형 / 재현 방향 | 확정하지 않은 부분 |
|---|---|---|
| 종로 일반 점포 전면 | 사진에 낮은 기와 건물이 이어진다. 연속 처마 아래 점포 칸·기둥·문을 나누는 상가형 모델을 우선 | 점포별 실제 폭·층수 분포·상호·상품·색 |
| 종로 상점 뒤편 | 전면 상가와 뒤편 필지를 분리해 좁은 골목·마당으로 이어지는 건물군을 검토 | 개별 필지의 정확한 안채 배치는 도면 추가 판독 필요 |
| 종로 양식 건물 | 박물관 사진의 한성전기회사 사옥은 주변 한옥보다 높은 2층 본체, 반복되는 창, 지붕 위 탑 부분으로 식별된다. 일반 점포와 다른 별도 모델 후보 | 상세 치수·재료·1907년 간판은 추가 고증 |
| 육조거리 대로변 | 사진에서 낮고 긴 기와 행랑의 처마선이 거리 양편을 형성한다. 담장만 두르기보다 칸이 이어지는 행랑 건물로 표현 | 모든 구간의 칸수·문 위치·보수 상태는 미확정 |
| 육조거리 출입구·내부 | 행랑 사이 대문과 그 뒤 마당·주요 전각을 도면에 따라 배치하는 관청 단위 모델 | 평면도로 알 수 없는 입면·지붕 세부는 사진·발굴 자료로 보완 |

위 표의 사진 관찰은 앞뒤 절에 연결한 서울역사박물관 안내서와 뷘슈 사진에 근거한다. 작은 이미지에서 개별 점포를 확정 복원할 수는 없다. ‘종로 전체가 동일한 단층 한옥’ 또는 ‘1907년이면 모두 일본식 2층 상점’으로 일괄 생성하지 않는다.

[서울역사아카이브 광화문통 컬렉션](https://museum.seoul.go.kr/archive/archiveNew/NR_archiveList.do?ctgryId=CTGRY809&type=D)은 도로 양편 관아 행랑을 볼 수 있는 사진 10건을 모아 놓았다. 다만 1913년·공진회 등 후대 자료도 포함되므로 개별 사진의 날짜를 걸러야 한다. [육조거리 발굴 현장 소개](https://mediahub.seoul.go.kr/archives/2001722)에는 삼군부 외행랑 기초, 사헌부로 추정되는 문지·행랑·담장이 설명되어 있어 건물 경계 유형을 대조할 수 있다. 발굴 층위가 다르므로 모두 1907년 유구로 간주하지 않는다.

상점 외형을 더 구체적으로 다룬 자료도 찾았다. 이유정, 「시전에서 상점으로—광고를 통해 본 근대 초기 상점의 변화 양상(1890–1910)」, 『한국문화연구』39(2020), 93–130쪽([원문 PDF](https://kcri.ewha.ac.kr/kcri/board/study-of-korean-culture.do?articleNo=703758&attachNo=467942&mode=download))의 97–98쪽은 작은 칸으로 나뉜 낮은 상점과 일부 2층 건물을 다루고, 운종가·남대문로에서 조적 벽 또는 회반죽 전면을 가진 상가가 등장했다고 설명한다. 115–116쪽은 상점 간판·진열광고의 변화를 다룬다. 1888년 여행기의 관찰과 1890–1910년 연구 범위를 1907년 개별 점포 실측으로 바꾸어 해석하지 않는다.

따라서 종로에는 **전통 기와 점포형 / 기와지붕에 조적·회벽 전면을 더한 절충형 / 자료로 확인되는 2층 상가·양식 랜드마크형**을 구분하는 것이 적절하다. 모든 가게를 궁궐식 단청 건물로 만들거나, 모두 초가·노점으로 채우지 않는다. 각 유형의 비율·실제 위치는 추가 사진 판독 후 결정한다.

건물 제작 순서는 **① 종로 대표 점포 전면 유형 ② 육조거리 양측 행랑·대문 ③ 관청 내부 마당·전각 ④ 사진으로 확인되는 양식 랜드마크**로 잡는다. 개별 상점 고증이 부족한 구간은 ‘거리 경관 추정 모형’으로 기록하고, 특정 상점의 이름을 임의 부여하지 않는다. 1750년 모델은 부품만 재사용하며 배치·기관명·건축 연대는 1907년 자료로 다시 결정한다.

## 전차 배치·운행 구현 계획

### 1. 선로 판독과 데이터

우선 원도의 붉은 전차선을 확대 추적하고 기존 `roads`와 별도의 노선 그래프를 만든다. 도로 폭은 검은 경계, 레일 위치는 붉은 선을 기준으로 재검토한다. 현재 도로 중심선을 그대로 전차선으로 복사하지 않는다.

| 단계 | 공간적 구간 | 구현 판단 |
|---|---|---|
| 1 | 돈의문–종로–흥인지문 | 지도상 동서 전차선부터 연속 추적. 첫 운행 구간 |
| 2 | 종로 분기–광통교 부근–숭례문–지도 남쪽 용산 방향 | 분기와 청계천 횡단 위치를 확대 확인한 뒤 연결 |
| 3 | 서대문 밖과 남대문 밖 연결, 흥인지문 동쪽 지도 끝 | 지도 안에서 확인된 경로만 확장. 화면 경계는 실제 종점으로 표시하지 않음 |
| 제외 | 육조거리에서 광화문으로 북상 | 1907년 미개통인 광화문선은 제외 |

한국학중앙연구원 [전차 항목](https://encykorea.aks.ac.kr/Article/E0049706)은 1899년 개통, 같은 해 종로–남대문, 1900년 구용산 연장을 설명한다. 위 표는 운행 계통이나 정류장 목록의 확정이 아니라 지도 판독·제작 순서다. 전체 지도가 한 시점의 운행 상태를 완벽히 담는다고 가정하지 않는다.

노선별 `source_position.pixel`, 원도 해시, 근거 URL, `observed_year`, 개통·폐지일(미확정은 null), 판독 확실성, 교량·성문 통과점, 단선/복선 확인 상태를 기록한다. 실제 연결 노드와 단순 입체/평면 교차를 구분한다. 정류장과 교행장은 근거를 확인한 뒤 추가하고, 보기 좋은 위치를 역사적 정류장으로 명명하지 않는다.

### 2. 차량과 기반시설

대한제국기 사진을 기준으로 짧은 차체, 지붕, 창/개방부, 양끝 승강부, 차륜과 집전봉을 단순화한다. 개통 당시 개방형 차량 기록을 1907년 모든 차량의 단일 형식으로 일반화하지 않는다. 후대 대형 전차·광고·현대 팬터그래프를 그대로 사용하지 않는다. 차체 치수, 궤간, 차륜 간격, 색상, 1907년 보유 차량 형식은 추가 확인 항목이다.

전주와 가공선은 사진을 참고한 별도 레이어로 만든다. 초기에는 종로 구간에 차량 1대로 운행을 확인한다. 이 숫자는 당시 운행 대수 복원이 아닌 화면 구현 설정이다. 왕복은 양방향 차량의 진행 방향 전환으로 처리하며, 차량을 제자리 180도 회전시키지 않는다. 집전봉 방향도 진행방향에 맞춘다.

선로가 하나인 구간에 양방향 차량을 겹쳐 달리게 하지 않는다. 차량 추가 시 구간 점유와 분기 우선권을 적용하고, 교행선 위치가 확인되기 전에는 임의의 역사적 교행장을 만들지 않는다. 정차시간·속도는 시각화 설정이라고 명시한다.

### 3. 현재 렌더러와 연결

- `seoul1907.js`의 동일한 국부 정합 `project()`와 지형 `groundAt()`을 선로·차량·전주에 공유한다. 지도 투명도와 무관하게 위치를 유지한다.
- 도로를 자르는 기존 지형 삼각형 방식을 레일 바닥에도 적용하되 레일 두 줄을 실제 공간 간격으로 만든다. 지도 기호 한 줄이 레일 한 줄을 뜻하지 않는다.
- 차량 앞뒤 지지점으로 높이·pitch를 계산한다. 큰 굴곡과 급경사에서는 DEM을 바로 선로 종단으로 간주하지 않고 경사·교량 접속을 검토한다.
- 성문 홍예, 광통교 부근 횡단, 보신각 사거리 분기를 우선 검사한다. 현 모델 통과 폭·높이가 부족하면 차량 크기를 억지로 줄이지 말고 근거와 모델 배치를 재검토한다.
- 근거리에는 차륜·승강부·집전봉, 중거리에는 단순 차체, 원거리에는 작은 실루엣만 남긴다. 전주 반복 부품은 인스턴싱하고 가공선은 멀리서 생략한다.
- 기존 1907년 설정 형식에 ‘전차’ 표시 옵션을 넣는다. 기본 켬을 제안한다. 숨긴 레이어의 애니메이션은 멈추고 브라우저가 비활성 상태였다 돌아오면 시간차를 제한한다.
- 연대 필터에서 기관·건물·선로·차량 형식의 기간을 각각 판정한다. 1750년 장면에는 전차가 나타나지 않아야 한다.

### 4. 완료 판정

원도 선과 선로 중첩, 그래프 끊김·잘못된 분기 없음, 성문·교량 접촉/관통 없음, 양방향 충돌 없음, 지도 투명도 0/50/100%에서 위치 동일, 저사양 모바일 LoD·프레임 검사, 연대별 출현 검사를 완료한다. 당시 사진의 정확한 색·시간표까지 복원한 것으로 표기하지 않는다.
