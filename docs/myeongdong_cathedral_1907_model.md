# 1907년 명동성당 근거리·내부 모형

## 근거와 표현 범위

명동성당 본체는 1898년 완공되었으며, 삼랑식 라틴 십자 평면·벽돌 고딕 구조를 바탕으로 만든다. [한국민족문화대백과사전 「서울 명동성당」](https://encykorea.aks.ac.kr/Article/E0018240)은 첨두아치 창, 이형 벽돌 열주, 부축벽, 종탑 양옆의 팔각 계단탑을 설명한다. 이 설명을 요약해 직접 제작한 코드 모형이다. 사진·스캔·유료 모델의 메시나 텍스처를 가져오지 않았다.

사용자 제공 [AZTechnology, 「GPT 6 x 블렌더 3D = 이제는 바이브 모델링 시대」](https://www.youtube.com/watch?v=_S4SaiNBlRk)(2026-09-12, 14분 56초)는 명동성당의 역사 자료가 아닌 가우디 성당 모델링 영상이다. 전체 구간의 표본 프레임과 9분 지점 내부 렌더를 확인했다. 내부에서 열주·천장 연결·색유리·좌석 열을 볼 수 있는 상세 표현과 절차적 모델링 방식을 참고했다. 영상 속 가우디 건축의 분기 기둥·다수 첨탑을 명동성당에 옮기지 않았다. 영상과 프레임은 `/tmp`에서 참고했으며 Git·서비스 배포 자료에 포함하지 않는다.

확정한 것은 건물의 존재 연대와 건축 유형이다. 내부 기둥 간격·개수, 궁륭과 리브의 형상, 색유리의 색·기하 문양, 의자·제단 배치와 바닥 타일 문양은 추정이다. 1907년 실측 복원이 아니며, 현대 제단·성화·전례 시설의 구체적인 도상을 복제하지 않았다. 기존 지도상의 위치·방위와 30×45×65m 추정 배치 영역은 유지했다. 원문에서 제시하는 건물 치수와 완전히 일치하는 실측 모델을 뜻하지 않는다.

## 구현

- `webapp/static/cathedral1907.js`: 속이 빈 본당·측랑·익랑, 정문 개구부, 종탑·팔각 계단탑, 부축벽, 창틀·기하 색유리, 복합 기둥, 첨두아치·궁륭·리브, 의자·제단.
- 벽돌 줄눈은 셰이더로 생성하고 화면에서 작아지면 부드럽게 생략한다. 외부 이미지 텍스처가 없다.
- 원거리에는 기존 경량 실루엣, 중거리에는 건축 외피, 약 260m 이내에는 내부 가구·리브·창살·색유리 세부를 표시한다. 경계에서 깜빡이지 않도록 기존 LOD와 같은 여유 구간을 둔다.
- 지면 → 접근 계단 → 정문 → 중앙 통로 → 제단 앞을 실제로 걸을 수 있다. 측랑과 익랑도 둘러볼 수 있으며 벽·기둥·의자·제단은 통과할 수 없다. 지하 묘역·상층 계단실은 이번 탐색 범위에 포함하지 않는다.
- 1인칭 보행의 뒤쪽 카메라가 성당 벽을 넘어가지 않도록 건축 외피와 카메라 선분을 검사한다. 다른 건물과 1750년은 기본값으로 기존 동작을 유지한다.
- 건물 설명의 **성당 내부 보기** 버튼으로 내부를 바로 볼 수도 있다. 건물 자체를 클릭할 때의 기존 시점 유지 동작은 그대로다.
- 건물 설명·출처 페이지에 추정 범위와 참고 문헌을 함께 표시한다.

## 확인
