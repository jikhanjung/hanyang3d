# 길 주변 주택·상가 추정 배치

2026-09-11. 도성대지도 3D 화면에 작은 주택·상가를 추가했다. 역사적 개별 건물 위치를 복원한 결과가 아니라 도시 규모와 길 주변 생활공간을 보기 위한 가정 배치다.

## 규모 추정

[한국민족문화대백과사전 「한성부」](https://encykorea.aks.ac.kr/Article/E0061730)는 1780년경 한성부의 38,742호·201,070명을 제시한다. 이 범위에는 도성 밖 십리 지역도 들어가며, 원도의 1750년 전후와 시기 차이가 있다. ‘호’는 등록 가구이지 건물 동수가 아니므로 일대일로 바꾸지 않는다.

동수 자료를 직접 확인하지 못한 상태에서 공유 주거·부속채를 고려하는 **등록 호당 0.8~1.5동이라는 시각화 가정**을 둔다. 이를 둥글게 잡은 **민간 건물 약 3만~6만 동**은 한성부 전체의 규모 감각을 위한 범위이며, 실측 통계나 역사학적 신뢰구간이 아니다. 누락 인구·가구, 동별 시설 구성, 주거·영업 겸용, 시대별 변화를 정량 보정한 추정도 아니다.

현재 모델은 성 안에서 추출된 길 주변 일부만 그린다. 실제 모델 한 동을 여러 동으로 환산하지 않으며 한성부 전체 가정 수량을 모두 성 안에 몰아넣지 않는다. ‘성김/보통/촘촘함’은 표시 밀도 비교로, 역사적 인구의 세 시나리오가 아니다.

028 시점 기본 브라우저 확인값은 14,431동이었다. 037의 길가 집중 배치에서는 4,202개가 브라우저 배치 조건을 통과하고, 기본 밀도·경사 필터 적용 후 2,540동(주택 2,375동·상가 165동)을 표시한다. 표면 보정·배치 모드에 따라 최종 표시 수가 달라질 수 있다.

## 배치

`build_settlement.py`는 원도 길 가장자리의 좁은 띠에서 48,429개 후보를 만든다. 원도 후보 간격은 3 px이고, 가까운 길 픽셀 좌표를 함께 보존한다. 난수 시드 1750을 고정하고 원도·길 마스크 SHA-256을 보존한다. 성벽 안쪽만 허용하며 성벽·문·판독된 하천과 궁궐·제례 공간 제외 영역을 비운다. 제외 다각형은 원도를 참고한 보수적인 영역이며 확정 필지선이 아니다.

브라우저는 같은 TPS와 원도 표면으로 후보를 배치한다. 변형 후 실제 거리로 다시 걸러 지붕 앞쪽에서 길 가장자리까지 2~9 m 범위에 모은다. 지붕 능선은 길과 나란히 놓고, 출입구·차양은 가까운 길을 향한다. 주요 시설, 건물끼리의 여유거리, 하천의 절삭 어깨, 현대 고도 140 m 초과와 국부 경사 후보를 추가 제외한다. 원도의 종로에 해당하는 띠에서는 상가 후보 확률을 높인다. 상가 비중·초가색/기와색 비중은 역사 자료로 계산한 비율이 아니다.

주택은 폭 4.5~7.5 m·깊이 4~6 m, 상가는 폭 5~8 m·깊이 4~6 m다. 벽 높이 2.6~3.5 m에 지붕 높이 1.5 m를 더한다. 대표적인 작은 단층 건물의 개념 치수이며 한옥 실측 복원이 아니다. 작은 차양으로 상가를 구분한다. 일반 주택은 초가집 위주로, 일부 주택과 상가는 기와집으로 표현한다. 초가는 두꺼운 모서리와 둥근 사면지붕, 기와는 곡선 처마와 기와 줄을 가진 맞배지붕이다. 흙벽색 벽면에 어두운 기둥·보·창살을 더했다. 지붕 형태·비율 역시 표현을 위한 가정이다.

최종 지형·원도 삼각형에서 회전한 지붕 포함 바닥 범위를 계산한다. DEM과 원도 사이의 4 m 표시 차이를 기단 높이로 사용하지 않고, 각 표면의 최저값 중 높은 값과 전체 최고값으로 보이는 상부 지면의 범위를 잡는다. 작은 건물 바닥은 그 최저 기준 +8 cm에 둔다. 기단은 18 cm 두께로 얇게 만들고 일부를 땅에 묻는다. 오르막 부분은 벽 하단이 지면에 조금 묻히도록 하여 높은 받침을 만들지 않는다.

표시 배율을 반영한 바닥 범위의 고도 차가 1.2 m를 넘으면 해당 건물은 숨긴다. 높이 강조에 따라 일부 건물이 추가로 숨겨질 수 있다. 원도 불투명도 0%에서는 실제 보이는 DEM만 기준으로 삼아 건물이 허공에 남지 않도록 낮춘다. 하도 보정·원도 표시·높이 강조를 바꿀 때 다시 적용한다.

반복 모형은 다섯 개의 InstancedMesh(벽·기와지붕·초가지붕·받침·차양/출입구)로 묶어 그린다. 기존 주요 시설의 선택 기능과 추정 일반 건물의 표시 전환은 별개다. 추정 일반 건물에는 실재 상호나 가구 이름을 부여하지 않았다.

## 재현

```bash
.venv/bin/python scripts/buildings/build_settlement.py
.venv/bin/python manage.py test webapp
.venv/bin/python scripts/terrain/check_settlement_browser.py
```

브라우저 검사에는 표시 수량, 작은 크기, 하천 이격, 표시 밀도·전환, 높이 2배와 하도 보정 변경 시 실제 지형 접지가 포함된다.
