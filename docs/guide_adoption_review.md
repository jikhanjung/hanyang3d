# 공통 가이드 적용 검토 — 2026-09-12

한양3D 저장소의 현재 코드와 배포 파일을 기준으로 검토했다. 공통 원문은 로컬 `.guides`에서 참조하며 이 문서는 한양3D 자체의 현황과 후속 작업만 기록한다. 웹·운영·데이터 안전·브랜드 항목을 읽었으며 데스크탑 설치·패키징 규칙은 대상이 아니다.

## 연결과 적용 범위

- `.guides -> ../devdocs/guides` 상대 링크를 만들고 Git·Docker 빌드 대상에서 제외했다.
- `CLAUDE.md`와 `AGENTS.md`에 가이드 발견 경로 및 링크 부재 시 원인을 기록했다.
- 공통 인덱스의 비공개·심볼릭 링크 안내를 따른다. 웹 README의 복사 안내는 인덱스 및 같은 문서의 참조 안내와 충돌하므로 적용하지 않았다.
- 가이드 전체 준수 상태를 선언하는 것은 아니다. 아래 미완료 항목은 후속 구현 대상으로 남긴다.

## 우선순위가 높은 후속 작업

1. **운영 `.env` 보존.** `deploy/host/deploy.sh`는 새 파일에 IMAGE_TAG, DATA_VERSION, HOST_PORT 세 항목만 쓰고 기존 `.env`를 교체한다. 비밀값 파일 `.env.django`는 보존하지만, `.env`에 추가한 값은 사라지고 저장된 HOST_PORT도 기본 8013으로 돌아갈 수 있다. 기존 설정을 보존하며 릴리스 키만 갱신하도록 바꾸고, 임의 키·사용자 지정 포트 보존과 실패 시 복귀를 검증하는 것이 우선이다.
2. **공통 배포 명령 완성.** manifest에는 build/deploy/rollback만 있다. preflight, smoke, seed를 명시하고 seed는 현재 불필요함을 선언한다. preflight는 버전 일치, 위험한 배포 파일 변경, 런타임 자료 검사와 마지막 배포 이후 변경 요약을 제공해야 한다.
3. **원격 배포를 한 파일로 재현.** 호스트 정보는 이미 manifest에 있으나 실제 절차는 SSH·SCP 명령 조합이다. 명시적 대상이 있는 remote-prod 래퍼에서 호스트 확인, 이미지 pull, 묶음 검증·설치, health/version 확인까지 묶는다. 스크립트 갱신은 임시 경로에서 문법 검사 후 원자적으로 교체하고 이전본을 보관한다.
4. **버전 동기화와 배포 기록.** DOCKER_VERSION, Dockerfile 기본 ARG, manifest, 문서에 버전이 반복된다. 단일 bump 명령과 불일치 검사를 추가한다. devlog와 별도로 마지막 배포 커밋/태그를 기계가 읽을 수 있게 남겨 preflight 기준으로 사용한다. 기존 공개 이미지 태그는 덮어쓰지 않는다.

## 추가 검토 항목

| 항목 | 판단 및 다음 단계 |
|---|---|
| DB 백업·마이그레이션·세션 제거 | 현재 DB·로그인·사용자 입력 저장이 없어 해당 없음. 기능이 추가되면 재검토한다. |
| 자료·운영 설정 복구 | 버전별 데이터 묶음은 검증하지만 원본 자료·운영 비밀 설정의 별도 백업 위치와 복구 절차는 이 검토에서 확인하지 않았다. 원본과 파생물, 운영 설정을 구분한 복구 목록이 필요하다. |
| 디스크 사용량·자동 장애 알림 | 이 프로젝트 저장소에는 정기 감시와 실패 알림 연결이 없다. 서버 공용 감시가 있는지는 별도 확인 후 기존 채널과 통합한다. 알림 채널을 임의로 만들거나 메시지를 보내지는 않았다. |
| HTTPS 보안 설정 | 프록시 신뢰는 환경변수로 설정 가능하다. HSTS 등은 Django 설정에 없다. `check --deploy` 결과와 서버 TLS 정책을 확인해 단계적으로 적용한다. |
| 정적 자료 Nginx 직접 제공 | 현재 허용 목록에 있는 JS·자료를 Django가 제공한다. 경로 제한을 유지하면서 직접 제공할 수 있는지 성능 측정 후 판단한다. 원본 데이터 디렉터리 전체를 공개해서는 안 된다. |
| 제품 정보·브랜드·라이선스 | 한양3D는 역사 지도 서비스이며 기존 연구·스포츠 브랜드 중 하나로 자동 분류할 근거가 없다. 게시자·소프트웨어 라이선스를 임의로 정하지 않는다. 현재 화면의 간결한 제목과 모바일 © 요청은 유지하고 제품 정보는 별도 페이지에서 보완할 수 있다. |
| 웹 메타데이터·접근성 | 지도 HTML의 lang, 설명·공유 메타데이터와 아이콘 구성을 정비할 여지가 있다. 공통 바닥글을 강제로 추가하면 지도 캔버스 중심 UI 요청과 충돌한다. |

이번에는 가이드 연결, 발견 안내와 적용 검토 문서를 추가했다. 위 배포 도구·보안·브랜드 변경은 구현하지 않았으며, 기존 v0.0.15 지도 릴리스와 별개의 후속 작업이다.
