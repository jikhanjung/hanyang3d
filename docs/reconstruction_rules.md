# 3D 복원 규칙

| 수준 | 대상 | 필요한 기록 |
|---|---|---|
| L1 대표 건축물 | 궁궐·관아·성문·교량 등 | 개별 위치·평면·높이·외형의 근거와 미상 부분 |
| L2 근거 기반 유형 모델 | 위치·평면이 확인된 일반 건축 | 확인 geometry와 추정 외형의 구분 |
| L3 절차적 채움 | 근거가 부족한 민가·부속건물 | 생성 규칙·입력·난수 seed와 추정 표시 |

첫 파일럿은 L1 한 건과 주변의 단순 매스부터 만듭니다. 수준은 정밀도나 확실성 점수가 아니며 L1에도 외형 추정이 있을 수 있습니다.

모델마다 manifest에 `model_id`, `feature_id`, `level`, `source_ids`, `asset_ids`, `valid_from`, `valid_to`, `temporal_status`, `units`, `axis_convention`, `origin`, `crs`, `tool_version`, `parameters`, `output_path`, `license_status`를 기록합니다. 근거 위치는 GIS evidence 테이블과 연결합니다.

작업 단위는 미터로 통일하는 방향으로 설계하며, 로컬 모델 원점과 GIS 원점 간 변환을 기록합니다. 내보내기 포맷의 축과 단위 변환을 명시하고 GIS footprint와 정렬을 확인합니다.

위치·평면·높이·외형의 신뢰도는 각각 유지합니다. 확정 부분과 추정 부분은 메타데이터 및 화면 범례로 구분합니다. 현대 DEM을 사용한 결과에는 현대 지형임을 표시하며 역사 지형으로 확정하지 않습니다.

생성 모델은 `models/generated/`에 두고, 생성 코드·매개변수는 Git에 보관합니다. 배포 파일은 입력 자료의 파생물 조건을 확인한 뒤 별도로 선정합니다.
