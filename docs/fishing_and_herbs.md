# 낚시·약초 채집

1750·1907년은 봇짐·상점과 조작을 공유한다. 배치한 인물, 약초, 어획물은 창작 게임 요소이며, 실제 청계천 어종·약용식물의 식별 자료가 아니다.

## 찾아가기와 조작

- 광통교 옆 청계천 물가: 삿갓을 쓴 낚시꾼 1명. 강태공 고사·낚시법·어물전 이야기를 듣고 낚싯대를 살 수 있다.
- 낚싯대 15문, 최대 1개. 청계천 어느 곳이든 물가에서 수면을 보고 사용한다. 시선 방향 3~14m 안에 실제 물이 있어야 한다. PC 봇짐 우클릭 또는 액션바에 끌어놓은 뒤 1~0키·좌클릭·우클릭, 모바일 봇짐의 쓰기 버튼을 사용한다.
- 액션바의 Shift+우클릭은 해당 칸의 연결만 비운다. 물품 자체는 봇짐에 남는다.
- 낚시꾼은 실제 수면 가장자리의 마른 땅에 배치하며 낚싯대 길이는 최대 2.4m다. 플레이어는 몸 방향과 별개로 현재 카메라가 바라보는 수평 방향의 물에 던진다. 던진 뒤 시선을 돌려도 찌는 그 자리에 남는다.
- 한 번에 10초, 어획 확률 30%. 남은 초와 진행 막대를 표시한다. 자동으로 결과를 받고 다시 사용해야 다음 낚시를 시작한다. 이동·점프·승마·1인칭 종료·재사용은 취소한다. 대기 중 낚싯대·낚싯줄·찌와 팔 자세를 표시한다.
- 민물고기는 내어물전을 포함한 기존 상인의 상점에서 내 봇짐 칸을 눌러 판다. 기본 환매율 60%에서 종류별 판매 가격은 아래와 같다. 내어물전의 기존 말린 명태·조기 상품은 유지한다.
- 북악산·인왕산·남산의 수목 자료에서 드문 후보 63곳을 고정 선택했다. 두 시대 현재 지형에서 고도 100m 이상인 39곳에 보인다. 바닥에 펼쳐진 녹색 잎으로 단순화했다.
- 1인칭으로 5m 안에 다가가 약초에 커서를 올리면 `grab`, 누르는 동안 `grabbing`. 우클릭하면 성공률 80%로 산약초 한 묶음을 얻는다. 성공·실패 모두 해당 자리에서 5분 뒤 다시 시도한다. 계정별 재채집 대기는 새로고침·시대 변경 후에도 유지한다.
- 종루/보신각 부근의 ‘약전 藥廛’ 표지 약재상에서 산약초를 판다. 종류별로 한 묶음 3~8문이다. 위치·상호·인물은 추정 창작이며 실제 점포 복원 주장이 아니다.

## 종류와 게임 가격

| 약초 | 표현 | 기준 가격 | 상인에게 판매 |
| --- | --- | ---: | ---: |
| 쑥잎(애엽) | 회녹색의 키 큰 잎 | 6문 | 3문 |
| 질경이(차전초) | 낮고 넓은 잎·갈색 이삭 | 8문 | 4문 |
| 민들레(포공영) | 낮은 잎·노란 꽃 | 10문 | 6문 |
| 도라지뿌리(길경) | 가는 줄기·보라 꽃 | 14문 | 8문 |

| 물고기 | 어획 성공 시 비중 | 기준 가격 | 상인에게 판매 |
| --- | ---: | ---: | ---: |
| 피라미 | 40% | 6문 | 3문 |
| 미꾸라지 | 25% | 10문 | 6문 |
| 붕어 | 25% | 16문 | 9문 |
| 잉어 | 10% | 24문 | 14문 |

30% 어획 성공 판정 뒤에 별도로 종류를 추첨한다. 판매가는 `floor(기준 가격 × 0.6)`이며 역사적 시세가 아니다. 기존 봇짐의 ‘산약초’와 ‘민물고기’는 그대로 보존·판매 가능하다. 새 채집물은 각각 별도 아이템으로 쌓인다.

약초 종류는 노드 ID별로 고정돼 두 시대를 오가도 바뀌지 않는다. 채집을 시도하면 잎·줄기·꽃이 함께 사라지고 5분 뒤 재생한다. 성공률은 80%이며 실패해도 해당 포기를 소모한다. 재생 시간은 기존처럼 **계정별**로 기록하며 다른 접속자의 채집까지 공유하는 구조는 아니다.

## 자료와 표현 범위

- [국립생물자원관 — 해제로 보는 조선시대 생물자원 2](https://www.nibr.go.kr/aiibook/catImage/93/Joseon%202.pdf): 동의보감 해제의 길경·애엽·차전초·포공영 목록(인쇄 쪽 27–30, PDF 43–46쪽), 구급이해방의 도라지/길경 대응(인쇄 21쪽), 주촌신방 해제의 미꾸라지·붕어·잉어(인쇄 61–62쪽), 신증동국여지승람 경도 해제의 붕어·피라미·잉어(인쇄 165–166쪽)를 확인했다. 본초강목 원문 전체를 대조한 결과로 표현하지 않는다. 종별 1750/1907년 청계천 서식과 산지 분포·개화 시기를 복원한 것은 아니며 효능·복용법은 구현하지 않는다.


- [국사편찬위원회 — 무성왕 강태공](https://contents.history.go.kr/front/km/print.do?levelId=km_007_0060_0010_0030_0010&whereStr=): 강상, 위수 가에서 문왕과의 만남, 문왕·무왕을 도운 인물이라는 설명을 바탕으로 대화를 구성했다. 청계천의 실제 사건으로 옮기지 않았다.
- [한국민족문화대백과 — 어물전](https://encykorea.aks.ac.kr/Article/E0035969): 어물전과 생선전·해전의 구분을 설명한다. 게임에서는 민물고기를 기존 상점에 팔도록 편의를 제공한다.
- [국사편찬위원회 국사관논총 — 조선 후기 약전·약국](https://db.history.go.kr/id/kn_107_0040_0020_0020): 약품·약재 판매의 민영화와 약전·약국 증가를 참고했다. 구체적인 종로 점포 주소나 약초 효능은 주장하지 않는다.
- 1907년 화강암·수목은 1750년 원도의 식생 개념 자료를 **동일한 TPS·산지 보정과 지리 좌표**를 거쳐 옮겼다. 1907년 지도 픽셀에 직접 대입하지 않았다. 건물·도로변 민가·물길·담장 주변은 해당 시대 배치를 기준으로 걸러낸다. 원도와 FABDEM의 시대 차이, 수목 수량·암반 경계의 추정 한계는 그대로다.

## 서버와 운영 반영

- `FishingCast`: 계정당 진행 상태 하나. 서버가 시간과 확률을 결정하고, 토큰·만료·낚싯대 보유를 확인한다. 잡힌 종류도 DB에 기록한다. 완료 응답 재시도는 종류를 바꾸거나 물고기를 중복 지급하지 않는다.
- `HerbHarvest`: 계정·약초 자리별 고유 행. 서버가 후보 ID·재채집 시간과 확률을 확인한다. SQLite에서도 쓰기 잠금을 먼저 얻어 중복 지급을 막는다.
- 이동·물가 방향·화면 선택은 클라이언트 장면에서 판정한다. 서버가 전체 지형이나 실시간 플레이어 좌표를 시뮬레이션하는 구조는 아니다. 서버는 시간을 단축하거나 성공 결과·보상 수량을 지정하는 요청을 받지 않는다.
- 운영 적용에는 코드 이미지, `0008_fishing_cast`, `0009_herb_harvest`, `0010_fishing_catch_item` 마이그레이션과 `python manage.py seed_fishing`이 필요하다. **운영 컨테이너 안에서** 기존 백업·검증 절차를 따른다. seed는 새 물품·상점이 없을 때만 추가하며 기존 가격·봇짐·엽전을 덮어쓰지 않는다.
- 낚시꾼/약재상 대화·물품 원본·약초 후보는 `gis/characters/npcs.json`. 물품·상점은 운영 DB가 우선한다. 기본 낚시·채집은 v0.5.28에 배포했다. 후속 물가 배치·시선 방향 투척·종류 확장·10초 진행 막대·액션바 우클릭 수정은 다음 배포에 포함한다.
