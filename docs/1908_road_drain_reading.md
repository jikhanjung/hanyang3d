# 1908 도로·하수구 판독과 1912 비교 재개

2026-09-08. 도성 전도 TPS 웹 작업 이후 1908–1912 비교를 재개했다. 경행방 제3호까지 비교 범위를 넓혔으나 **동일 지점으로 확정한 시대 간 대응점은 아직 없다**. 우선 비교 대상 선의 종류를 구분하고 첫 이미지 좌표 판독선을 작성했다.

## 판독 결과

[판독 데이터](../gis/roads/1908_gyeonghaeng_reading.json)는 asset-0012의 일부 구간을 대상으로 한다. 도로 3개 선과 하수구 2개 선이며, 모든 형상은 `proposed`다. 원본 픽셀 좌표와 SHA-256, 사료 ID, 기호 판독 근거를 보존했다. 지리 GeoJSON이 아니며 현대 좌표·도로 폭·도로망 연결·하수구 유향은 미확정이다. 선의 끝은 검토 구간의 끝이다.

[웹 판독 화면](../gis/georeferenced/readings/index.html)은 Django에서 `/gis/georeferenced/readings/index.html`로 연다. 판독선을 켜고 끄며 원도와 비교할 수 있다. 원본과 화면 파생 파일은 Git 제외이고, 데이터·생성 코드는 Git 관리다.

## 확인한 근거

『1908 한성부지적도』(2015, src-0008) 인쇄/PDF 192쪽은 경행방도의 황토색을 도로, 푸른색을 하수구로 설명한다. 따라서 푸른 선을 자연하천이나 도로 중심선으로 자동 해석하지 않았다. 붉은 외곽선의 구획 용도와 소유자는 이 판독에서 확정하지 않았다.

같은 쪽의 현재 위치는 경운동·낙원동으로, src-0017의 기관 상세 설명과 일치한다. 도록 7쪽 표의 관훈동 표기는 그대로 남겨 내부 불일치로 기록했다. 이 동명 설명만으로 실제 도엽 polygon을 확정하지 않는다.

## 1912 비교 상태

관인방·경행방과 기존 1912 도면 5·6·12·13호를 비교했다. 전처리 후 자동 특징 비교는 충분히 분산되고 판독 가능한 대응을 얻지 못해 채택하지 않았다. 도로 분기 3곳을 가정한 수동 배치도 주변 필지를 함께 맞추지 못했고 큰 전단 변형을 요구하여 기준점으로 채택하지 않았다. 검사점을 확보한 정합 실험이나 성공한 TPS로 기록하지 않는다.

[기존 검토 JSON의 후속 항목](../gis/control_points/insadong_review.json)에 결과를 추가했다. 다음 검토는 이번 도로·하수구의 분기와 인접 필지 형태가 함께 맞는 구간을 찾는 것이다. 1908 방 경계와 1912 동 경계를 같은 선으로 전제하지 않는다.

## 재생성

후속 [비교 후보 기록](../gis/control_points/1908_1912_comparison_cases.json)은 서쪽 골목·하수구 분기, 동쪽 골목·붉은 구획 남측, 서남쪽 계단형 방 경계의 3개 원본 구간을 고정했다. 판독 화면의 각 카드에서 1912 제5·6·12·13호를 선택하면 지도 비교 화면의 왼쪽이 해당 구간으로 확대된다. 오른쪽은 목표 위치가 미확정이므로 도엽 전체를 보여 준다. 후보 변경·다시 확대를 지원하며 대응점을 자동 생성하지 않는다.

```bash
.venv/bin/python scripts/georeference/build_reading_review.py
.venv/bin/python scripts/georeference/build_review.py
```

생성기는 원본 체크섬과 좌표의 이미지 범위를 검증한다. 이번 판독선은 원본에 직접 겹쳐 육안 점검했다. 최종 지리 정합·측량 정확도 테스트가 아니다.

## 두 분기점 배치 가설 검토

1908 경행방도와 1912 제6호의 서쪽·동쪽 분기를 각각 같은 위치라고 가정하여 확대·회전·이동으로 배치했다. 가정점은 원본 픽셀 좌표 `(958,1036) → (930,322)`, `(1124,1224) → (1155,590)`이다. 두 점으로 유사변환을 결정했으므로 선택점의 일치는 검증 결과가 아니다.

서쪽 분기의 도로·하수구 구분과 동쪽 분기 주변 필지의 연결 관계가 함께 대응한다는 근거를 확보하지 못했다. 따라서 이 특정 배치는 기준점으로 채택하지 않았다. 두 도엽이 지리적으로 겹치지 않는다는 의미는 아니다. 독립 검사점은 0개이고 검사 RMSE는 산출하지 않는다.

[재현 기록](../gis/control_points/1908_1912_branch_hypothesis.json)에 원본 체크섬, 가정 좌표, 변환 행렬, 미채택 이유를 저장했다. 판독 웹 화면의 ‘두 분기점 가정 배치 검토’에서 투명도를 바꿔 대조할 수 있다. 다른 도엽 후보와 서남쪽 경계 후보는 미확정 상태로 유지한다. 다음 정합 판단에는 선택점 외의 인접 필지·도로 연결 관계를 확인할 별도 근거가 필요하다.
