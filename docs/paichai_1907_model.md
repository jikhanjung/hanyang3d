# 1907년 배재학당 본당

- 대상: 1887년 준공, 1929년 철거된 옛 본당. 학교 자체의 설립(1885)과 건물의 존속 연대를 분리.
- 현재 역사박물관인 1916년 동관은 1907년 장면에서 제외.
- 옛 사진의 단층 벽돌 교사, 여섯 아치창, 돌출 중앙 아케이드·박공, 기와지붕과 굴뚝을 자체 모형으로 단순화. 사진을 텍스처로 사용하지 않음.
- 위치: asset-0024의 회전 적용 좌표 `[509,2520]`. 정동교회 남쪽 큰길 건너 구획, 작은 남북길 서측. 지도에서 학교 글씨·필지 경계를 확정 판독하지 못했으므로 구획 내 추정이다. 렌더링상의 교회와 거리 약 166m.
- 치수 32×10×14m, 방향 12도는 추정. 내부 관람은 구현 범위에 포함하지 않음. 현관 계단, 건물 충돌, 원거리 단순 모형, 이름/클릭 설명은 기존 시스템 사용.
- 데이터: `gis/buildings/1907_landmarks.json`; 상세 설명은 `docs/landmarks.md` 및 영어 JSON. 운영 DB는 다음 배포 시 `sync_content --apply`로 신규 건물 추가(미리보기·백업·충돌 확인). 이번에는 배포하지 않음.
