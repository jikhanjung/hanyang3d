# 한양 고지도 간 비교·캘리브레이션 설계

2026-09-18. 여러 시대의 지도를 같은 공간 위에서 비교하면, 한 지도에서 판독이 어려운 장소를 다른 지도에서 좁혀 갈 수 있다. 현재는 **설계와 장소 대응 후보 정리** 단계이며, 새 지도들의 정합이 완료된 상태가 아니다.

## 제작 방식과 판본을 먼저 구분

“19세기 말 이전은 모두 비측량, 이후는 모두 정확”으로 나누지 않는다. 서울역사박물관은 초기 수선전도를 1824~1834년 김정호가 실측해 제작했다고 설명한다. 역사 서술의 “실측”은 현대적인 삼각측량·측지 기준망·오차 관리가 적용됐다는 의미로 읽지 않는다. 구체적 측정 방식은 별도 확인 대상이다. 이 용어를 현대 측량 정확도의 증거로 사용하지 않고 독립 검사점으로 실제 위치 오차를 검증한다. [박물관 야외전시 안내](https://museum.seoul.go.kr/www/exh/openExh.jsp?sso=ok).

수선총도는 소장본마다 추가 지명과 표현이 다르고 제작연대 설명도 갱신되었다. 2010년 소개의 1824~1870년 추정과 2024년 연구 소개의 1850년대 추정을 그대로 섞지 않고 판본·근거별로 보존한다. [2024년 수선총도 연구 소개](https://museum.seoul.go.kr/www/board/NR_boardView.do?bbsCd=1032&seq=20240401102150569&sso=ok), [소장품 안내](https://museum.seoul.go.kr/www/board/NR_boardView.do?bbsCd=1126&seq=20140421080000060&sso=ok).

## 대응점을 저장하는 방법

1. 지도마다 고유 asset ID, 원본 해시, 판본/소장번호, 제작 연대 범위, 이미지 회전·잘라낸 범위를 고정한다.
2. 동일 장소에 공통 `place_id`를 부여한다. 각 이미지에서는 건물 중심, 문 통로 중심, 교대 끝점처럼 **무엇을 찍었는지** 구분한다. 글씨 중심과 건물 기호 중심은 같은 기준점이 아니다.
3. 이전·중건·확장 이력과 판독 확실성을 기록한다. 보신각과 이동한 궁문을 이름이 같다는 이유만으로 고정점으로 쓰지 않는다.
4. 좌표 결정에 이용할 점과 별도 검증점을 미리 나눈다. 건물 추정 위치로 만든 점을 다시 정확도의 증거로 쓰지 않는다.
5. 두 지도를 직접 비교하는 대응도 보존한다. `1750→1907→현대` 연쇄만 저장하면 중간 지도의 오차와 실제 도시 변화를 분리할 수 없다.

이번에 `gis/control_points/landmark_correspondence_1750_1907.json`에 **장소 대응 후보 30개**를 저장했다. 전부 `accepted_for_fit=false`, `role=candidate_only`다. 지도 관측이 없는 항목은 없는 상태를 보존한다. 시설 존속 확인이 곧 그 좌표의 검증을 뜻하지 않는다.

## 변환·검증 순서

- 도성 전체는 affine으로 이동·회전·축척·전단을 먼저 비교한다.
- 궁궐권·종로권·남산권처럼 구역별 잔차 분포를 본다. 국부 정합이 필요한 구역은 별도 변환을 유지한다.
- TPS나 구역별 삼각망은 독립 검사점 오차가 개선될 때 채택한다. 맞춘 점의 오차가 0이 된다는 이유로 정확하다고 하지 않는다.
- 반전된 삼각형·과도한 늘어남·접힌 영역·경계 밖 외삽을 검사한다. 산봉우리의 회화적 표현은 정밀 고정점에서 제외한다.
- 점별 잔차, 구역별 중앙값·95백분위·최대 오차, 사용 점/제외 점, 해상도와 변환 버전을 기록한다. 기준점이 드문 곳은 정밀도 미확정으로 둔다.
- 위치 결과는 확정 좌표 한 점과 혼동하지 않도록 추정 구역 또는 근거가 있는 오차 범위를 제공한다. 계량 검증 전 임의의 ±몇 m를 신뢰구간처럼 쓰지 않는다.

기존 [좌표 정합 규칙](georeferencing.md), `fit_pixel_affine.py`, `detail_sheet_fits.json`, 1908/1912 비교 실험을 이어서 사용한다. 최종적으로 원본/보정본 겹치기, 대응점 켜기, 구역별 잔차 보기가 있는 검토 화면을 만들 수 있다. 현재 서비스의 1750·1907 지도 변환을 이번 제안만으로 자동 변경하지 않았다.

## 1907년 산지 국부 보정 (2026-09-18)

백악산 주변 두 닫힌 등고선과 남산 정상부에 한해 시각적 국부 정합을 적용했다. 현대 FABDEM 높이를 유지하면서 지도·성벽·건물의 좌표를 함께 변환한다. 원도 봉우리의 동일성은 잠정이며, 역사적 지형 복원으로 해석하지 않는다. 관측점과 고정점, 수치 검증 결과는 [기록 151](../devlog/20260918_151_seoul1907_mountain_calibration.md)에 있다. 다른 판본 사이의 정합은 아직 후보 단계다.
