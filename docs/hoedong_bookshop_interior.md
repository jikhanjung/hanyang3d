# 1907년 회동서관 실내·주인·소설 판매

## 자료와 재현 범위

[회동서관 터](https://dh.aks.ac.kr/~jisun/edu/index.php/회동서관_터)는 1897년 서적상 출발과 1907년 회동서관 명칭을 설명한다. 1915년 사진이나 훗날 출판 목록을 1907년 실내·재고로 소급하지 않는다.

[한국민족문화대백과 「독서」](https://encykorea.aks.ac.kr/Article/E0016007)는 조선 후기 유통·독서에서 춘향전·구운몽·숙향전 등을 다룬다. 이 근거로 1907년 이전의 소설 세 종류를 골랐다. 회동서관의 해당 연도 판매 판본·재고·가격이나 은밀한 판매 관행을 확인한 것은 아니다. 남녀의 사랑을 다룬 옛 소설이라는 맥락이며 노골적인 성적 묘사는 제공하지 않는다.

## 구현

- 기존 추정 위치·15×11m 규모를 유지한 기와 서점. 앞문 2.8m, 높이 0.3m 마루, 지형에서 연결되는 계단.
- 벽면·중앙·뒤쪽 책장, 낮은 판매대, 쌓아 둔 선장본 형태의 책. 책장은 개별 충돌과 카메라 막힘이 있고 중앙/후면 통로는 열린다.
- 책은 InstancedMesh 두 개(내지·표지)로 묶고 책장·책 상세는 근거리에서 표시. 실내 영역에 들어가면 공통 규칙으로 외부 이름 숨김·자동 하마.
- 가상의 책방 주인이 0.75m/s로 이동하며 노드마다 3초, 뒤쪽 구석에서 12초 멈춘다. 대화 중 이동 정지. 기존 시국 이야기 메뉴 유지.
- 1인칭 사용자가 실내에서 주인 3m 이내에 있고 주인이 뒤쪽 구석에 있을 때만 ‘남녀상열지사를 다룬 책’ 선택지가 추가된다. 선택하면 별책 상점을 연다.
- 춘향전 18문, 구운몽 26문, 숙향전 22문. 놀이용 가격이며 서버 DB 기준으로 결제하고 봇짐에 보관한다. 이번 범위는 구매이며 책 전문 읽기는 구현하지 않았다.
- 위치 조건은 장면의 상호작용 조건이다. 기존 거래 API는 위치를 서버에서 검증하는 시스템이 아니므로 이를 부정거래 방지용 서버 권한 검사라고 보지 않는다.

## 배포

`0011_book_icon` migration과 웹·멀티플레이 이미지 갱신이 필요하다(멀티플레이는 함께 작업한 말 보법 전송 변경 때문). `python manage.py seed_books`는 컨테이너 안에서 실행하며 누락된 3개 상품·상점만 만들고 기존 편집 값·판매 목록은 보존한다.

인물 갱신은 `gis/updates/1907_cathedral_dialogue.json`에 성당 역할 분리와 함께 묶었다. 이 미배포 번들의 이전 people1907 해시는 v0.5.30 기준이다. 검증 백업 후 `update_data.sh`로 적용한다. 파일만 교체하거나 seed_scene_data만 실행해서는 운영 인물이 바뀌지 않는다.
