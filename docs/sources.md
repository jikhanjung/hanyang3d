# 자료 등록과 취득

초기 [sources.csv](../data/catalog/sources.csv)의 7건은 조사 원문에서 추린 우선 후보입니다. 모두 `unverified`이며 외부 사이트를 이번 초기화에서 재확인하지 않았습니다. 원문의 자료 수·연대·서비스 기능은 최신 사실로 보증하지 않습니다.

## 등록 순서

1. 기존 URL·기관 식별자·제목을 확인해 중복을 찾습니다.
2. 안정적인 source ID를 만들고 제작 시기, 공간 범위, 기관, 원문 URL을 기록합니다.
3. 상세 페이지를 직접 확인하고 확인 범위·날짜를 기록한 뒤 `verified`로 변경합니다. 접속 불가·열람 제한은 `blocked`와 이유로 남깁니다.
4. 자료군은 파일럿 관련 개별 도엽으로 나누어 등록합니다. 부분도·도록·스캔의 관계를 노트에 기록합니다.
5. 파일별 이용 조건을 확인한 후 취득 가능한 파일을 저장하고 `assets.csv`에 별도 행을 추가합니다.
6. 취득 파일의 SHA-256, 크기, 형식, 취득일과 저장 위치를 기록합니다. 조건이 다른 파일의 권리 정보를 복사하지 않습니다.

기관 전체 수집이나 크롤러 구현 전에 소수 파일로 자료 구조와 다운로드 절차를 확인합니다. 상세 페이지 URL과 실제 파일 URL을 구별합니다. 사라진 URL이나 교체된 파일의 기록은 삭제하지 않고 후속 상태를 남깁니다.

## 사료 노트 형식

`references/source_notes/<source_id>.md`에 다음 항목을 기록합니다.

```markdown
# 자료 제목
- source_id:
- asset_id / 페이지·도엽·이미지 영역:
- 확인일 / 작업자:
- 원문 URL:

## 직접 확인한 내용과 판독

## 해석과 대상 시기

## 다른 사료와의 일치·충돌

## 이용 조건의 근거와 필요한 출처 표기

## 미확인 사항과 다음 작업
```

2차 서비스는 원사료를 찾는 단서로 사용합니다. 원소장처나 제작연대를 확인하지 못했다면 추측해 채우지 않습니다. 조사 문서 안의 예시 객체·신뢰도 값도 검증된 실측 데이터로 등록하지 않습니다.

서울역사아카이브 1건의 취득 결과와 사용자 지정 입력값은 [다운로드 절차](archive_download.md)를 참고합니다. 초기 후보의 서지 검증 상태와 파일 취득 상태는 별개입니다.


## 상세 페이지와 판독 가능성

자료 취득 시 아카이브 번호·유물 번호·별도 자료 번호·시기·자료출처를 카탈로그에 기록합니다. 내용/상세 설명을 포함한 모든 상세 표 항목은 원문 라벨을 유지한 JSON으로 저장하고, 같은 시점의 HTML과 checksum을 보존합니다. 자동 추출은 `scripts/catalog/extract_seoul_archive.py`를 사용합니다. 해석과 요약은 사료 노트에 별도로 작성합니다.

파일을 확보한 사실과 연구 목적에 충분한 해상도를 확보한 사실은 다릅니다. 작은 글자·골목·필지 경계가 보이지 않으면 미판독으로 남깁니다. 확대·보간 결과를 새로운 사료 근거로 취급하지 않습니다. 판독이 필요한 구역이 생기면 부분도, 고해상도 스캔, 원소장처 제공본을 순서대로 조사하고 새 asset ID로 등록합니다.
