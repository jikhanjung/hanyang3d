# 1907년 서울 지도

현재 기본 화면은 1750년경 한양이다. 사용자가 다음 시대로 1907년 「최신경성전도」를 선택하여 별도 `/1907/` 화면을 추가했다. 양쪽 설정 메뉴의 **시대** 선택으로 전환한다. **원본 지도** 버튼은 제목·범례가 있는 전체 이미지를 확대·이동하는 2D 화면으로 전환한다.

## 자료

- 사료 `src-0029`, 원본 `asset-0024`: [소장처·취득·권리 기록](../references/source_notes/src-0029.md).
- 원본 파일: `data/maps/src-0029/asset-0024.jpg`. 변형 없이 보존한다.
- 표시용 이미지: `gis/georeferenced/seoul1907/map.jpg`. EXIF 회전을 적용한 2,667×3,750 JPEG.
- 정합·픽셀·좌표·해시: `gis/control_points/seoul1907.json`.
- 원본과 가공 이미지는 Git 밖의 런타임 자료이며, 공개 허용 목록과 `deploy/pack_data.py` 데이터 묶음에 포함된다. 코드만 배포하면 이미지가 빠지므로 새 데이터 묶음도 필요하다.

## 위치 정합

회전한 전체 이미지 좌상단을 픽셀 원점으로 사용한다. 도곽 표시 범위는 `[115,560,2580,3530]`. 4개 성문 대응점으로 6계수 affine 변환을 구했으며, 전체 지도를 비선형으로 휘지는 않았다.

| 역할 | 지점 | 이미지 픽셀 | 현대 참고 좌표와 차이 (지면 m, 반올림) |
|---|---|---|---:|
| 적합 | 숭례문 | 635, 2767 | 2.3 |
| 적합 | 흥인지문 | 2130, 2300 | 0.9 |
| 적합 | 돈의문 터 | 394, 2301 | 4.2 |
| 적합 | 광화문 | 765, 1917 | 2.8 |
| 적합 제외 비교 | 광화문사거리 | 747, 2220 | 17.38 |
| 적합 제외 비교 | 종로1가사거리 | 1000, 2230 | 42.71 |

적합 잔차가 작다고 지도 전체 정확도가 수 m라는 뜻은 아니다. 모든 픽셀은 육안 판독이며, 현대 참고점과 당시 문의 중심·도로 교차 중심이 정확히 같다는 검증은 없다. 비교점도 공인 측량 검사점이 아니다. 특히 성문 밖과 산지의 독립 검증은 남아 있다.

## 3D 표시

현대 FABDEM 지형과 동일한 삼각형·정점에 지도 텍스처를 올려 투명도가 바뀌어도 높이가 움직이지 않는다. 지도는 도곽 밖을 잘라 표시하고, 원본 보기에서는 전체 이미지를 표시한다. PC는 좌클릭 이동·휠 스크롤 확대·휠 버튼 드래그 회전이며, 모바일은 OrbitControls의 터치 이동·확대·회전을 사용한다. 나침반은 기존 3D 바늘을 공유한다.

1907년 장면에는 1750년용 청계천 지형 보정·성벽·건물·사람·수목을 로드하지 않는다. 현재 구현은 **1907년 지도 + 현대 지형의 초벌 정합**이다. 1907년의 건물 복원이나 1인칭 보행 장면 완성으로 보지 않는다. v0.5.1에서는 첫 1907년 전용 건물로 근정전·중화전·인정전의 단순화 모형을 DB에서 불러온다. [건물 제작 목록과 근거](seoul1907_landmarks.md)에 연대·추정 위치·후속 순서를 기록했다.

## 재현과 검증

카탈로그의 `download_url`에서 원본을 지정 경로에 확보한 뒤:

```sh
.venv/bin/python scripts/georeference/build_seoul1907.py
.venv/bin/python manage.py test webapp.test_seoul1907 webapp.tests webapp.test_i18n
.venv/bin/python scripts/georeference/check_seoul1907_browser.py --url http://127.0.0.1:18027
```

빌드 스크립트는 원본 SHA-256을 확인하고 회전 표시본·정합계수·오차를 재생성한다. 브라우저 검사는 별도 1907년 장면, 원본 보기, 투명도 변경 시 지면 불변, 모바일 메뉴와 시대 전환을 확인한다. 출처·저작권 페이지에 지도와 가공 사실을 추가했다. 2026-09-17 v0.5.0으로 운영 배포했다: https://hanyang3d.nopeoplestime.info/1907/

2026-09-17 v0.5.1으로 세 정전과 건물 이동·연대/출처 패널을 배포했다.

2026-09-17 v0.5.2로 경회루·궁문·종묘·환구단·근대 종교/외교시설 등 16개를 추가해 총 19개 모형을 운영 배포했다. [작업 기록](../devlog/20260917_145_seoul1907_more_landmarks.md).

v0.5.3 운영 배포는 1750년과 표시 방식 통일, LoD, 돈화문 위치 수정, 건물 13개 추가(총 32개), 원도 기반 성곽·백운동천/청계천·다리 7개다. [판독과 한계](seoul1907_infrastructure.md). 2026-09-17 운영에 반영했다.
