# 1907년 서울 — 건물 제작 목록과 위치 기록

작성: 2026-09-17. 기준 지도는 일한서방 《실측상밀 최신경성전도》1907년 11월 수정 재판, 서울역사박물관 소장본이다. 1750년 건물 배치를 복사하지 않고, 이 지도의 기호와 글자를 읽어 위치를 정한다. 첫 제작 묶음은 근정전 → 중화전 → 인정전의 세 정전이다.

## 우선순위와 진행 상태

모든 치수와 방위는 시각화 추정값이다. 숭정전은 원도에 전각이 생략돼 현대 궁궐 참고 위치를 원도 구역과 대조했다. 정동교회 역시 원도 개별 기호를 확정한 위치가 아니다. 황궁우는 환구단 북쪽이라는 상대 위치를 적용했으며, 러시아 공사관은 공관 담장 구역 내 추정 위치다. 낮은 위치 신뢰도를 DB와 화면 설명에 표시했다.

**보류:** 독립문·독립관은 현재 지도 서쪽 도곽 밖의 원위치와 1979년 이전 관계를 추가 대조해야 한다([서울기록원 이전 기록](https://archives.seoul.go.kr/item/5950)). 지도 경계에 임의로 끼워 넣지 않았다. 석조전은 아래의 연대상 보류 기준을 유지한다.

## 첫 세 건의 근거와 모형 범위

- **근정전:** 문화포털은 1867년 11월 중건, 정면 5칸·측면 5칸, 중층 팔작지붕으로 설명한다. 모형은 그 구조를 적용하고 이중 월대·계단·회랑·문·품계석을 개략적으로 표현한다. [문화포털](https://www.culture.go.kr/portal/cltKnw/usePtt/viewOrigin.do?did=60910&menuNo=200059), [궁능유적본부 경복궁 역사](https://royal.khs.go.kr/ROYAL/contents/R101010000.do).
- **중화전:** 1902년 중층 정전이 1904년 화재로 소실되고 1906년 단층으로 중건되었다. 1907년 편찬된 《중화전영건도감의궤》는 화재 전 신축 과정을 담으므로 도설을 그대로 1907년 형태로 사용하지 않는다. 모형의 회랑은 현존 잔여 회랑만 재현한 것이 아닌 조정의 개념 표현이다. [국가기록원 덕수궁](https://theme.archives.go.kr/next/koreaOfRecord/DeoksuPal.do), [한국민족문화대백과 중화전영건도감의궤](https://encykorea.aks.ac.kr/Article/E0076906).
- **인정전:** 고궁박물관은 1804년 중건, 1857년 해체 수리, 1908년 개수를 구별한다. 1907년용은 중층 정전의 외형만 표현하고 후대 실내 개수는 표시하지 않는다. [국립고궁박물관 창덕궁 도록](https://www.gogung.go.kr/ebook/access/ecatalogt.jsp?Dir=161&callmode=admin&catimage=&eclang=ko&start=26&um=s), [국가기록원 창덕궁](https://theme.archives.go.kr/next/koreaOfRecord/ChangdeokPal.do).

전각·조정의 치수와 회랑·문의 상세 배치는 **실측값이 아닌 시각화용 추정**이다. 복제한 박스가 아니라 칸수, 지붕 층수, 월대, 기둥과 창호를 가진 절차적 모형이며 공통 정전 생성기를 이용한다. 단청 색과 장식은 유형화했다. 정밀한 1907년 외관을 확정하려면 당시 사진·도면과 추가 대조해야 한다.

## 연대상 보류할 것

**석조전의 완성형은 1907년에 넣지 않는다.** 국사편찬위원회 설명에 따르면 1907년에는 실내 설계 단계가 진행되고 1910년 4월 완공되었다. 추후 만들면 공사 중 상태를 별도로 연구한다. [국사편찬위원회 — 덕수궁 석조전 건축](https://contents.history.go.kr/front/hm/view.do?levelId=hm_134_0030).

조선총독부 경복궁 청사, 현재의 구 서울역사, 조선호텔 등도 유명하다는 이유만으로 1907년 장면에 넣지 않는다. 후보 등록과 당시 존속 확인은 별도 단계다.

## 좌표·DB·재현 방법

- 원본: [서울역사박물관 최신경성전도](https://museum.seoul.go.kr/www/relic/RelicView.do?cdLanguage=KOR&mcseqno1=015439&mcseqno2=00000&mcsjgbnc=PS01003026001). [지도 정합 설명](seoul1907.md).
- 픽셀 원점은 **북쪽 위로 정규화한 2667×3750 이미지의 좌상단**이다. x는 오른쪽, y는 아래쪽. 원본 JPEG의 EXIF 회전 전 좌표가 아니다.
- 정규화 이미지 SHA-256: `dc58d4256deba8844f3e5e75bd1172a3f3a19ea06bab7a27e48aa9ee054c3fb7`. 위치는 `gis/control_points/seoul1907.json`의 affine 변환을 거쳐 배치한다.
- `gis/buildings/1907_landmarks.json`은 개발자 seed. DB에 `scene_year:1907`로 저장하고 1750년 기본 목록에서는 제외한다. `import_content`는 빈 DB 초기화, 기존 DB에는 백업 후 `sync_content --apply`를 사용한다. 운영 편집 충돌은 자동 덮어쓰지 않는다.
- 위치 앵커는 **전각 중심**이다. 생성기의 조정 중심과 전각 중심 사이 오프셋을 회전 후 보정한다. yaw 약 3.735°는 원도 세로축에서 구한 추정값이며 각 건물의 실측 방위가 아니다.
- 모델 치수는 m, Three.js Y-up, +Z가 모형의 앞쪽. EPSG:3857 정합 좌표를 DEM 중심의 미터 좌표로 옮긴다. 기반은 현대 FABDEM이며 당시 지표 높이를 복원한 것이 아니다.
- 조정 밑 기단은 지형 표본의 최고 높이에 맞추고 아래까지 받친다. 지도 투명도를 바꾸어도 건물과 기단 높이는 변하지 않는다.
- 화면의 건물 이름 또는 설정 → **건물로 이동**으로 개별 모형을 살펴볼 수 있다. 원본 지도 보기에서는 모형·이름표가 숨겨진다.


## 두 번째 묶음의 고증과 구현

- **경회루:** 1867년 중건, 7×5칸·48개 하층 돌기둥. 사각 외곽 기둥과 둥근 내부 기둥, 상층 누각·단일 팔작지붕·연못·섬·다리. 연못의 꺾인 원도 윤곽은 직사각형으로 단순화했다. [우리역사넷 궁궐 건축](https://contents.history.go.kr/front/nh/view.do?levelId=nh_035_0040_0020_0050_0020).
- **광화문·숭례문·흥인지문:** 기존 생성기를 재사용하되 1907년 원도 위치를 별도 저장했다. 광화문 3홍예, 숭례문 우진각, 흥인지문 1869년 중건·외측 옹성을 구분했다. 인접 성벽은 후속 원도 판독으로 추가했으며, 숭례문 주변 연결은 아래 위치 보정 기록을 따른다. [궁능유적본부 경복궁](https://royal.khs.go.kr/ROYAL/contents/R101010000.do), [서울 한양도성 역사](https://seoulcitywall.seoul.go.kr/content/8.do).
- **대한문:** 단층 정면 3칸. 1906년 개칭 이후·1970년 이전 배치를 표현한다. 이전은 건물 소멸과 다르므로 `existence.end_year`는 미확정, `depiction.end_year`만 1970으로 기록. [국가기록원](https://theme.archives.go.kr/next/daily/viewMain.do?selectDay=20120102).
- **명정전·돈화문·홍화문:** 기존 유형 생성기에 1907년 원도 좌표를 적용. 명정전과 홍화문은 동향, 돈화문은 남향. [명정전 재건](https://royal.khs.go.kr/ROYAL/contents/R402000000.do?id=20240904134731840421&schBcid=normal1&schM=view), [돈화문](https://encykorea.aks.ac.kr/Article/E0016240), [홍화문](https://encykorea.aks.ac.kr/Article/E0064444).
- **종묘:** 1608년 중건의 존속과 1836년 증축 모습의 적용 시작을 분리. 정전 19칸, 영녕전 16칸·중앙 4칸 높은 지붕. 1750년 모형의 15칸은 유지했다. [궁능유적본부 연혁](https://royal.cha.go.kr/ROYAL/contents/R105010000.do).
- **환구단·황궁우:** 원형 삼단 제단과 팔각 삼층 신위 봉안 건물을 각각 제작. 환구단은 1897–1913, 황궁우는 1899년 이후. 제단 상세 난간·계단은 개략 표현. [우리역사넷](https://contents.history.go.kr/front/ht/print.do?levelId=ht_003_0020_0020_0020&whereStr=).
- **명동성당:** 1898년 완공, 고딕 벽돌 성당을 십자형 본당·첨두 창·종탑·첨탑으로 단순화. 치수와 창 배열, 축 방위는 추정이다. [국가기록원](https://theme.archives.go.kr/next/koreaOfRecord/myeongdongCathedral.do).
- **정동교회:** 관광공사 기록의 1897년 봉헌, 1926년 증축 전 십자형 평면·남쪽 종탑을 참고. 서울시 자료는 준공을 1898년으로 표기하므로 봉헌/준공 연대 차이가 있다. 1897년은 봉헌 기준이며 증축은 `depiction.end_year=1926`으로 기록. [한국관광공사](https://korean.visitkorea.or.kr/detail/ms_detail.do?cotid=c354b2fc-4c84-496f-822e-e8d78bbd6488), [서울시](https://culture.seoul.go.kr/culture/bbs/B0000000/view.do?menuNo=200050&nttId=3515&pageIndex=30).
- **숭정전:** 문헌상의 1618년 창건·5×4칸·단층·동향, 1926년 매각 이전을 참고. 원도에는 기호가 없고 복원 조정의 정확한 평면도 미확정이므로 궁궐 구역 내 추정 모형이다. [한국민족문화대백과](https://encykorea.aks.ac.kr/Article/E0003036).
- **러시아 공사관:** 2층 벽돌 본관과 한쪽 탑·연창이라는 기록을 단순화. 지붕·외장 색·날개 위치·전체 평면은 추정. 자료에 1890년 완공/초석 서술 차이가 있어 `start_precision=circa`; 전쟁 중 파괴의 정확한 해를 확정하지 않았으므로 표현 종료는 보수적인 1950년, `end_precision`에 1950–1953 기간을 명시했다. 탑은 남아 있어 전체 객체의 존속 종료는 미확정이다. [우리역사넷](https://contents.history.go.kr/front/ki/printViewPopup.do?levelId=ki_060_07000), [한국민족문화대백과](https://encykorea.aks.ac.kr/Article/E0005711).

`models/landmarks/seoul1907/`의 19개 provenance manifest는 `scripts/content/build_1907_manifests.py`로 재생성한다. 새 renderer 등록은 기존 DB 동기화 트랜잭션 안에서 수행하며 운영 편집 항목은 덮어쓰지 않는다. 현재 개발 DB는 1750년 114개 + 1907년 19개 = 총 133개다.

광화문 중건은 공식 자료에서도 1865/1867년 서술이 다르다. 모형 기준은 경복궁 중건 완료 무렵인 1867년을 사용하되 단일 날짜 확정으로 보지 않는다([국가기록원](https://theme.archives.go.kr/next/koreaOfRecord/Gwanghwamun.do), [국가유산청 API 설명](https://khs.go.kr/html/HtmlPage.do?mn=NS_04_04_03&pg=%2Fpublicinfo%2Fpbinfo3_0301.jsp)).

랜드마크 객체 24개를 추가해 현재 65개다. 종로 양측 상점군 12개(점포 표현 144개), 육조거리 관청 구획 10개, 한성전기회사 사옥, 북묘를 추가했다. 사진과 관청 배치도에서 확인한 건축 유형을 단순화했으며 치수·색·부속 건물 배치는 추정이다. 연대·출처·위치 신뢰도와 LoD를 각 객체에 기록했다. [조사와 전차 계획](seoul1907_streets_and_trams.md), [구현·검증 기록](../devlog/20260918_154_street_buildings_and_positions.md).

## 회동서관 추가 (2026-09-18, 총 66개)

- `hoedong-seogwan-1907`: 원도 픽셀 `[1001,2337]`, 크기 15×7×11m, 정면 서향(-86.265°). 크기·방향·외관 모두 추정.
- [사용자가 제공한 DH Edu 자료](https://dh.aks.ac.kr/~jisun/edu/index.php/회동서관_터)는 1906년 광고의 ‘광통교 동변’과 1907-09-07 회동서관 광고를 소개한다. 학생 편집 자료이며 광고 원본 전체를 독립 대조한 결과로 표시하지 않는다.
- 자료에 실린 표석 좌표를 지도 역변환하면 약 `[988,2352]`. 표석을 건물 중심으로 삼지 않고, 광통교 동쪽이라는 설명과 원도 물길·남대문로를 함께 보고 동쪽 구획으로 조정했다. 확정 필지 아님.
- 창업은 본문의 1897년과 표석의 1880년대 설명이 달라 건물 존재 시작연도를 비워 두었다. 묘사 구간은 1907–1908, 기준연도 1907.
- [1915년경 회동서관 사진 소개](https://www.donga.com/news/Culture/article/all/20080702/8597188/1)는 시기 차이가 있어 1907년 실측 외관으로 소급하지 않았다. 프로젝트가 만든 기와지붕·목조 전면·책 진열대·匯東書館 간판과 별도 원거리 LoD를 쓴다. 사진 텍스처는 재배포하지 않는다.
