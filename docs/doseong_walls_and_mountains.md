## 성벽 원도 판독

`gis/walls/doseong_city_wall.json`은 도성대지도 asset-0001의 성가퀴가 반복되는 선을 따라 판독한 165점의 닫힌 둘레다. 녹색 점선과 붉은 도로를 성벽으로 취급하지 않는다. 백악·인왕산·남산의 산 그림과 중앙 접힘으로 흐릿한 부분은 별도의 uncertain_sections에 추정 근거를 남겼다. 원도 판독 보기에서 선과 문 위치를 확인한다.

3 px 간격으로 세분하고 같은 TPS/원도 표시 삼각형에서 x/z를 얻는다. 약 2,131개 짧은 성벽 구간의 실제 지형·원도 표면 최저/최고 고도를 계산해 지형 아래 0.4 m부터 최고 표면 +5 m까지 돌출시킨다. 두께 4 m, 여장 1.1 m는 개략 모형 가정이다. 단순화한 양측 여장을 인스턴스 메시로 표시해 개별 수천 개 객체를 만들지 않는다. 하도 보정과 높이 강조 변경 시 지형과 함께 갱신한다.

돈의문·흥인지문·숭례문은 회전한 기존 모형 바닥 범위에서 성벽을 잘라 연결한다. 나머지 원도의 문 기호 5곳은 열린 틈으로 남기며 별도 문루는 미구현이다. 청계천 통과부도 열어 두고 수문 구조는 재현하지 않는다. 광화문은 외곽 도성 성벽에 연결하지 않는다.

## 다리의 빨간 진입로 정합

`road_connections.pixel_points`에 북쪽 경사로 끝·상판 북단·상판 남단·남쪽 경사로 끝의 4점을 기록한다. 모든 점을 원도 표시 삼각형으로 변환한다. 상판 방향·길이는 가운데 두 점으로, 각 경사로 끝은 바깥 두 점으로 정한다. 경사로는 중심선의 옆 방향 차이까지 반영해 상판과 붉은 진입로를 연결한다. 기존 교량 기호의 pixel은 판독 근거로 보존한다. 021의 수로 수직 방향·고정 14 m 경사로 대신 이 규칙이 최신 배치 기준이다.

모전교: (1262,1482) → (1263,1493) → (1266,1538) → (1267,1549)
광통교: (1420,1476) → (1420,1487) → (1422,1530) → (1422,1542)
장통교: (1529,1523) → (1530,1534) → (1535,1577) → (1538,1589)
수표교: (1620,1524) → (1622,1536) → (1627,1579) → (1630,1592)

폭 12 m와 지형 받침·경사로 접촉은 유지한다. 적색선의 폭과 기호는 개략 판독이며 역사적 도로·교량 실측이 아니다.

## 평지를 유지하는 산지 정합

`gis/control_points/doseong_mountain_alignment.json`에 평지 보호 다각형과 3개 산 그림 대응점을 둔다. 기존 5점 TPS를 base로 계산하고 평지 다각형 내부는 그대로 반환한다. 별도의 산지 TPS는 기존 5점, 평지 경계의 기존 좌표, 산지 3점으로 계산한다. 평지 경계 밖의 거리 0–220 px 구간에서 smoothstep으로 점진적으로 혼합한다. 경계의 가상점은 실측 기준점이 아니라 현재 배치를 보존하는 모델링 제약이다.

남산 원도 (1500,2320), 인왕산 (650,890), 백악 (1080,490)을 현대 DEM의 높은 지점과 대응시켰다. 참고 위치 주변 220 m 안의 기존 257격자 최고 고도를 선택했다. 새 321격자는 같은 원본 고도 타일의 재표본화이므로 이 좌표에서 최고값이 조금 달라질 수 있다. 이전 TPS 대비 지상 이동량은 각각 약 328 / 900 / 590 m다.

| 대응점 | 현대 좌표 (위도, 경도) | 선택한 기존 DEM 고도 |
|---|---|---|
| 남산 능선 | 37.5519287029, 126.9880241705 | 270.51 m |
| 인왕산 능선 | 37.5849712328, 126.9579165723 | 317.37 m |
| 백악 능선 | 37.5932295748, 126.9733563662 | 326.65 m |

원도의 산 그림은 실제 정사영 봉우리 좌표가 아니므로 이 대응도 개략 가정이다. 평지 보호 경계는 사용자의 시각 확인을 보존하려는 가정이며 모든 산기슭의 실측 경계가 아니다. 용산·신촌은 개별 지점을 직접 판독한 정합이 아니라 외곽 보정의 외삽으로, 아직 정확도를 검증하지 않았다.

좌표 참고: [한국관광공사 남산서울타워](https://data.visitkorea.or.kr/linkedview/126535), [한국관광공사 인왕산](https://data.visitkorea.or.kr/linkedview/126479), [OSM 백악 정상](https://www.openstreetmap.org/node/2668271331). 백악 OSM 좌표는 [Mapcarta 재게시값](https://mapcarta.com/N2668271331)으로 대조했다. 남산 페이지 직접 조회는 503 응답으로 검색 색인의 관광공사 위경도를 사용했다. 참고 장소 좌표 자체를 산 정상 실측점으로 확정하지 않고 주변 DEM을 함께 사용했다.

공통 `fitTerrainTPS`를 평면·3D에 사용한다. 3D의 ‘산기슭부터 정합’은 페이지를 다시 불러오며 `?alignment=base`로 기존 배치와 비교한다. 평지의 5개 파란 점과 산지의 추가 3개 점을 표시한다. ‘남산 확대’ 및 ‘산기슭 정합 근거’의 보호 영역 그림을 제공한다.

고도 범위는 EPSG:3857 [14129500,4513500,14142500,4526500], 321×321로 확장했다. 원자료 4개 타일, 새 표본 고도 범위 -22.7–517.9 m다. 원본 지도와 고도 타일은 수정하지 않는다.

## 숭례문 접속부 정렬 (026)

숭례문 중심에서 35 m 이내 성벽을 문 모형의 가로축에 정렬했다. 35–100 m 구간에서 smoothstep으로 원도 판독선으로 돌아가고, 100 m 밖은 기존 선형을 그대로 유지한다. 문의 위치·통로 방향을 바꾸지 않으며 성벽 높이는 바뀐 위치의 실제 표시 지형에서 다시 계산한다.

성벽 판독 픽셀은 먼저 `sourceSurface`로 변환한다. 이는 현재 ‘산기슭부터 정합’ 적용 여부를 포함한 원도 표시 삼각형의 x/z이므로, 외곽을 늘리면 성벽도 같은 위치로 따라간다. 단순히 변형 전 현대 좌표를 재사용하지 않는다. 숭례문 접속부만 위 규칙으로 의도적으로 원도 선에서 벗어난다. sourceNodes 진단값으로 원도 변형 위치를 보존해 접속부 밖의 추가 이동이 없는지 검사한다. 원도 자체에서 희미하거나 가려진 구간의 수동 판독 불확실성은 남는다.
