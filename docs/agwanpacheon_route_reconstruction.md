# 아관파천 회상 경로·도착 연출 검토 (2026-09-21)

## 기록과 추정의 구분

동북아역사재단 김영수의 「아관파천, 이범진, 그리고 쉬뻬이에르」(2016년 11월)는 영추문 → 금천교 → 내수사 앞길 → 새문고개 → 러시아공사관 순서로 이동했다고 설명한다. 세부 좌표를 제공하는 자료는 아니다.

- 출처: https://www.nahf.or.kr/web/portal/webzine/774/56075
- 내수사 부근은 현재 내수동·경희궁의 아침 3단지 일대. 내수동 72번지 표석과 실제 청사 범위를 동일시하지 않는다. 옛 지도·지번 비교 참고: https://lembas.tistory.com/164
- 새문고개 구간은 사용자가 지정한 **현재 새문안교회 앞 부근**을 경유하는 해석이다. 오늘날 교회가 1896년에 그 모습으로 있었다는 뜻이 아니다. 현대 교회 앞 위경도 부근을 1907 지도 변환으로 역산한 픽셀 `[598,2207]`을 사용했다. 현대 위치 참고: https://findby.co.kr/details/03182-111103005004-st-652c0c06f27008be2c54f263
- 금천교는 정확한 위치·치수 미확정. 1907년 지도에 판독해 둔 백운동천의 `[580,1870]` 부근에 회상 전용 개념 교량을 놓았다. 수로 양안과 교량 진입로를 직접 경유하며 수면 아래 경로는 금지한다. 청계천 본류의 광통교 등과 동일시하지 않는다.
- 도로변 초가·기와집, 담장, 골목은 고정 시드의 추정 경관이다. 1907년 건물의 실제 존속 연대를 1896년으로 소급한 자료가 아니다. 현대 FABDEM 지형을 유지하며 별도의 가상 고개를 만들지 않는다.

## 호칭과 공사관 경비

아관파천은 1896년 2월 11일이다. 1894년 음력 12월에 왕실 호칭이 주상 전하에서 **대군주 폐하**로 격상되었으므로, 1897년 황제 즉위 이전인 이 장면에도 ‘폐하’가 적절하다.

- 국사편찬위원회 우리역사넷: https://contents.history.go.kr/mobile/kc/view.do?levelId=kc_i401000
- 재단의 위 글에는 아관파천 직전 러시아 해병 병력 증원과 공사관 경비가 설명되어 있다. 게임의 수병 4명은 전체 주둔 인원을 재현한 것이 아니다. 짙은 제복·모자·소총은 단순 개념 표현으로, 특정 부대 군복의 실측 복원이 아니다.

## 체험 구성

가마는 1.65 → 2.8m/s로 이동한다. 일반 걷기 3m/s보다 느려 모바일에서도 추적할 수 있다. 45m 이상 뒤처지면 기다리는 동작을 유지한다.

공사관 앞마당에서 멈춤 → 휘장 열림 → 고종과 왕세자 하차 → 맞이하는 인물의 인사 → 출입구를 통해 입장 → 완료 저장 순으로 연출한다. 의복, 대사, 인사 동작, 가마 두 대의 연출, 출입구 형태는 창작이다. “폐하, 이쪽으로 드시옵소서.”는 역사적 발언을 인용한 것이 아니다.

경로 확인 지점이 달라져 정의 버전을 2로 올렸다. 기존 진행은 사용자에게 새 경로로 다시 시작하도록 알리고, 계정의 기존 완료 시각은 보존한다. 일반 1907년과 1750년의 이동 속도·건물 배치는 바꾸지 않는다.
