# 좌표 정합 규칙

P2에서 현대 기준자료의 좌표계와 파일럿 위치를 확인한 뒤 작업용 투영 CRS를 확정합니다. 미터 단위로 거리·면적을 평가하고 EPSG 식별자 또는 WKT를 기록합니다. GeoJSON 교환본은 경도·위도 순서의 WGS84로 내보내며, 원본 좌표계를 추측해 지정하지 않습니다.

1. 1912 지적자료와 현대 기준자료를 비교하고 실제로 존속한 기준점을 선정합니다.
2. 1908 자료와 19·18세기 자료를 각각 정합합니다. 연쇄 변환에 따른 오차를 별도로 기록합니다.
3. 기준점마다 원본 pixel 좌표, 목표 좌표, 선정 근거, 존속 여부, 채택 상태를 저장합니다.
4. affine 등 단순 변환부터 비교하고 필요에 따라 polynomial/TPS를 평가합니다.
5. 정합에 사용하지 않은 검사점으로 오차를 평가하고 국부 왜곡과 잔차 분포를 확인합니다.

`gis/control_points/`에는 `gcp_id,asset_id,pixel_x,pixel_y,target_x,target_y,target_crs,role,evidence_note`를 가진 CSV를 둡니다. `role`은 `control` 또는 `check`입니다. 이미지 pixel 원점과 축 방향도 실험 기록에 명시합니다.

각 실행 기록에는 입력 SHA-256, CRS, 변환 방식·차수, 도구 버전, 사용·제외 점, RMSE와 최대 오차 및 단위, 검사점 오차, 출력 경로를 포함합니다. 허용 오차는 사용 목적과 원본 축척·해상도를 근거로 실험 전에 정합니다. 검사점 부족 시 검증의 한계를 명시하고 정밀 위치 확정에 사용하지 않습니다.

회화적인 산 정상, 이동·재건된 문, 변형된 하천은 자동으로 고정 기준점으로 취급하지 않습니다. 원본, 원도 판독 벡터, 보정 벡터를 구분하고 변형이 실제 도시 변화인지 지도 왜곡인지 판단 근거를 남깁니다.

사용자 요청으로 추가한 [도성 전도 TPS 화면](doseong_terrain_overlay.md)은 현대 배경 위에 직접 놓는 탐색용 미검증 배치입니다. 후보점을 정식 GCP로 승격하지 않으며 위 단계적 정합의 완료로 세지 않습니다.
