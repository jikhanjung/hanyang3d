# 프로젝트 범위

장기 목표는 조선 후기 한양 도성 내부의 시공간 GIS, 증거 데이터베이스, 3D 자산 라이브러리입니다. 도성 외곽과 다른 시기는 같은 규칙을 검증한 뒤 확장합니다.

## 첫 파일럿

후보 지역은 **육조거리–종로–청계천**입니다. 첫 작업 단위는 이 전체가 아니라, 지적도·고지도·실측 또는 발굴 자료가 겹치는 한 블록이나 짧은 가로 구간입니다. 의정부지 주변과 종로·청계천 연결 구간을 우선 비교합니다.

P1에서 도엽 범위와 이용 가능한 근거를 확인한 뒤 경계 polygon을 `gis/pilot_area.geojson`에 기록합니다. 면적, 포함 지명, 선정 이유, 제외 영역을 함께 문서화합니다. 현재 정확한 경계는 미정입니다.

1908·1912년은 좌표 비교를 위한 별도 레이어로 우선 구축합니다. 첫 역사적 복원 시기는 확보한 자료로 판단하며, 18세기 중엽과 19세기 후반을 후보로 둡니다. 특정 연도에 존재했다고 확인하지 못한 객체는 해당 연도의 확정 장면에 포함하지 않습니다.

## 첫 결과물

- 확인 가능한 원본과 파일별 메타데이터
- 정합 과정과 오차를 검토할 수 있는 GIS 프로젝트
- 도로·수계·필지·건물의 시간과 출처 연결
- 대표 건물 1개와 주변 공간의 단순 3D 모델
- 근거·추정 수준을 확인하는 최소 탐색 화면

초기에는 한양 전체의 정밀 모델, 모든 기관의 완전 수집, 범용 자동 복원 AI, 사실적인 민가 전수 모델링을 범위에 넣지 않습니다.
