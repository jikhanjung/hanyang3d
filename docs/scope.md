# 프로젝트 범위

갱신일: 2026-09-09. 장기 목표는 조선 후기 한양 도성 내부의 시공간 GIS, 근거 데이터와 3D 자산이다. 첫 결과는 **도성대지도를 바탕으로 도성 전체의 주요 길·하천·성곽을 대략 볼 수 있는 지도**로 정한다.

## 첫 작업 범위

도성대지도 전체 JPG를 기본 자료로 사용한다. 사대문 안의 가로·수계 구조를 중심으로 성문·성곽과의 관계를 함께 보여 준다. 현대 지형과의 오버레이 및 TPS 부분 변형 도구를 활용하고, 부분도는 판독이 어려운 구간의 보완에 사용한다.

첫 시각화 목표는 고도 데이터로 구성한 3D 지형에 도성대지도를 입히고 기울임·회전·확대로 둘러보는 Django 기반 화면이다. 기존 OSM/OpenTopoMap 평면 배경에 더해 실제 고도를 표현하기 위해 Mapzen Terrain Tiles의 고도와 Three.js를 사용한 [첫 3D 화면](doseong_terrain3d.md)을 구현했다. 원본 판독선과 검토 가능한 전체 배치를 순차 추가한다. 상세 필지 정합이나 건물 복원 없이도 도성 전체의 공간 구성을 탐색할 수 있게 한다. 대략적 배치임을 표시하고 선별 출처·판독 불확실성을 보존한다.

## 후속 범위

건물의 위치·외형·높이는 별도 자료를 확보한 뒤 대표 사례부터 추가한다. 현재 지형 배경은 역사 지형의 3D 복원 결과가 아니다. 한양 전체의 정밀 건물 모델, 기관 전수 수집, 범용 자동 복원은 첫 작업에 포함하지 않는다.

1908 관인방–경행방 연결과 1908–1912 비교는 세부 연구로 보존한다. 해당 정합의 완료를 전체 지도 제작의 선행 조건으로 두지 않는다. 육조거리–종로–청계천의 상세 파일럿 경계는 필요해질 때 확정하고 `gis/pilot_area.geojson`으로 기록한다.

## 시간과 정확도

도성대지도에 나타난 모습과 1908·1912·현대 자료를 별도 시점으로 다룬다. 특정 연도의 확정 복원 장면은 아직 정하지 않았다. 현대 기준점에 맞춘 TPS는 개관을 위한 배치이며 거리·면적·필지 경계의 정확도를 보증하지 않는다. 미판독 구간은 임의로 연결하거나 건물로 채우지 않는다.

우선순위 변경의 근거는 [결정 0002](decisions/0002-citywide-map-first.md)에 기록한다.
