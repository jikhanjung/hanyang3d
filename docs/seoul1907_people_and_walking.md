# 1907년 걷기·거리 인물

1907년 지도에 1750년과 같은 걷기 조작, 계정, 봇짐·거래, 대화와 함께 걷기를 연결한다. 인물은 특정 실존 인물의 복원이 아닌 당시 복식 유형을 단순화한 가상 인물이다.

남성은 저고리·바지 차림과 긴 두루마기·갓 차림을 섞고, 여성은 짧은 저고리·치마와 쪽머리를 표현한다. 밝은 회백색을 중심으로 차이를 주었다. 여성·남성 비율 및 복식 변형의 비율은 화면 설정이다. 경비병은 어두운 단추 상의·세운 깃·바지·차양 모자·단순 장총으로 구분한다. 특정 연대의 정확한 제식·부대 표장·색상을 재현했다는 의미는 아니다. 당시 다양한 외국인·신식 복장 전체를 망라하지 않는다.

참고 사진은 임시 경로에서 판독했으며 서비스 텍스처로 복제하지 않았다. 인물 기하는 코드로 자체 제작했다.

## 장면 구성과 대화

- 큰길 8개에 행인 128명. 원도 길에서 경로를 만들고 서버와 브라우저가 같은 지도 변환·이동 규칙을 사용한다. 흥인지문 옹성 및 일부 상점과 겹치는 구간은 행인의 왕복 구간 끝을 제한했다. 도로 자체의 판독선은 유지하며 성문 통과 군중을 확정 복원하지 않는다.
- 종로 상점군 12곳에 상인 12명. 기존 물건·가격·거래 API를 사용한다. 업종과 자리의 조합은 가상 배치이며 실제 상호나 1907년 독점 상권을 주장하지 않는다.
- 대한문·돈화문·근위대대 권역에 경비병 총 6명. 정확한 초소·배치 인원은 미확인이다. `valid_from=1907-08-26`과 추정 배치 상태를 기록했다.
- 행인·상인·경비병을 누르면 대화한다. 거리 변화와 군대 해산 설명에는 출처를 연결하고 모든 대사를 창작이라고 표시한다.
- 엽전·가격·말 타기는 기존 게임 기능을 공유한다. 당시의 화폐 개혁·실제 가격을 복원한 경제 시뮬레이션이 아니다.

자료: `gis/characters/seoul1907.json`, `gis/roads/seoul1907_walking_routes.json`. 인물의 연대·출처·대화는 이 시대별 JSON에서 관리하며 건물 DB를 인물 저장소로 가장하지 않는다. 계정·보유 물건·거래는 기존 DB에 저장한다.

## 공통 기능

`first_person.js`가 두 시대의 키보드·조이스틱·시선·점프·말 타기를 담당한다. 눈높이는 지면 위 1.65m, 기본은 기존 1750년과 같은 뒤따르는 카메라이며 휠을 가까이 당기면 눈 시점이다. 모바일은 반투명 조이스틱, 점프 버튼과 반투명 미니맵을 사용한다. 물건 옆의 **쓰기** 버튼으로 모바일에서도 말에 타고 내릴 수 있다. PC 오른쪽 클릭도 유지한다.

저장 위치는 `seoul1907` 공간으로 구분하고 멀티플레이도 1750년과 다른 방을 사용한다. 인증·접속자 이름·채팅·NPC 동기화는 기존 규칙을 따른다. 건물·성벽은 이동을 막고 성문 통로와 다리는 통과할 수 있다. 일반 건물 내부 탐험은 제공하지 않는다.

## 회동서관 앞 책방 주인 (2026-09-18)

중심 이야기꾼 1명을 회동서관 추정 건물 앞에 배치했다. 50대 서포 주인이라는 창작 설정이며 실존 경영자 고제홍·고유상의 재현이 아니다. 갓·회색빛 두루마기·손에 든 책으로 구별한다. 건물 목록에서 회동서관을 고른 뒤 **책방 주인과 이야기하기**를 누르거나, 가까이에서 인물을 누르면 기존 궁감과 같은 대화 창이 열린다. 모바일도 같은 선택지를 사용한다.

`gis/characters/seoul1907.json`의 `storyteller`와 `storytellers`에 대사·배치를 둔다. NPC는 다른 1907년 NPC처럼 파일 기반이며 백오피스 이야기 DB와는 별도다. 건물은 기존 건물 DB seed/sync 대상이다. 원래 조사 후보 24편은 보존하고, 그중 16편을 한국어·영어 대사로 각색해 연결했다.

- 전차·신기술: S1907-01, 02, 03, 05, 06.
- 궁궐·정치: S1907-09, 10, 11, 14, 16.
- 거리 생활: S1907-07, 17, 18, 19, 20, 22.

각 대사에 원래 이야기 ID, 사건 연대, 출처 URL, `knowledge_mode=fictional_retelling_not_eyewitness`를 둔다. 고종실록의 후대 편찬 사실과 당시 인물의 지식을 혼동하지 않도록 NPC가 실록을 읽었다고 말하지 않는다. 북묘는 왕실 피난의 구체적 동시 동선을 단정하지 않고, 수도는 1907년에 공사 소식을 들은 상태로 다룬다. 11월 13일 창덕궁 이어 등 지도 기준일만으로 선후가 불분명한 사건은 이번 대사에서 제외했다. NPC 표시 범위 1907–1908은 시각화 구간이며 인물 생몰년이 아니다.

## 긴 이야기 구성 (2026-09-18)

책방 주인의 16편을 각각 4장면으로 확장했다. 총 64장면이며 한국어 본문은 편당 638–705자(평균 685자)다. 기존의 짧은 도입 뒤에 배경, 사건의 전개와 생활상의 의미가 이어지고, 방문객의 질문을 선택해 다음 장면으로 간다. 앞 장면·주제 목록·처음 목록·닫기를 유지한다. 공통 대화 창은 이야기 제목과 `현재 / 전체`를 표시하고 장면이 바뀌면 스크롤을 맨 위로 돌린다. 이 메타데이터가 없는 기존 NPC는 진행 표시를 숨긴다.

한국어와 영어를 모두 확장했으며 각 장면에 출처와 사건 연대를 유지한다. 이야기 ID는 도입에, 뒤 장면은 `parent_story_id`에 기록한다. 읽기용 [전체 한국어 대본](seoul1907_bookseller_script.md)을 별도로 남겼다. 주관적 비교와 가정 장면을 실제 목격담이나 역사 인물의 직접 인용으로 표시하지 않는다. NPC JSON이 정본이며 대본 문서는 검토용 사본이다.
