## 실행과 화면

[웹서비스 안내](../webapp/README.md)의 의존성 설치·검증·실행 절차를 따른다. Python 의존성은 `requirements.txt`, 브라우저 검증은 `requirements-dev.txt`에 있다. DB는 사용하지 않는다.

```bash
.venv/bin/python manage.py runserver 0.0.0.0:8000 --noreload
```

기본 주소는 `http://m710q.tail339927.ts.net:8000/` 또는 `http://100.98.176.40:8000/`이다. 같은 Tailscale 네트워크에서 접속한다.

- `/`: 작업 현황
- `/gis/terrain/`: 도성대지도·현재 지형 TPS 편집
- `/gis/terrain/3d/`: 도성 전체 3D 지형·원도 탐색
- `/gis/georeferenced/1908_join/index.html`: 1908 도엽 연결
- `/gis/georeferenced/readings/index.html`: 1908 판독·1912 가설 겹침
- `/gis/georeferenced/review/index.html`: 원본 선택·대응점 CSV 검토

현재는 Django 개발 서버이며 재부팅 후 수동 실행이 필요하다. 배경 타일은 브라우저가 외부 서비스에 요청한다. 대응점 CSV·TPS JSON을 브라우저에서 저장해도 서버 원본에 자동 반영되지 않는다.

## 원본과 결과 보존

카탈로그·판독 JSON·기준점 CSV·실험 기록·코드·문서는 Git 관리 대상이다. 앞선 누적 변경은 `33ffef0`으로 커밋·푸시했다. 서버 이동 시 현재 Git 상태를 확인하고 이후 미커밋 작업도 보존한다. 다음은 Git 제외 대상이며 따로 복사하거나 재생성해야 한다.

- `data/maps/`: 도성대지도 전체도·부분도 및 상세 페이지 기록
- `data/cadastral/`: 1908·1912 지도·도록 및 조사 스냅샷
- `data/terrain/`: 현대 참고 위치의 OSM 응답과 Terrarium 원본 고도 타일
- `gis/georeferenced/`: 파생 이미지·보고서·생성 HTML

원본 위치는 `data/catalog/assets.csv`를 기준으로 하며 복사 후 SHA-256을 대조한다. 원본이 없는 새 서버에서 카탈로그만 보고 취득 완료로 판단하지 않는다. 외부 대용량 저장소는 아직 설정하지 않았다.

1908 연결 재현은 [도엽 연결 명령](1908_sheet_join.md), 도성 배치는 [TPS 재현](doseong_terrain_overlay.md), 판독·가설 화면은 [웹서비스 안내](../webapp/README.md)를 따른다. 기존 affine 보고서는 계산 CLI가 덮어쓰지 않으므로 재실행 시 해당 문서의 출력 경로 규칙을 확인한다.

## 취득 규칙과 남은 결정

서울역사아카이브 사용자 지정값은 **개인 / 기타 / 조선시대 한양 모습 탐구**다. [다운로드 절차](archive_download.md)에 따라 정상 목적 제출 후 취득하며 재시도 때문에 목적 제출을 중복하지 않는다. 사료별 상세 설명·권리·체크섬을 보존한다. 지도 JPG의 조건을 도록 PDF에 전용하지 않으며 도록의 재이용 조건은 미확정이다.

정식 작업 CRS, 확정 역사 시점, 상세 파일럿 경계, 외부 저장소, 배포 라이선스는 후속 결정이다. 3D 렌더러는 Three.js를 사용한다. EPSG:3857은 웹 표시용이다. 과거 시점의 건수·진행 내용은 [개발 기록](../devlog/README.md)에 보존하며 현재 상태는 이 문서와 실행 계획을 기준으로 한다.

## 현재 3D 작업 (041)

주요 시설 8개와 성문 9개, 원도 옛길·성벽·서촌–청계천 수로와 다리 4개를 표시한다. 돈의문 모형과 보정점은 모두 원도 (766,1481)이며 현대 대응 위치는 유지한다. 산기슭 정합은 평지의 기존 5점 배치를 보존하고 남산·인왕산·백악에 외곽을 맞춘다. 파란 보정점 5개·산지점 3개를 표시한다.

원도에서 판독한 상류·도심 75점에 현대 OSM 하류를 추정 연결하여 중랑천 합류부와 한강 방향까지 개념 하도 보정을 확장했다. 현대 하류를 당시 유로로 확정하지 않는다. 원도 붉은 길의 색상 마스크를 별도 레이어로 추가했고, 성벽의 빈 문 자리 다섯 곳에 모형을 넣었다. 숭례문 성벽은 원도 재판독·겹침 비교 후 국부 접속 범위를 축소했다.

최신 동작·출처·재현 명령은 [옛길·하류·성문](doseong_roads_and_downstream.md), 기존 물길·다리 규칙은 [청계천](doseong_cheonggyecheon.md), 산기슭 정합은 [성벽·산지](doseong_walls_and_mountains.md)를 따른다. 012 이후 누적 구현은 미커밋 상태이므로 인계 시 Git 상태를 확인한다.

028: 길 주변 추정 주택·상가를 추가했다. 작은 단층 모형을 지형에 접지하며 밀도/표시 전환과 확대 버튼을 제공한다. 전체 한성부의 약 3만~6만 동은 호수 자료에 가정을 더한 규모 범위이며 화면의 성 안 일부 배치 동수와 구분한다. [추정 근거·재현](doseong_settlement.md)을 참고한다.

029: 주요 건물·문 17곳 위에 배경 없는 작은 3D 이름표를 추가했다. 이름 표시 전환, 높이/하도 보정 후 위치 추적을 제공한다.

030: 일반 주택·상가 바닥을 보이는 지면 최저 기준 +8 cm로 낮추고 18 cm 얇은 기단을 적용했다. 지형 표시 오프셋을 기단에 포함하지 않는다. 표시 고도 차 1.2 m 초과 건물은 숨기며, 원도 0%에서는 DEM에 밀착한다.

031: 종로·육조거리·돈의문 안쪽 세 길에 130명의 보행 모형을 추가했다. 보행 확대·표시 전환·재생/일시정지를 제공한다. 원도·DEM 표시 및 지형 보정에 맞춰 발 높이를 조정한다. 경로 재현은 scripts/people/build_walking_routes.py, 검사는 scripts/terrain/check_people_browser.py.

032: 지형→원도→주요 건물→하천·성벽·길→주택→사람 순서로 프레임을 표시한다. 하천 지형 계산은 Web Worker에서 실행하며 로딩 중에도 지형 회전이 가능하다. 캔버스 내 진행 안내와 실패 시 장면 유지·재시도를 제공한다. 검사는 scripts/terrain/check_progressive_browser.py.

033: 종로에서 시작하는 1인칭 탐색 추가. WASD/방향키 이동, 드래그 시선, Shift 빠르게, Esc 원래 시점 복귀. 눈높이 1.65 m로 지형을 따르며 터치 방향 버튼도 제공한다. 건물 충돌·교량 상판 보행은 미구현. 검사는 scripts/terrain/check_first_person_browser.py.

034: 사람 발 높이에 옛길 표시 표면을 포함하고 보행 차선·다리 흔들림 범위를 덮도록 보정. 1인칭 오른쪽 아래에 변형 원도 기반 미니맵(북쪽 고정·주변 1.8 km·현재 위치/시선), 오른쪽 위에 나침반 추가. [기록](../devlog/20260911_034_walk_ground_and_navigation.md).

035: 보행자 130명에 머리카락·두 눈·코 추가. 얼굴은 진행 방향을 따른다. [기록](../devlog/20260911_035_pedestrian_faces.md).

037: 일반 건물을 변형 지도 기준 길 가장자리 2~9 m 범위로 모으고 출입구·차양을 길 쪽으로 돌렸다. 기본 2,540동. 흙벽·목재 기둥·창살에 둥근 초가/곡선 처마 기와지붕을 추가했다. [기록](../devlog/20260911_037_street_frontage_hanok.md).
