# 다른 서버에서 이어가기

기록일: 2026-09-08. 사용자 요청에 따라 이 환경에서는 초기 정리까지만 진행하고 실제 수집·GIS·3D 작업은 다른 서버에서 이어갑니다.

## 현재 저장된 내용

- 저장소 구조, README, 기여 안내, 이슈·PR 템플릿
- 단계별 실행 계획, 범위, 데이터·시간 모델, 정합·복원·권리 관리 규칙
- 사료 후보 7건과 도성대지도 다운로드 파일 1건의 메타데이터
- 상세 페이지 원문 표를 로컬 HTML에서 JSON으로 추출하는 Python 스크립트
- 서울역사아카이브 목적 제출 및 다운로드 1건의 실제 확인 기록

GIS 데이터, 3D 모델, 뷰어, 일괄 다운로더는 아직 없습니다. 서지 후보 전체 검증도 완료하지 않았습니다. 문서·카탈로그·스크립트는 Git으로 인계합니다. 오늘 작업의 상세 기록은 [devlog](../devlog/20260908_001_project_foundation_and_archive_pilot.md)에 있습니다. 대용량 외부 저장소는 설정하지 않았습니다.

## 다음 서버의 시작 순서

1. [실행 계획](plan.md), [범위](scope.md), [자료 규칙](sources.md)을 읽습니다.
2. 아래 로컬 파일을 옮겼다면 assets.csv의 SHA-256과 대조합니다. 옮기지 않았다면 카탈로그 경로만으로 파일 확보를 판단하지 않습니다.
3. 1908·1912 지적자료의 도엽 범위를 조사하고 파일럿 경계를 확정합니다.
4. 파일럿에서 실제로 판독할 구역을 정하고, 전체 JPG가 부족하면 부분도·더 높은 해상도 원본을 조사합니다.
5. 작업 CRS와 대상 역사 시기를 확정한 후 좌표 정합과 GIS 작성으로 진행합니다.

## 다운로드에 사용할 사용자 지정값

서울역사아카이브: **개인 / 기타 / 조선시대 한양 모습 탐구**.

[다운로드 절차](archive_download.md)에 실제 전송 필드와 Referer 필요 사항을 기록했습니다. 정상 목적 제출 후 다운로드하며, 다운로드 재시도 때문에 목적 제출을 중복하지 않습니다. 다른 자료의 hidden 필드·권리 유형을 복사하지 않습니다.

상세 페이지의 유물 번호·아카이브 번호·별도 자료 번호·시기·자료출처·상세 설명도 함께 보존합니다. 원문과 연구자의 해석은 분리합니다.

## Git만으로 옮겨지지 않는 파일

다음 파일은 `.gitignore` 대상인 로컬 원본입니다. 필요하면 디렉터리째 별도로 복사합니다.

```text
data/maps/src-0001/
  asset-0001.jpg
  detail-2026-09-08.html
  detail-2026-09-08.json
```

JPG의 SHA-256은 `data/catalog/assets.csv`, HTML의 SHA-256은 상세 JSON에 있습니다. JSON 안의 경로는 저장소 루트 기준입니다. `/tmp`의 다운로드 실험 파일이나 세션 쿠키는 인계에 필요하지 않습니다.

현재 JPG는 전체 구조 참고용이며 세부 판독 적합성은 미평가입니다. 불명확한 지명·골목은 미판독으로 유지하고 필요할 때 원본을 찾습니다.

## 남은 결정

정확한 파일럿 경계, 첫 역사적 복원 시기, 작업 CRS, 도구 버전, 대용량 외부 저장소, 배포 라이선스, 뷰어 기술은 후속 단계에서 결정합니다. 초기 조사 문서에 있는 수치·연대·서비스 설명은 최신 검증 결과로 간주하지 않습니다.
