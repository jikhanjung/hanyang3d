# 시간 모델

사료의 제작 기간(`date_start`, `date_end`)과 공간 객체의 존속 기간(`valid_from`, `valid_to`)은 서로 다른 정보입니다. 1912년 지도에서 보인다는 사실만으로 1755년에도 있었다고 기록하지 않습니다.

초기 시간 해상도는 정수 연도입니다. 존속 구간은 양 끝을 포함합니다. 미상 경계는 null이며 무한히 과거·미래까지 존재했다는 의미가 아닙니다. CSV의 빈 셀이 null입니다. 어림 연대는 원문 표현을 `date_text` 또는 `chronology_note`에 보존합니다.

객체의 `temporal_status`는 `confirmed`, `estimated`, `unknown` 중 하나입니다. 구간이 추정이면 `estimated`로 표시하고 기간을 뒷받침하는 근거를 연결합니다. 지도 제작 추정 범위를 객체가 전 기간 존속했다는 뜻으로 사용하지 않습니다.

특정 연도 장면은 양쪽 경계가 알려지고 `confirmed`인 객체 중 해당 연도가 구간 안에 드는 객체를 기본으로 표시합니다. 추정·미상 객체는 별도 표시 옵션으로 제공합니다. 단일 연도의 존재 확인은 그 연도만 등록하고 전후 기간은 조사 대상으로 남깁니다.

같은 장소는 `place_id`, 시기별 형상은 별도 `feature_id`로 구분합니다. 도로 확장, 필지 분할·합병, 철거·재건은 새 버전과 이전 객체 ID로 연결합니다. 기간이 겹치는 상충 해석은 대안 관계를 기록하고 동시에 확정 장면으로 내보내지 않습니다.

초기 조사본의 1755·1780·1840·1868·1895·1908·1912는 탐색 시점 후보이며 완성된 데이터셋 목록이 아닙니다.
