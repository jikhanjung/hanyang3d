# 1907년 추가 건물 후보 — 2026-09-20 재검토

현재 seed의 74개 건물·시설(이화학당 추가 전)과 대조했다. 기존 후보 목록에서 이미 만든 손탁호텔·배재학당·돈덕전 등은 제외한다. 아래는 조사 후보이며 장면에 추가한 목록이 아니다. 좌표와 실측 치수는 아직 확정하지 않았다.

| 2 | 상동교회 / 숭례문 안 남창동 | 1901~1902년 벽돌 예배당 단계. 전덕기·청년교육·신민회 이야기를 연결 | AKS는 1901년 준공, 기존 독립기념관 자료는 1902년 이전으로 설명. 공사/이전/봉헌 차이를 확인하고 날짜를 단일 확정하지 않음. 당시 외관 사진 추가 확보 [2] |

| 4 | 영국 외교 공관 / 경운궁 북동쪽 정동 | 1891~1892년 두 공관 건물. 외교관의 업무·정동 생활 | 서울미래유산에 건립·증축 이력과 사진. 현재 외관은 참고하되 1973년 등 증축 제외. 1907년 공관의 법적 지위·명칭은 별도 확인 [5] |

| 6 | 남대문역 초기 역사 / 염천교 인근 | 1900년 경인선의 초기 역사. 철도 여행·시간표·화물·전차 환승 이야기 | 국가유산포털은 1900년 초기 역사와 1925년 재건을 구분. 도곽 포함 여부, 초기 목조 역사 사진·선로 위치부터 확보. 현재 문화역서울284의 돔 건물을 사용하지 않음 [7] |
| 7 | 함녕전과 주변 행각 / 경운궁 동쪽 | 1904년 화재 이후 중건 단계. 황궁 화재·재건과 고종의 거처 변화 | 기존 궁궐 모델을 확장하기 좋음. 경운궁중건도감의궤와 시점별 배치 대조; 1907년 내내 고종 거처였다고 단정하지 않음 [8] |

우선 세브란스병원 → 상동교회 → 보구녀관 순으로 진행하면 현재 학교·교회 중심의 근대 생활 공간에 의료와 사회운동을 더할 수 있다. 정동의 밀도가 높으므로 보구녀관은 이화학당·손탁호텔과 필지 관계를 먼저 확인한다. 이 우선순위는 제작 판단이며 역사적 중요도의 절대 순위가 아니다.

## 완성형을 보류할 건물

- **대한의원 본관**: 기관 설립은 1907년이지만 본관 공사는 1908년 5월까지 계속되었다. 1907년 11월 병실 이전을 본관 준공과 혼동하지 않는다. 재현한다면 병동/공사 중 본관을 시점에 맞춰 구분한다. [9]
- **황성기독교청년회 종로 회관**: 1907년 착공, 1908년 12월 개관. 1907년에는 옛 태화궁 구내 회관 또는 공사 현장 후보이며, 완성된 유명 회관은 제외한다. [10]
- **석조전·조선은행 본점·경성우편국의 유명 후대 청사**: 기관이 이미 존재했는지와 그 건물이 존재했는지는 별개다. 이전 건물·공사 단계·정확한 연도를 확인하기 전 추가하지 않는다.
- **대한매일신보·황성신문 사옥**: 이야기 가치는 높지만 이전이 잦아 1907년 주소와 월별 사용 상태 확인을 우선한다. 후보 조사 단계 유지.

## 러시아 공관 위치에 관한 보충
