# 1907년 이화학당 본당

- 1886년 학교 설립과 본당 건립 연대를 분리했다. 공식 캠퍼스 역사는 1897년 한옥 교사 철거·2층 붉은 벽돌 메인홀 착공을 확인한다.
- 준공은 장규식의 해설에서 1900년, 국민일보 문화유산 해설에서 1899년으로 달리 설명한다. 연대 메타데이터는 이설을 보존하고 시작 필드 1900은 보수적 경계로 사용한다. 전쟁 중 소실의 정확한 종료 연도는 확정하지 않아 null로 두었다(현재까지 존속한다는 뜻 아님).
- 모델은 2층 벽돌 학교의 **개념 표현**이다. 메인홀의 확정된 1907년 외관 사진·실측도는 확보하지 못했다. 반복 창, 현관, 지붕과 굴뚝의 형식·개수·색은 추정이며 사진 기반 복원으로 설명하지 않는다.
- 1915년 심슨홀, 1923년 프라이홀, 신촌 캠퍼스는 제외했다. 후대 학생 유관순의 재학 생활도 1907년 현재 이야기로 넣지 않았다.
- 원도 회전 적용 픽셀 `[456,2421]`: 손탁호텔 남동쪽·정동교회 서쪽, 도성 안 구획. 개별 건물 기호 확정 판독이 아니다. 크기 30×13×17m, 회전 30도 역시 추정.
- 기존 건물 클릭·이름·한영 설명·충돌·현관 접근 계단·원거리 LOD를 연결했다. 실내 관람은 포함하지 않는다.
- seed는 1907년 75개/전체189개. 운영 DB에는 다음 배포 때 기존 sync_content 절차로 신규 건물을 반영한다.
