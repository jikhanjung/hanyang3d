# 권리 관리 방침

현재 프로젝트 자체 코드·문서에 적용할 배포 라이선스는 미정입니다. 저장소 소유자의 선택 없이 MIT 또는 CC 라이선스를 부여하지 않습니다. LICENSE와 정식 CITATION.cff는 권리자·배포 정책·공식 저장소 정보가 확정될 때 추가합니다.

외부 사료, 스캔 이미지, 도록 PDF, 기존 3D 모델은 각각 이용 조건을 확인합니다. 같은 기관이나 같은 유물이라는 이유로 조건을 공유한다고 가정하지 않습니다. 공개 열람 가능 여부와 다운로드·변형·재배포 가능 여부도 구분합니다.

`assets.csv`에 라이선스 명칭, 조건 URL, 확인일, 필요한 출처 표기와 다운로드·상업 이용·변형·재배포 상태를 기록합니다. 상태는 `unknown`, `allowed`, `conditional`, `prohibited`로 표현하며 `conditional`은 조건 원문 위치와 내용을 노트에 기록합니다.

권리 미확인 asset은 공개 배포 묶음에서 제외합니다. 파생 GIS·3D 데이터도 입력 자료의 조건과 프로젝트 기여분의 배포 정책을 함께 확인합니다. 이 문서는 작업 방침이며 개별 자료에 대한 이용 허가를 의미하지 않습니다.
