# FABDEM V1.2 서울 도심 검토

2026-09-12 사전 비교 기록. 이후 전체 교체 작업은 [046 기록](../devlog/20260912_046_fabdem_and_credits.md)을 따른다.

## 자료와 방법

- [공식 데이터 소개](https://research-information.bris.ac.uk/en/datasets/fabdem-v1-2/): Copernicus DEM의 건물·수목 편향을 줄인 지면 고도 추정 자료. 1초각, CC BY-NC-SA 4.0.
- [제작 논문](https://research-information.bris.ac.uk/ws/files/314496213/Hawker_2022_Environ._Res._Lett._17_024016.pdf): 건물·숲별 random forest 보정, 병합과 함몰 보정·평활화. 수직 기준 EGM2008. 일부 건물 흔적 및 급경사 오차가 남을 수 있다. 논문의 세계 검증 정확도를 서울의 정확도로 간주하지 않는다.
- [V1.2 변경 기록](https://data.bris.ac.uk/datasets/s5hqmjcdj8yo2ibzi9b4ew3sn/FABDEM-V1-2%20Changelog.pdf): 2023년 1월 공개. 기반 Copernicus 2021_1, COG 형식, DEFLATE/PREDICTOR=2, PixelIsPoint 표기 수정.
- [원본 ZIP](https://data.bris.ac.uk/datasets/s5hqmjcdj8yo2ibzi9b4ew3sn/N30E120-N40E130_FABDEM_V1-2.zip): 641,627,921 bytes. N37E126_FABDEM_V1-2.tif의 필요한 부분만 HTTP Range로 읽었다.
- TIFF 확인: EPSG:4326, 3600×3600, Float32, NoData=-9999, 1/3600도, PixelIsPoint. 서울에서 동서 약 24.5m·남북 약 30.9m 간격. 256×256 블록 중 열 13·행 6을 사용했다. 샘플점의 반 픽셀 이동 없이 GeoTIFF tiepoint를 사용했다.
- 저장 경로: `data/terrain/fabdem-v1.2/`. 원본 압축 블록, 디코딩 배열, 헤더 태그, SHA-256·다운로드 메타데이터 및 비교 스크립트를 보존했다. 전체 TIFF/ZIP 다운로드 및 전체 멤버 CRC 검증은 수행하지 않았다. 초기 타일 전체 전송은 느려서 중단하고 부분 블록 조회로 전환했다.

기존 원도 TPS가 배치한 모전교·광통교 좌표를 기준으로 반경 150m를 15m 간격으로 317점씩 표본 추출했다. 양쪽 자료를 같은 좌표에서 bilinear 보간했다. 15m 표본 간격이 원본 해상도를 높이는 것은 아니다. 현존 교량의 측량 좌표 또는 화면 삼각형 높이 자체가 아니라 원도 변환 좌표에서의 기초 고도 비교다. 하도 절삭·원도 표시 오프셋·높이 강조를 포함하지 않았다.

## 판단과 적용 조건

현재 화면의 큰 도심 돌출부가 실제 언덕보다 고도 자료의 건물 영향 또는 기타 오차일 가능성을 뒷받침한다. 다만 기존 Mapzen과 FABDEM은 기반 자료·취득 시기·처리 방식·수직 기준이 같지 않으므로 차이 전체를 건물 높이 또는 정확도 개선량으로 해석하지 않는다. 지상 기준점과 대조하기 전까지 FABDEM을 정답 지형으로 확정하지 않는다.

도심 지형 교체 후보로 적합하다. 적용 시에는 동경 127도 동쪽 타일을 포함해 전체 표시 범위를 확보하고, 수직 기준·타일 접합·산지 형태를 점검해야 한다. 하도 수면·깊이와 다리 받침은 새로운 고도에 맞춰 다시 계산해야 한다. 약 30m 자료로 개별 하천 단면과 교량 접속부의 정확한 복원을 기대하기는 어렵다. 공개 서비스에 적용할 때에는 비영리·출처표시·동일조건변경허락 조건을 확인한다.
