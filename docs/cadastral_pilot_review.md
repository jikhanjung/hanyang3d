# 1908·1912 지적자료 확보와 파일럿 후보 검토

갱신일: 2026-09-09. 지적자료는 현재 JPG 9건·도록 PDF 1건을 확보했다(도성대지도 JPG 2건은 별도). [1908 관인방–경행방 연결](1908_sheet_join.md)은 상대 픽셀 정합을 수행했으나, **1908–1912 확정 대응점은 0개**다. 최근 두 분기점 가설은 주변 필지 대응 근거 부족으로 미채택했다. [판독·가설 검토](1908_road_drain_reading.md)를 참고한다. 아래 후보의 육안 유사성은 동일 장소의 확정 근거가 아니며, 파일럿 경계 polygon과 정식 작업 CRS도 미확정이다.

## 1908 도엽 범위

[공식 목록](https://museum.seoul.go.kr/archive/archiveNew/NR_archiveList.do?ctgryId=CTGRY790&type=C)의 3개 페이지, 29개 도엽을 [도엽 색인](../data/catalog/1908_sheet_index.csv)에 정리했다. 모든 행의 현재 위치 설명은 [공식 영인 도록](https://museum.seoul.go.kr/common/file/NR_download.do?id=b52448e6-5ed4-49db-a5ce-b7af1c2a856c)의 PDF 7쪽(인쇄 007쪽) 대조표에 근거한다. 이는 동명 수준의 범위이며 공간 경계가 아니다.

## 1912 목록의 단위와 열람 절차

종로2정목 검색의 22건은 **철 단위 결과**다. 철의 제목에 관철동·인사동 등이 함께 들어 있어도 모든 건이 그 전체를 덮는 도면은 아니다. 22철 화면에서 추출한 건 항목 1,414행을 [기록 색인](../data/catalog/1912_jongno_record_index.csv)에 보존했다. 이 수를 고유 도엽 수나 확보 이미지 수로 사용하지 않는다. 서로 다른 건이 같은 스캔을 가리키는지 별도 확인해야 한다.

- `want=1`: 철 상세와 건 목록, 건별 공공누리 표시·원문보기 링크를 제공한다.
- `want=0` 또는 빈 값: 건 상세가 표시될 수 있다. 이 화면에 원문 링크가 없다고 열람 불가로 판단하지 않는다.
- 건의 `docid`와 뷰어 `archiveEventId`를 연결한다. `mngno`는 철 관리번호로 별도 기록한다.
- 건제목 `관철동 0001`의 숫자를 지도에 인쇄된 도엽 번호로 옮기지 않는다.
- 뷰어에 실제 제공된 파일 경로와 다운로드 함수를 사용한다. 이번 3건은 TIFF의 JPG 변환 제공본이며 TIFF 원파일은 취득하지 않았다.

첫 관철동 다운로드는 `waterMarkFlag=Y`로 요청해 HTTP 200 오류 HTML을 받았다. 뷰어 HTML의 기본값 `waterMark=01`과 코드의 대응값 `N`을 확인하고, 경로를 URL 인코딩한 요청은 정상 JPEG를 반환했다. 두 조건을 함께 바꿨으므로 오류 원인을 하나로 단정하지 않는다. 오류 응답은 asset에 등록하지 않았다.

## 권리와 검증

각 지도 이미지의 상세 페이지/건 행에서 공공누리 제1유형을 확인했다. 도록 PDF의 파일별 재이용 조건은 확인하지 못해 상업적 이용·파생물·재배포를 `unknown`으로 유지한다. 다른 서울시 사이트나 개별 지도 이미지의 라이선스를 도록에 전용하지 않는다. PDF 자체는 인쇄 허용, 복사·변경·주석 비허용을 표시한다.

초기 취득 JPEG 6건은 FFmpeg 디코딩 검사를 통과했다. 2026-09-09에는 전체 카탈로그 파일 12건의 존재와 SHA-256 일치를 확인했다. 후속 1908 관인방–경행방 연결의 별도 검사점 4개 RMSE는 3.31 px이며 공통 경계의 상대 픽셀 정합에 한정한다. 현대 좌표 정확도와 시대 간 대응은 미검증이다. 현재 확보한 이미지를 최고 해상도 원본으로 간주하지 않는다.

## 세부 비교 재개 시 할 작업

현재는 [도성 전체 지도·3D 지형 개관](plan.md)을 우선한다. 아래는 지적자료 비교를 다시 진행할 때의 절차이며 당장의 선행 과제가 아니다.

1. 지명·시설·도엽 경계 등 별도 근거로 1908 경행방과 1912 후보의 중첩 구역을 좁힌다. 도로 형태만으로 미채택 가설을 반복하지 않고, 추가 취득은 필요한 도엽을 특정한 뒤 진행한다.
2. 도성대지도 전체도/부분도의 실제 겹침을 확인한다. 인사동 북쪽까지 부분도8이 덮는다고 가정하지 않는다.
3. 근거가 겹치는 작은 구역을 선정하고 대상 역사 시기·현대 기준자료·CRS를 정한다.
4. 그 뒤에 `gis/pilot_area.geojson`과 기준점·검사점 자료를 작성한다.
