# 서울역사아카이브 다운로드

2026-09-08 도성대지도 한 건에서 목적 제출 및 다운로드를 확인했습니다. 범용 다운로드 스크립트와 일괄 수집은 아직 구현하지 않았습니다.

## 프로젝트 기본 입력값

사용자가 지정한 값은 다음과 같습니다. 이 프로젝트의 후속 서울역사아카이브 다운로드에 사용합니다.

| 입력 | 화면 값 | 전송 필드·값 |
|---|---|---|
| 구분 | 개인 | `kGubun=1` |
| 사용목적 | 기타 | `kSubject=U99` |
| 상세목적 | 조선시대 한양 모습 탐구 | `kDescr=조선시대 한양 모습 탐구` |

## 확인한 절차

1. 해당 상세 페이지를 읽고 `koglForm`의 hidden 필드와 개별 이용 조건을 확인합니다. 사료 ID·제목·공공누리 유형을 다른 자료에서 복사하지 않습니다.
2. 동일 세션에서 hidden 필드와 위 입력값, 빈 개인용 `kName`, `kPname`을 폼 action인 `AR_arcvKoglAction.do`에 POST합니다.
3. 제출 응답이 정상인지 확인한 다음 `downform` action과 파일 식별자로 GET 요청합니다. 상세 페이지 URL을 Referer로 전달합니다.
4. HTTP 상태뿐 아니라 Content-Type, 파일 시그니처와 실제 파일 유효성을 확인합니다. HTTP 200이어도 오류 HTML일 수 있습니다.
5. 원본 보관 경로와 checksum, 해상도, 크기, 권리 상태를 assets 카탈로그에 기록합니다.

다운로드만 재시도할 때는 성공한 목적 제출을 중복하지 않습니다. 도성대지도 샘플은 2,836,782 bytes의 JPEG이며 자세한 기록은 [사료 노트](../references/source_notes/src-0001.md)에 있습니다. 세션 쿠키는 Git에 저장하지 않습니다.
