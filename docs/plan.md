- 사실적 건물 모형 4단계 완료: 궁궐 정전, 성문·궁문, 관청 구역(관아 배치), 주택·시전. 먼 거리 단순 모형(LoD)과 이름 중요도별 표시 거리.
- 사람: 걷는 사람, 경비병(궁문 4곳·도성 문 3곳), 경복궁 궁감, 훈련원 훈련 군사. 1인칭 걷기(충돌, 클릭 선택).
- 함께 걷기: 별도 Colyseus 서버로 접속자 이름·위치와 보행자 130명의 이동·회피를 공유. ‘1인칭’으로 진입하며 중복 이름 검사·옷 색깔·문자 채팅, 마지막 위치 복원·NPC 무작위 시작을 제공. [실행 방법과 제한](../multiplayer/README.md). v0.2.4 운영 배포 완료.
- 출처를 확인한 장소 이야기 33개(`gis/stories/doseong_stories.json`), 건물 안내 페이지 `/guide/`.
- 운영: dolfinid, 웹·멀티플레이 Docker 이미지 v0.2.4. 1908–1912 지적도 연결은 보존만 한다.

## 해석과 후속 결정

화면은 도성대지도의 공간 구성을 1750년 무렵 기준으로 보여 주는 개관이다. 도로 폭·필지 면적·정확한 거리·건물의 실측 형태를 보증하지 않는다. TPS로 화면을 맞춘 정도와 역사적 동일성 검증은 구분한다. 건물은 원도·부분도에 그려진 자리와 문헌 위치를 근거로 두고, 형태는 기록된 칸수·지붕 형식을 따른 개념 모형으로 표시한다.

정식 GIS 작업 CRS, 상세 파일럿 경계, 외부 원본 저장소, 배포 라이선스는 미정이다. 3D 렌더러는 Three.js를 쓰며, 표시 기준 연도는 1750년 무렵이다. EPSG:3857은 현재 웹 표시용이다. 1908·1912 자료와 도성대지도를 단일 시점의 확정 장면으로 합치지 않는다.

실행 의존성은 `requirements.txt`의 Django·NumPy·Pillow, 브라우저 검증은 `requirements-dev.txt`로 관리한다. DB는 사용하지 않는다. QGIS/GeoPackage·Blender는 후속 작업 후보이며 현재 구현 완료로 간주하지 않는다. 서비스 실행과 원본 인계는 [인계 문서](handoff.md)를 따른다.
