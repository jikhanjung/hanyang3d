# 실행 계획

작성일: 2026-09-08. 아래 계획은 초기 조사 문서를 실행 가능한 순서로 정리한 제안입니다. 담당 인원과 자료 접근성이 정해지지 않아 날짜보다 완료 조건을 기준으로 진행합니다.

## 목표와 우선순위

첫 목표는 **작은 구역에서 원사료 → 좌표 정합 → 시간별 GIS → 근거가 연결된 3D**를 한 번 완주하는 것입니다. 기관 전체 수집과 대규모 자동화는 이 과정이 검증된 다음 확장합니다.

| 단계 | 작업과 산출물 | 완료 기준 | 선행 조건 |
|---|---|---|---|
| P0 기반 정리 | 문서, 디렉터리, 카탈로그, 협업 템플릿 | 기본 파일과 규약을 검토할 수 있음 | 없음 |
| P1 자료·범위 확정 | 우선 7개 자료 조사, 파일별 권리 기록, 도엽 coverage, 파일럿 경계 | 작은 구역을 덮는 지적자료와 독립 비교 사료 확보, 취득 가능한 파일·결손·권리 상태 기록 | P0 |
| P2 좌표 기반 | 현대 기준자료, 지적도 정합, 기준점·검사점, 정합 보고서 | CRS와 변환 이력 명시, 독립 검사점 오차와 허용 기준 기록, 구역별 사용 가능성 판단 | P1 |
| P3 시간별 GIS | 도로·수계·필지·대표 건물, 출처 연결, 변경 이력 | 선택 구역의 대상 객체 작성, 참조 누락·잘못된 기간·유효하지 않은 geometry 없음, 미상 영역 표시 | P2 |
| P4 최소 3D | 근거가 충분한 대표 건물 1개, 주변 단순 매스, 모델 manifest | GIS 위치 일치, 높이·외형 근거와 추정 구분, 재생성 절차 기록 | P3 |
| P5 탐색·공개 준비 | 시점 전환과 객체 근거 조회의 최소 뷰어, 배포 묶음 | 시기가 다른 객체 혼합 방지, 출처·추정 표시, 공개 허용 파일만 포함 | P4 |
| P6 확장 | 도성 내부, 추가 시기, 일반 민가 생성, 수집 자동화 | 파일럿 품질 기준을 확장 구역에서도 충족 | P5 |

P0의 저장소 골격은 이번 초기화에 포함됩니다. P1 이후의 자료 수집·분석·개발은 아직 수행하지 않았습니다.

## 다음 작업 목록: P1

- [ ] 도성대지도 전체도·부분도의 실제 파일 제공 범위와 해상도를 확인한다.
- [ ] 1908 한성부지적도 도엽별 범위를 작성한다.

- [ ] 북궐도형·동궐도형은 원사료 공개처와 권리를 조사하되 파일럿 밖이면 모델링을 후순위로 둔다.
- [ ] 개별 asset의 이용 조건, 취득일, checksum, 로컬 경로를 기록한다.

- [ ] 첫 역사적 대상 시기와 1908·1912 비교 레이어를 구분해 확정한다.

## P2 이후의 개발 작업

우선 카탈로그 필수값·ID 중복·외래키·체크섬 검증부터 구현합니다. 실제 파일 몇 개의 수집 절차를 확인한 뒤 다운로드 재시도와 중복 방지를 자동화합니다. 이어서 공간 데이터의 geometry·시간·근거 참조 검증, 내보내기, 3D 생성을 순차 구현합니다. OCR·지도 분할·민가 자동 생성은 수작업 검토 표본이 마련된 뒤 평가합니다.

기본 작업 도구는 CSV와 Python 스크립트, GIS 편집은 QGIS/GeoPackage, 모델링은 Blender를 사용하는 방향입니다. 설치 버전과 의존성은 첫 실행 파이프라인을 만들 때 고정합니다. DB 서버, 웹 프레임워크, 렌더러는 데이터 크기와 뷰어 요구가 드러난 뒤 결정합니다.

## 진행을 바꿀 조건

| 문제 | 대응 |
|---|---|
| 핵심 원본 접근 또는 파생물 공개가 어려움 | 상태와 문의 결과 기록, 대체 사료·다른 소구역 검토 |
| 고지도 정합 오차가 용도에 비해 큼 | 상대 위치 해석으로 제한하고 정밀 footprint 근거에서 제외 |
| 1908·1912 자료가 역사 시점과 연결되지 않음 | 후대 비교 레이어로 유지하고 소급 복원을 미상으로 남김 |
| 일반 건축물 높이 근거가 부족함 | 별도 추정 매스로 표시하고 대표 건물 위주로 진행 |

각 단계 종료 시 산출물 경로, 검증 결과, 미해결 질문, 다음 단계 진행 판단을 이슈 또는 PR에 기록합니다. 공개 여부와 배포 라이선스는 P5 전에 결정합니다.


## 자료 확보 후 판독 품질 확인

도성대지도 전체 JPG 1건은 로컬 취득했습니다. 전체 구도 참고용으로 두고, 파일럿의 지명·도로·수계 판독에 필요한 해상도는 별도로 점검합니다. 부족한 구역은 부분도와 원소장처 고해상도 원본을 후속 조사하며 불명확한 부분을 임의로 확정하지 않습니다. 자료 확보 완료와 정밀 판독 가능 상태를 분리해 진행 상황을 기록합니다.
