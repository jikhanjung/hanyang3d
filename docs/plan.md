# 실행 계획

갱신일: 2026-09-09. 사용자 요청에 따라 **도성대지도 중심으로 한양 도성 전체의 대략적인 공간 구조를 먼저 보여 주는 것**을 우선한다. [범위](scope.md)와 [우선순위 변경 결정](decisions/0002-citywide-map-first.md)을 함께 따른다.

## 현재 상태

- 사료 17건, 파일 12개(JPG 11개·PDF 1개)를 등록했고 파일 존재와 SHA-256을 확인했다.
- Django 웹서비스와 Tailscale 접속, 도성 전도·현재 지형의 TPS 편집 화면을 구현했다. 기본 후보점은 5개다. 사용자는 사대문 안에서 비교적 정확하다고 확인했으므로 이 배치를 개관용 기준으로 이어간다. 독립 검사에 의한 측량 정확도는 미검증이다.
- 1908 관인방–경행방 상대 픽셀 연결은 기준점 5개·검사점 4개, 검사 RMSE 3.31 px다. 도로 3개·하수구 2개를 이미지 좌표로 판독했다.
- 1908–1912 확정 대응점은 0개다. 두 분기점 가설은 주변 필지 대응 근거 부족으로 미채택했다. 이 세부 실험은 보존하고 당장 확장하지 않는다.
- 도성대지도를 고도 데이터 위에 입힌 [3D 지형 화면](doseong_terrain3d.md)을 구현했다. 도성 전체 도로·하천 벡터, 검증된 지리 정합, 역사 지형·건물 모델은 아직 없다.

## 우선 작업 순서

| 단계 | 작업과 산출물 | 완료 기준 |
|---|---|---|
| 1 전체 배치 | 도성대지도 전체도와 현재 지형의 대응점·TPS 배치 검토 | 도성 전체를 한 화면에서 비교하고 사용한 점·변형·미확정 구간을 확인할 수 있음 |
| 2 3D 지형 개관 | 고도 데이터로 지형을 구성하고 도성대지도를 표면에 배치 | 도성 전체와 주변 산세를 기울임·회전·확대로 살피고 원도 투명도를 조절함 |
| 3 주요 공간 구조 | 성곽·성문·주요 길·청계천과 주요 지류의 원도 판독 | 원본 좌표와 출처를 보존한 주요 선·점이 연결되고 불명확한 구간을 표시함 |
| 4 전체 개관 화면 | 판독선을 전체 지도 위에 표시하고 원도·현대 배경과 비교 | 도성 안의 주요 길과 물길 구조를 탐색하고 배치 기록을 재현할 수 있음 |
| 5 선택 구역 보완 | 판독이 부족한 곳의 부분도·별도 사료 대조 | 필요한 구간의 근거와 불확실성을 갱신함 |
| 6 건물 확장 | 별도 근거가 있는 대표 건물과 지형·주변 공간 | 위치·외형 근거와 추정을 구분한 모델 및 탐색 화면을 제공함 |

1단계의 도구는 구현되어 있으나 전체 배치 검토는 남아 있다. 2단계의 3D 지형 화면은 구현·브라우저 검증을 마쳤고 사용자 검토를 기다린다. 도성 전체 판독은 순차 추가한다. 평면 OSM/OpenTopoMap 배경 타일과 지형의 높이를 만드는 고도 데이터는 구분하여 준비한다. 1908–1912 지적도 연결은 전체 개관의 선행 완료 조건으로 두지 않는다.

## 해석과 후속 결정

첫 결과는 도성대지도의 공간 구성을 대략 파악하는 개관이다. 도로 폭·필지 면적·정확한 거리·특정 연도의 건물 복원을 보증하지 않는다. TPS로 화면을 맞춘 정도와 역사적 동일성 검증은 구분한다. 건물의 위치·형태·높이는 별도 사료를 확보한 뒤 추가한다.

정식 GIS 작업 CRS, 정확한 역사적 대상 시기, 상세 파일럿 경계, 외부 원본 저장소, 배포 라이선스와 3D 렌더러는 미정이다. EPSG:3857은 현재 웹 표시용이다. 1908·1912 자료와 도성대지도를 단일 시점의 확정 장면으로 합치지 않는다.

실행 의존성은 `requirements.txt`의 Django·NumPy·Pillow, 브라우저 검증은 `requirements-dev.txt`로 관리한다. DB는 사용하지 않는다. QGIS/GeoPackage·Blender는 후속 작업 후보이며 현재 구현 완료로 간주하지 않는다. 서비스 실행과 원본 인계는 [인계 문서](handoff.md)를 따른다.
