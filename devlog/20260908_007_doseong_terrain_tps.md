# 007 — 도성 전도·현재 지형 오버레이와 TPS

도성 전도의 현대 지형 오버레이 요청에 따라 Django `/gis/terrain/`을 추가했다. 이어 사용자가 제안한 TPS와 광화문·광화문사거리 대응점을 반영했다. 기본 3점 affine과 후보점 5점 TPS를 전환하고, 점 드래그·추가·삭제·격자·전체 조절·JSON 저장·불러오기를 지원한다.

광화문사거리의 현대 참고 위치는 OSM 차로 결절점 4개의 평균으로 기록했다. 원도 후보 픽셀과 현대 좌표 출처는 실험 JSON에 보존했다. 기본 TPS에서 사거리 서쪽 후보점 사이 직선은 최초 배치의 82.1%, 동쪽은 106.8%다. 실제 역사적 도로 길이를 뜻하지 않는다.

초기 TPS의 Leaflet 좌표 인수 형식 오류로 원도 로딩이 중단됐다. 사용자 보고에 맞춰 수정하고 실제 Chromium에서 원도 표시·점 편집·저장·재로드를 재검증했다. Django 테스트 6개 및 TPS 수치·입력 검증이 통과했다. 기본 표본 격자 접힘은 없었으나 독립 검사점은 0개다.

[사용법·근거·재현·제한](../docs/doseong_terrain_overlay.md)에 상세 내용을 기록했다. 배경 타일은 외부 서비스에서 브라우저가 요청하며, 화면 편집은 원본과 서버 기준점 기록을 바꾸지 않는다.
