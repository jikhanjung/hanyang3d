# 공통 UI 숨김과 PNG 스크린샷

- 1750·1907 공통 `screenshot_mode.js`를 연결하고 공개 리소스 목록에 등록.
- Alt+Z: 제목·설정·나침반·채팅·봇짐·액션바·미니맵·대화·이름표 숨김/복원. 패널 열림 상태와 체크박스 값 자체는 유지.
- Alt+P 또는 설정 메뉴 ‘스크린샷 저장’: 3D 장면만 PNG 다운로드. DOM UI뿐 아니라 1750 지명·건물 이름과 플레이어 머리 위 이름도 촬영에서 제외. 실제 약전 간판은 유지.
- 렌더링 직후 같은 작업에서 toBlob으로 읽어 preserveDrawingBuffer 없이 저장. 이름표 가시성은 렌더링 동안만 임시 변경 후 복원.
- Esc로 숨김 해제. 모바일에서는 두 손가락 터치로 복원. 채팅·입력란 편집 중 Alt 단축키 무시. 걷기 상태를 초기화하지 않는다.
- 1907 원본 평면 지도 모드에서 PNG 버튼을 누르면 3D로 전환하도록 안내. UI 숨김은 평면 지도도 유지하며 Leaflet 컨트롤만 숨긴다.
- 한·영 메뉴 제공. 브라우저 검사에서 UI·기존 숨긴 패널 복원, 타이핑 보호, 터치 복원, 3D 이름표 렌더 제외, 실제 800×600 비어 있지 않은 PNG 다운로드 확인.
- 운영 미배포. 일반 동작은 두 시대 장면 로드 검사와 함께 확인.
