# 015: 건물 박스의 개략 규모 조정

- 사용자 요청에 따라 대형 위치 기호를 대표 건물 한 동 규모의 박스로 축소했다.
- 궁궐 전각·성문·관청·상점별 치수를 다르게 설정하고, 종묘는 긴 평면, 사직단은 낮은 제단 규모를 적용했다.
- 미터 치수는 사직단 제단 참고값을 제외하면 모델링 가정이다. 데이터에 규모 상태·근거를 기록하고 클릭 설명에 치수를 표시한다.
- 위치와 TPS를 유지하고 원도 위 표시 오프셋을 4.5 m로 낮췄다. 작은 박스의 선택 보조 범위를 추가했으며 시각적 크기는 확대하지 않는다.
- Django 7개 검사 통과. Tailscale Chromium에서 12개 박스 모두 축소 후 이름 표시·클릭·높이 조절·모바일 가로폭 검사 통과, JavaScript 오류 없음.
