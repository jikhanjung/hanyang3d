# 204 — 전체 지도·하도 보행·건물 관리인

1750년과 1907년의 공통 1인칭 모듈에 M 키 전체 지도를 추가했다. 기존 미니맵과 동일한 보정 원도를 북쪽이 위로 오도록 사용하며, 창의 92% 영역에 표시한다. 1907년은 원도 바깥 DEM 여백을 제외해 확대한다. 1인칭에서는 발 위치의 X/Z와 시선 방향, 일반 지도에서는 현재 시점 중심을 표시한다. M/Esc/닫기 버튼으로 닫는다. 입력창·한글 조합 중에는 단축키를 무시하고, 지도 안에서 Tab 포커스를 유지한다.

1907년 청계천에서는 물 표면과 지면이 거의 겹쳐 사람이 물 위를 걷던 상태를 고쳤다. 원도 물길 주변만 지형 삼각형을 세분화하고 개념적인 약 2m 하도를 만든다. 실제 1907년 수심을 측량했다는 뜻은 아니다. 옛지도·지형·보행 높이는 같은 삼각형을 사용하고 수면은 기존 높이를 유지한다. 다리는 상판을 걸을 수 있으며 하도 쪽으로 진입한 사람은 다리 아래 지면을 사용한다.

단성사 문지기와 궁궐·종묘·환구단·성당·교회·성균관·북묘·전기회사·차고의 관리인, 합계 13명을 추가했다. 단성사 이야기는 네 부분으로 구성하고 각 대화에 출처를 연결했다. 인물은 창작이며 배치와 복식은 추정이다. 기존 회동서관 이야기꾼은 유지한다. PC의 봇짐 `쓰기` 버튼은 숨기고 모바일·터치 환경에서는 유지한다.

검증:

- 실제 브라우저: 물길 62개 지점에서 발 높이가 지형과 일치하고 수면 아래인지 확인, 다리 7개 상판/하부 높이 확인.
- 관리인 13명 위치가 충돌 영역 바깥인지 확인, 단성사 4부분 대화 및 출처 링크 확인.
- 두 시대 M 지도, 1907년 현재 위치 마커, 입력 중 M 무시, Tab 포커스, 닫을 때 1인칭 유지, PC/모바일 봇짐 버튼 확인.
- Django 장면 데이터·1907·번역 테스트 21개 통과. 이전 메뉴 변경의 `1인칭 시점` 문구에 번역 테스트 기대값도 맞춤.
- 시험 DB에서 인물 갱신 번들 dry-run이 데이터를 보존하고 실제 적용 결과가 새 seed와 일치함을 확인.

운영 반영 전이다. 새 코드 배포와 함께 `gis/updates/1907_caretakers.json`을 `update_data.sh`로 적용해야 기존 운영 DB에도 인물이 추가된다. `seed_scene_data`는 기존 값을 덮어쓰지 않는다. 운영 해시가 달라졌으면 충돌을 무시하지 말고 최신 데이터를 export하여 병합한다.
