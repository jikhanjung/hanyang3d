# 055 — 지역·시설 위치 보정과 황토색 지면·암반 수목

사용자 지적에 따라 서촌 이름을 경복궁 서쪽 담장과 청계천 상류 사이로 옮겼다. 이전 위경도 `(126.969, 37.5805)`는 개략 배치였으며 당시 서촌의 중심을 고증한 점이 아니었다. 현대 좌표를 그대로 표시하여 변형된 원도의 경복궁·물길과 관계가 어긋나 보이는 문제가 있었다.

새 표기는 도성대지도 원도 좌표 `(1042, 1085)`에 두고 궁궐·물길과 같은 TPS 변환을 적용한다. 같은 높이의 물길은 약 x=1006, 경복궁 서쪽 담장은 약 x=1078이므로 그 사이에 놓인다. 지역 이름을 알아보기 위한 표시 위치이며 역사적 중심이나 행정 경계를 뜻하지 않는다.

[서울한옥포털 경복궁 서측](https://hanok.seoul.go.kr/front/kor/town/town02.do)은 넓은 지역 범위를 경복궁에서 인왕산 기슭 사이로 설명한다. 그 범위 전체의 중심을 단정하지 않고, 이번에는 사용자가 요청한 담장 옆 주거지 쪽에 이름을 둔다.

북촌도 사용자 요청에 따라 기존 표기와 원도의 안국방 글씨 사이로 내렸다. 기존 표기의 역추정 원도 좌표는 약 `(1460,868)`, 안국방 글씨 중심은 약 `(1433,1060)`이다. 중간 위치인 `(1445,965)`에 북촌을 표시하고 같은 TPS 변환을 적용한다.

## 검증

- 원도 확대 이미지에서 안국방 글씨 위치를 확인했다.
- 브라우저의 실제 3D 좌표로 서촌이 상류 물길과 경복궁 서쪽 담장 사이에 놓이는지 확인하고, 북촌·서촌의 최종 화면을 확인했다.
- 첫 화면 저장은 시간 초과가 발생했으나, 렌더 루프를 멈춘 뒤 다시 저장하여 확인했다.
- Docker 빌드의 Django 11개 테스트, 누락/버전 불일치 차단, Gunicorn HTTP 검사 통과.

## 사직단·경덕궁 위치 추가 조정

v0.0.14 배포 후 사용자 지적으로 사직단·경덕궁도 원도의 담장 내부에 맞췄다. 사직단은 기존 원도 환산 `(798,1133)`에서 `(820,1200)`으로 남쪽, 경덕궁은 `(747,1320)`에서 `(880,1380)`으로 남동쪽 이동했다. `source_position`과 판독 원본 해시를 기록하며 기존 현대 위경도는 참고값으로 보존했다. 건물 연대 메타데이터는 유지한다. 최종 배포는 v0.0.15다.

문묘·성균관도 원도를 확대해 건물·담장 범위를 확인하고 원도 `(2010,770)`의 시설군 내부로 옮겼다. `source_position`과 원본 해시를 기록하고 연대 정보는 유지한다.

## 황토색 지면과 수목 주변 녹지

추가 요청으로 기본 지면을 황토색으로 바꾸고, 실제 배치한 나무 위치에서 부드럽게 번지는 녹지 마스크를 생성해 지면 재질에 합성했다. 나무별 24m 이상 반경을 완만하게 혼합한다. 지형 정점·물체 높이와 옛지도 투명도 처리는 바꾸지 않는다. 기존 화강암 표현은 녹지 합성 뒤에 적용하며 옛지도 이미지와 OSM 배경 자체는 착색하지 않는다.

화강암 표현과 같은 북악산·인왕산 타원 범위 및 해발 150~240m 전이를 사용해 나무 배치 확률을 조정했다. 암반 중심은 기존 후보의 25%, 가장자리는 100%로 완만히 바뀐다. 원도 픽셀 기반의 고정 난수로 재접속해도 같은 나무를 남긴다. 녹지 마스크는 솎아낸 뒤 실제 남은 수목으로 생성한다.

브라우저 추가 검증 통과: 세 시설의 실제 좌표와 원도 배치 일치 및 확대 화면 확인. 지면·녹지 셰이더 오류 없음. 실제 수목 2,349그루, 암반 확률 필터로 후보 104그루 제외, 유지 확률 50% 미만 암반 영역에도 33그루 잔존. 녹지 마스크 표본 100/100이 나무 위치와 일치하며 지도 0→50→0% 전환에서 전체 지형 정점과 건물 좌표가 유지됨을 확인했다.
