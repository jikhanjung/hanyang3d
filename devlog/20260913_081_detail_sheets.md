# 081 — 도성대지도 부분도 전체 취득

부분도11을 받아 영희전을 읽은 데 이어, 서울역사아카이브의 나머지 부분도 열 장을 모두 받았다. 이제 부분도 1~12번이 갖춰졌다.

## 취득

각 상세 페이지에서 공공누리 제1유형(출처표시)을 확인하고, 이용 목적을 개인 / 기타 / 조선시대 한양 모습 탐구로 제출한 뒤 다운로드 경로로 받았다. `src-0019`~`src-0028` / `asset-0014`~`asset-0023`으로 등록했고, 각 `references/source_notes/src-00NN.md`에 크기·SHA-256·기관 설명 요지를 적었다. 부분도 7·9번은 목록 검색에 나오지 않아 부분도 8 상세 페이지의 이전·다음 링크에서 찾았다.

## 전체 원도와의 대응

열두 장 모두 SIFT 특징점과 RANSAC 유사변환으로 전체 원도(asset-0001)에 맞췄다. 결과는 `gis/control_points/detail_sheet_fits.json`에 시트별 아핀 행렬·축척·회전·전체 원도 범위로 적었다. 부분도는 전체 원도를 가로 셋(x 약 670~1300, 1250~1880, 1830~2460)·세로 넷(y 약 500~960, 920~1360, 1340~1780, 1750~2200)으로 나눈 격자다. 부분도 8의 기존 수동 대응(축척 0.2152)과 축척이 같고, 회전은 1° 안에서 다르다.
