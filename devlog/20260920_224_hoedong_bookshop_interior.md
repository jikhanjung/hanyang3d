# 회동서관 실내와 구석의 소설 거래

요청: 서점 안으로 들어가 책장·책을 보고, 돌아다니는 주인에게 구석에서 말을 걸면 남녀상열지사 책을 살 수 있도록.

- [재현 범위·자료·배포](../docs/hoedong_bookshop_interior.md).
- `bookshop1907.js`: 빈 실내·열린 앞문·계단·책장·선장본 책 더미, 상세 LOD, 벽/책장 충돌, 실내 판정과 카메라 장애물.
- `people1907.js`: 데이터 wander 플래그와 모델 동선으로 주인 이동·대화 정지. `walk1907.js`: 실내·거리·구석 조건에서만 별책 선택지를 노출.
- 3종 소설과 책 아이콘, 서버 가격·봇짐 저장 재사용. `seed_books`와 아이콘 선택지 migration 준비. 기존 운영 값은 덮어쓰지 않는다.
- 성당과 서점의 미배포 인물 데이터를 같은 충돌 검사 번들로 묶음. v0.5.30 운영 DB에는 아직 적용하지 않음.
- PC 1280px·모바일 390px 실제 실내 진입, 책 1,170권, 주인 동선과 대화 중 정지, 구석 선택지, 춘향전 구매와 엽전 차감 검증 통과. Django 전체 81개 테스트 통과.
