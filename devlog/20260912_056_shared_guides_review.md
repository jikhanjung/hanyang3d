# 056 — 공통 가이드 연결과 적용 검토

사용자 요청으로 형제 devdocs의 가이드 인덱스, 웹 배포·운영·데이터 안전 문서와 브랜드 문서를 읽었다. 원문을 공개 저장소로 복사하지 않고 `.guides -> ../devdocs/guides` 상대 심볼릭 링크로 연결했다. `.gitignore`와 `.dockerignore`에서 제외하고 CLAUDE.md·AGENTS.md에 발견 안내를 추가했다.

프로젝트 자체의 적용 현황은 [검토 문서](../docs/guide_adoption_review.md)에 기록했다. 현재 갖춘 이미지·데이터 검증, 비루트/내부 포트/TLS, 업데이트 안내와 롤백을 확인했다. 가장 우선적인 차이는 운영 `.env` 전체 교체로 추가 설정 및 포트를 잃을 수 있다는 점이다. 공통 배포 명령, 원격 래퍼, 버전 동기화와 감시·복구 절차도 후속 검토 대상으로 정리했다.

DB·계정·사용자 업로드가 없는 현재 프로젝트에는 DB 마이그레이션·세션·SQLite 백업 규칙을 적용하지 않는다. 화면 간소화 요청에 반하는 공통 바닥글이나 근거 없는 게시자·라이선스 선언도 추가하지 않았다. 이번 범위는 연결과 적용 검토이며, 운영 정책 변경까지 구현한 것은 아니다.

검증: 상대 링크 목적지 확인, 가이드 README 읽기 가능, `git check-ignore .guides`, Docker 제외 설정, diff 검사. 원문과 심볼릭 링크는 커밋 대상이 아니다.
