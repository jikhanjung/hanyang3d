# 090 — 건물 안내 문서를 사이트 페이지로

사용자가 건물 안내 문서를 GitHub로 보내지 말고 사이트에 포함해 달라고 했다. 이전에는 About 창의 ‘건물 안내 문서’가 GitHub의 `docs/landmarks.md`로 연결됐다.

## 한 것

- `/guide/`에 건물 안내 페이지를 새로 두었다. `docs/landmarks.md`를 요청 때 HTML로 바꿔 보여 주며, 파일이 바뀌면(수정 시각 기준) 다시 만든다. 따로 옮겨 적은 사본이 없어 문서와 페이지가 어긋나지 않는다.
- Markdown 변환은 `webapp/guide.py`의 작은 변환기로 한다. 문서가 쓰는 제목·문단·목록·표·굵게·링크·코드만 다룬다. 새 파이썬 패키지는 넣지 않았다. 원문은 HTML로 이스케이프한 뒤 변환한다.
- 페이지는 출처·저작권 페이지와 같은 모양이며, 대분류(`##`) 목차가 있다. 외부 출처 링크는 새 창으로 연다. 폰 폭(390 px)에서 가로로 넘치지 않는다.
- 제목마다 건물 이름으로 `id`를 달았다. `숭례문 (남대문)` 같은 제목은 괄호 앞 이름을 쓴다. 제목이 없는 육조거리 관청은 표의 행에, `좌포도청·우포도청` 같은 묶음 제목은 이름마다 앵커를 달았다. 같은 이름이 제목과 표에 함께 있으면 제목이 앵커를 갖는다. 앵커 111개가 모두 서로 다르다.
- 지도에서 건물을 누르면 뜨는 카드에 **건물 안내에서 자세히 보기** 링크를 넣었다. `/guide/#이름`으로 새 창에서 그 건물 자리로 간다. 지도의 건물 96곳 모두 안내 문서에 자리가 있다.
- About 창의 ‘건물 안내 문서’ GitHub 링크를 사이트의 `/guide/`로 바꿨다. 출처·저작권 페이지에도 건물 안내 링크를 넣었다. 소스 코드 링크는 그대로 GitHub다.
- Docker 이미지에 `docs/landmarks.md`를 넣었다(`Dockerfile`, `.dockerignore`). 다른 문서와 devlog는 넣지 않는다.

## 검사

- `webapp/tests.py`: `/guide/`가 제목·성문·표 행 앵커를 갖고 GitHub 링크가 없음, POST 405, 홈의 About이 `/guide/`로 연결되고 앵커 목록을 내려보냄.
- 브라우저: About 링크, 우포도청·호조·종루 카드의 안내 링크가 `/guide/`의 해당 자리를 찾음.
