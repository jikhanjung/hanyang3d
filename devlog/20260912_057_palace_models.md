# 057 — 경덕궁·창덕궁·창경궁 입체 모형

사용자 요청으로 세 궁궐의 단순 상자를 기단·붉은 기둥·문살·기와지붕·계단·앞뜰·낮은 행각을 갖춘 모형으로 교체했다. 기존 대표 위치와 전체 크기를 기준으로 단순화했으며, 궁궐 전체 건물군의 실측 복원이 아니다.

창덕궁은 인정전의 중층 지붕을, 경덕궁과 창경궁은 숭정전·명정전의 단층 지붕을 참고했다. 창경궁 모형의 정면은 동쪽으로 두었다. 기존 연대 필드는 미확인 상태를 유지하며 특정 연도의 모습이라고 새로 단정하지 않는다. `display_model`, `palace_roof_tiers`, `display_yaw_deg`, `model_reference`, `model_note`에 표현의 근거와 설정을 기록했다.

참고 문헌은 현재 지도 모형에 사용하므로 출처 페이지에도 추가했다. 사진·기존 3D 자산을 재배포하지 않고 직접 코드로 제작했다.

## 구현과 검증

- `palace.js`는 77~85개 부품을 재질별 6개 메시로 합쳐 모바일 렌더링 부담을 줄인다.
- 단독 브라우저 화면에서 세 모형과 지붕 층수·범위를 확인했다.
- Django 11개 테스트 및 JS 구문 검사 통과.

실제 지도 브라우저 검사 통과: 세 상자 숨김·궁궐 모형 존재, 지붕 층수, 기둥·마당 부품, 궁궐당 6개 메시, 높이 배율 1→2→1 원위치 복귀. 세 궁궐 확대 화면도 확인했다.

## 지면색·이름 크기 추가 요청

황토색을 `#b88a4c`에서 밝고 채도가 낮은 `#c4aa7f`로 완화했다. 건물·문·산·지역 이름은 같은 nameSprite 생성 함수를 사용해 500 24px 글꼴, 36px 캔버스, 외곽선과 화면 배율을 통일했다. 산·지역 이름의 추가 1.12배 확대를 제거했다. v0.0.16 게시 진행 후 추가 요청이므로 최종 릴리스는 v0.0.17이다.

최종 브라우저 확인: 모든 지도 이름이 동일한 500 24px 글꼴·36px 캔버스·화면 배율을 사용한다. 지도 0%의 연한 황토색 화면을 확인했으며 v0.0.17 컨테이너 검사와 Django 11개 테스트가 통과했다.
