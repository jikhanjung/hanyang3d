# 045 — 지도 첫 화면의 조작 패널과 물길 범위

2026-09-12. 전체 화면 3D를 유지하면서 보정점 기본 해제, 옛지도 50%와 슬라이더, 1인칭 걷기 버튼, 기존 초기화면 링크를 요청받았다. 청계천은 처음 표시했던 흥인지문 근처의 원도 판독 구간까지만 보이도록 요청받았다.

## 변경

첫 화면 상단에 작은 조작 패널을 추가했다. 옛지도 불투명도는 50%, 보정점은 기본 해제다. 슬라이더·보정점·1인칭 버튼은 기존 뷰어 로직에 연결하고, 기존 초기화면 링크는 작업 현황 `/gis/`로 이동한다. 동일한 컨트롤 템플릿을 일반 뷰와 전체 화면에서 공유해 중복 ID 없이 동작한다. 모바일에서는 컨트롤이 줄바꿈된다.

청계천의 기존 원도 판독선과 다리는 유지하고, 이후 추가한 현대 하류·중랑천 수면을 제거했다. 하천 주변 지형 보정과 시설 배치에 전달하는 하도 경로도 원도 구간으로 맞췄다. 하류 확대 버튼과 더 이상 표시하지 않는 중랑천 설명을 제거했다. 원본 데이터의 하류 판독 자료는 보존한다.
