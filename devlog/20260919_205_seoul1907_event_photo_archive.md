# 205 — 1907년 전후 사건과 사진 연구 자료

기존 장소 이야기 24편을 보존하면서 대한제국 선포, 1904년 군사적 압박·경운궁 화재, 통감부 설치, 단성사 개관, 1908년 서울 진공 작전, 1910년 강제 병합을 추가했다. 총 31개 사건·생활사 항목이며 1907년 11월 이후 사건은 미래로 표시한다. 장소·시기 정밀도·출처·주의점·기존 건물 연결을 JSON과 읽을 수 있는 자료집에 함께 보관한다. 운영 이야기 DB에 자동 등록하지 않는다.

사진은 LOC 공식 공개 데이터셋에서 서울·1904년 레코드 94건을 추출하고 Cornell 8건, 국립고궁박물관 1건을 더해 103개 소장품 목록을 만들었다. 서로 다른 촬영 장면 103개를 뜻하지 않는다. 원제·소장기관·목록 연도·촬영일 미확정·중복 후보·사건 연결 관계·권리 검토 상태를 CSV/JSON에 기록했다.

LOC의 거리·전차·상점·가마·행렬·도시 전경 등 6점은 공개 JPEG를 한 파일씩 받아 이미지 디코딩·크기·SHA-256을 확인했다. `data/photos/seoul1907/` 아래에 이미지·선별 원메타데이터·로컬 HTML 인덱스를 둔다. 개별 웹 카탈로그가 403을 반환하는 경우 접근 제어를 우회하지 않고 기관이 별도 공개한 LC Labs 데이터셋을 사용했다. 전체 메타데이터는 임시 다운로드 뒤 필요한 레코드만 보관한다.

1904년이라는 목록 날짜를 촬영일이나 1907년 사건 날짜로 바꾸지 않는다. 같은 장면의 복제본 가능성, Cornell 궁궐 식별 충돌, 추정 화재 사진, 엽서 채색을 명시한다. 원본 권리와 출처를 추가 확인한 뒤 서비스 자산으로 적용한다.
