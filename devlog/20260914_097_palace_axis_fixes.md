# 097 — 경복궁 중심축 전각 터, 연못 이동, 전각 이름표 수정

사용자 지적 셋을 반영했다.

- **전각 이름표가 안 보임**: 인정전·명정전 이름표가 궁 이름표(한 줄 위)와 화면에서 0.4 px 겹쳐 겹침 가리기에 숨겨졌다. 같은 건물의 이름표끼리는 서로 가리지 않게 했다. 근정전 터 이름표는 보였다.
- **경회루 연못**: 실제 연못은 경복궁 서쪽 담장에 붙어 있다. 그림보다 서쪽 담장 안쪽(원도 1092, 1000)으로 옮기고, 실제보다 좁게 그려진 담장에 맞춰 절반 크기(64 × 57 m)로 표시한다. 누각 터·섬·다리도 같은 비율로 줄였다.
- **근정전 북쪽 전각**: 중심축을 따라 사정전(편전)·강녕전(임금 침전)·교태전(왕비 침전) 터를 기단 한 단과 주춧돌 모형(`hall_site`, 칸수는 기록값)으로 두었다. 근정전 북쪽의 실제 간격을 원도 담장 남북 축척(약 0.67)으로 줄여 배치했다. 출처는 위키백과 각 항목.
