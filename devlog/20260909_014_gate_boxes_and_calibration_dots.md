# 014: 성문 박스와 보정점 표시

- 사용자 요청대로 광화문·흥인지문·숭례문·돈의문 박스를 추가했다. 시설 박스는 총 12개다.
- 기존 보정점의 상시 텍스트를 파란 점 5개로 교체했다. 네 성문 박스와 해당 점의 수평 좌표는 동일하며 TPS는 수정하지 않았다.
- 성문도 hover·클릭 시 이름과 설명을 제공한다. 광화문은 당시 문루가 아닌 위치 표시임을 설명에 기록했다.
- Django 7개 검사 통과. Tailscale Chromium에서 12개 박스의 hover·클릭, 보정점 5개·표시 전환·성문 좌표 일치, 높이 변경과 모바일 가로폭 검사를 통과했다.
