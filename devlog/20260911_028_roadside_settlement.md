# 028 — 길 주변 주택·상가 추정 배치

2026-09-11. 사용자가 요청한 18세기 한양의 주택·상가 개관을 위해 일반 건물을 도성 안 길 주변에 배치했다.

## 근거와 범위

1780년 한성부의 38,742호·201,070명(한국민족문화대백과사전)을 참고했다. 성 밖을 포함한 등록 호수와 건물 동수를 구분하고, 호당 0.8~1.5동을 가정한 약 3만~6만 동을 전체 한성부의 규모 범위로 설명했다. 역사적 동수 통계나 신뢰구간으로 제시하지 않는다. 1750년 전후 지도와의 시기 차이도 표시했다.

화면에는 성 안에서 원도 길 주변의 일부만 배치한다. 작은 단층 주택과 상가 지붕·차양을 만들고, 종로 주변에 상가 후보를 늘렸다. 개별 건물·필지·상호를 확인한 배치가 아니다.

## 구현

- 시드 1750, 원도·길 마스크 SHA-256과 가정·출처를 JSON에 보존.
- 원도 길의 국부 방향을 읽어 지붕 축을 회전. 성벽 안쪽·길에서 일정 거리 떨어진 후보 사용.
- 궁궐·종묘·사직·문묘·육조거리 제외 영역, 성벽·문·물길 이격, 주요 시설과 건물끼리 간격 적용.
- 현대 고도와 경사, 실제 표시 지형의 회전 바닥 범위로 후보를 걸러내고 받침 계산.
- 네 개 InstancedMesh로 반복 건물 표현. 기와색·초가색은 표시 밀도와 독립적으로 섞음.
- 추정 주택·상가 전환, 성김/보통/촘촘함, 주택·상가 확대 버튼, 현재 표시 동수와 추정 설명.

최종 기본 표시량은 14,431동(주택 14,009·상가 422)이며, 궁궐 여유폭 반영 후 원도 후보 23,225개에서 지형·충돌 필터를 거쳤다.

## 검증

Django 리소스 제공 검사, 후보의 도성 내부·제외 영역 검사, SHA-256·크기 검사와 Chromium 화면 검사를 사용한다. 브라우저에서 표시량·물길 이격·밀도/표시 전환·높이 강조 2배·하도 보정 전후 건물 접지를 확인한다.

초기 화면 검사에서 원도와 DEM의 표시 오프셋 4 m를 실제 경사로 잘못 간주해 대부분의 건물이 숨겨지는 것을 발견했다. 두 표면을 포함한 높이 범위 기준을 7.5 m로 고쳐 개략 경사 3.5 m와 표시 오프셋을 구분했다. 궁궐 경계의 픽셀 반올림 후보는 경계 여유폭을 추가해 제외했다.

현재 규칙·한계·재현 명령은 [주택·상가 문서](../docs/doseong_settlement.md)에 기록한다.
