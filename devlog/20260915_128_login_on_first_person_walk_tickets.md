# 128 — 1인칭에 들어갈 때만 로그인, 계정 이름으로 함께 걷기

사용자 요청: 1인칭으로 들어갈 때만 로그인하게. 함께 걷기도 계정 이름으로 묶기.

## 로그인 시점

- 지도만 볼 때는 로그인하지 않는다. 엽전 표시(`#money-hud`)는 로그인 전에는 숨긴다(127의 ‘로그인’ 버튼 제거).
- ‘1인칭’을 누르면(`firstPerson.enter`) 로그인이 안 되어 있을 때 ‘한양 나그네 명부’가 뜬다. 들어가거나 이름을 정하면 바로 1인칭으로 들어가고, 닫으면 지도 시점에 남는다. `shop.requireLogin()`이 로그인한 이름(닫으면 `null`)을 돌려준다.
- 127의 걷기 이름 입력창과 localStorage 이름은 없앴다. 걷기 이름은 계정 이름이다. 걷던 위치는 전처럼 브라우저에 계정 이름별로 기억한다.
- 로그인 전에 상인의 ‘거래하기’를 고르면 가게가 구경 모드로 열린다. 물건을 누르면 “1인칭으로 들어갈 때 이름을 대면 사고팔 수 있소”라고 알린다.
- ‘나가기’(로그아웃)를 누르면 1인칭에서도 나온다.
- 좁은 화면에서는 엽전 표시가 조이스틱 아래쪽을 덮어 뒤로 걷기(S) 터치를 가로챘다. 모바일 걷기 검사에서 찾았고, 표시를 조이스틱 위로 옮겼다. 127까지는 로그인 전에도 ‘로그인’ 버튼이 같은 자리에 있었으므로 그때부터의 문제다.

## 함께 걷기 입장권

- `GET /api/walk-ticket`: 로그인한 계정의 이름과 60초 만료 시각을 `HMAC-SHA256`으로 서명한 입장권을 준다(`webapp/walk_ticket.py`). 로그인하지 않았으면 401.
- Colyseus `readJoinOptions`: `WALK_TICKET_SECRET`이 있으면 이름을 입장권에서만 가져온다. 서명이 틀리거나 만료됐으면 403. 클라이언트가 보낸 `name`은 무시한다. 비밀값이 없으면(로컬 개발) 전처럼 `name`을 쓴다.
- 운영 compose: 웹은 `HANYANG_WALK_TICKET_SECRET`, 멀티플레이어는 `WALK_TICKET_SECRET`으로 같은 값을 받는다. 멀티플레이어는 값이 없으면 시작하지 않는다(`:?`). `deploy.sh`는 서버 `.env`에 값이 없으면 `openssl rand -hex 32`로 만들어 넣는다(권한 077은 하위 셸에만 적용, 출력하지 않음). 배포가 실패해 이전 릴리스로 되돌려도 이 값은 남긴다. 되돌린 멀티플레이어 서비스도 필요로 하기 때문이다. `deploy/test_release_env.py`는 원래 설정은 그대로 두고 비밀값 한 줄만 더해졌는지 확인한다.
- 같은 계정이 이미 함께 걷는 중이면(4003) 이름을 다시 묻지 않는다. 대신 다른 창을 닫고 다시 들어오라고 알린다. 계정 이름은 바꿀 수 없기 때문이다.
- 함께 걷기 서버에 접속하지 못해도 이제 1인칭은 유지한다(혼자 걷기). 버튼은 ‘전체 지도 시점’으로 바뀌어 누르면 나온다. 전에는 접속 실패 때 1인칭에서 튕겨 나와, 멀티플레이어 서버가 멈추면 1인칭을 쓸 수 없었다.

## 검증

- Django 테스트 44개(새 입장권 테스트 포함): 입장권 401, 서명·이름, 비밀값 없을 때 `ticket: null`.
- `multiplayer/room.test.js` 11개(입장권 서명·만료·위조).
- `check_connections.js`를 비밀값 없이, 그리고 입장권 모드로 한 번씩 돌려 통과했다. `deploy/smoke_multiplayer.py`는 입장권 모드 컨테이너도 따로 돌린다.
- 브라우저 검사 `scripts/terrain/account_login.py`: 검사용 계정을 API로 만들어 로그인하는 도우미를 더했고, 1인칭에 들어가는 검사들이 localStorage 이름 대신 이것을 쓴다.
  - 통과: 두 브라우저 함께 걷기(명부 취소, 잘못된 이름, 이미 쓰는 이름, 입장권 접속, 채팅, 재접속), NPC·가게(구경 모드 → 1인칭 로그인 → 거래 → 로그아웃 시 1인칭 나옴 → 재로그인), 1인칭 조작, 충돌·1인칭 클릭, 모바일 걷기.
  - `deploy/check_public_browser.py`: 운영에서 1인칭을 누르면 명부가 뜨는지 확인하고, 매번 새 검사 계정(`배포검사…`, 임의 비밀번호, 출력 안 함)으로 들어간다.
- 이번 변경과 무관하게 이미 깨져 있던 검사(설정 패널 개편 전에 쓰인 단언): `check_compass_browser`(구역 이름표 목록), `check_yukjo_browser`(설정 패널 밖 슬라이더). `check_orbit_granite_browser`, `check_first_person_browser`는 8000 포트가 고정돼 이번에 돌리지 않았다.
