# 추정 위치 시설 11곳과 장소 이야기 15편

2026-09-16. 사용자의 전체 구현 요청과 “추정 위치로 하자” 결정에 따라 후속 조사 후보를 지도에 반영했다.

## 반영

- 군기시·영화당·청의정·문헌각·애련정·취운정·청풍계 태고정·남산 국사당·도화서·제용감·전생서를 추가했다. 원도 글씨 판독점이 아닌 권역 추정 위치이며 카드에 추정 위치·개략 모형을 명시한다.
- 기존 청사 모형 4곳, 새 정자·단독 전각 모형 7곳. 열린 마루, 기와·초가 지붕, 서고·사당의 벽과 문, 작은 논·연못을 축약했다. 먼 거리용 모형도 추가했다.
- 신설 11곳의 이야기와 기존 사역원·장악원·기로소·평시서 이야기 4편을 등록했다. 총 건물 114곳·이야기 49편이다.
- 존재 연혁과 묘사 기준 시기를 분리했다. 영화당의 1692년 보수 기록을 창건 연도로 입력하지 않았으며 미상 연도는 null이다. 모든 배치·치수·형상은 확정 복원과 구별한다.
- 새 건물 동기화 시 해당 안내 문단이 없으면 생성한다. 기존 백오피스 설명은 덮어쓰지 않는다. 신규 안내 미리보기의 롤백, 반복 실행, 운영 편집 보존을 검사했다.

## 자료와 DB

조사 문서: `docs/landmark_story_research_20260916.md`. 문헌각명 번역, 청풍계 모임과 정조의 태고정 방문, 서울시의 전생서 터 설명을 보완했다. JSON은 검토·동기화 자료이고 현재 지도는 SQLite DB에서 읽는다.

로컬 DB는 `/tmp/hanyang-content-before-landmarks-20260916.sqlite3`에 무결성·외래 키 검사를 거쳐 세션 제거 백업한 뒤 `sync_content --apply`로 적용했다. 첫 미리보기 추가 26·갱신 0·충돌 0. 재실행 추가 0·갱신 0·충돌 0. 기존 안내 문단 차이 1은 보고만 하며 덮어쓰지 않는다.
