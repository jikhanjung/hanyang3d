# 135 — 모바일 점프 버튼

사용자 요청: 모바일에서도 점프할 수 있게. 조이스틱과 점프 버튼을 같은 높이에 두고 미니맵은 위로.

## 변경

- 1인칭에서 화면 오른쪽 아래에 둥근 ‘점프’ 버튼(84 px)을 둔다. 터치 화면이나 600 px 이하 화면에서만 보이고, 데스크톱은 전처럼 스페이스바를 쓴다.
- 버튼 바닥선은 왼쪽 조이스틱과 같다(둘 다 `bottom: max(12px, safe-area)`). 누르는 동안 색이 바뀐다.
- 걷기 미니맵은 점프 버튼 위(`bottom + 100px`)로 올렸다.
- 점프 버튼과 겹치던 ‘채팅’ 버튼과 ‘©’ 출처 링크는 버튼 왼쪽으로 옮겼다. 채팅 버튼은 `walk_chat.js`가 인라인 스타일로 자리를 정하므로 모바일 규칙에 `!important`를 썼다.
- 점프 로직은 `firstPerson.jump()` 하나로 모았다. 스페이스바와 버튼이 같은 함수를 부르고, 공중에서는 다시 뛰지 않는다. 말을 탄 채로도 뛴다.

## 검증

- `check_mobile_walk_browser.py`: 점프 버튼과 조이스틱의 바닥선이 같은지, 미니맵이 버튼 위에 있는지, 버튼을 탭하면 발이 0.5 m 넘게 떠오르는지 확인을 더했다. 통과.
  - 한 번은 조이스틱 W 이동 거리가 절반(1.5 m)으로 나와 실패했다가 재실행에서 통과했다. 이번 변경과 무관한 타이밍 흔들림으로 보이며, 반복되면 검사의 물리 단계 수를 살펴본다.
- `check_first_person_controls_browser.py`: 스페이스바 점프 0.96 m, 통과.
- 처음에는 Django 템플릿 캐시 때문에 새 CSS가 서빙되지 않아 검사 화면이 그대로였다. 템플릿을 고치면 개발 서버를 재시작해야 한다(126에서도 겪은 일).
