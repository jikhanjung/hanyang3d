# 167 — 건물 이름의 추정 표기 제거

사용자 요청에 따라 1907년 건물 24개의 이름에서 `(추정)`을 제거했다. 회동서관 영문 이름의 `estimated`도 제거했다. 지도 이름표·건물 선택 목록·상세 제목은 같은 name을 사용하므로 함께 반영된다. 1750년 건물 이름에는 해당 괄호가 없었다.

위치·외형의 불확실성은 기존 건물 설명, 시기 설명, position_status·model_note·출처에 유지했다. 안내 문서 제목과 영문 제목도 맞췄다. 운영 DB의 기존 안내 섹션 제목을 강제로 바꾸지 않으며, 공개 안내 렌더링에서 괄호를 숨기고 원래 앵커를 유지해 기존 지도 링크를 보존한다.

기존 Django 콘텐츠·1907년 테스트 25개 통과. 로컬 DB 백업 `/tmp/hanyang-before-clean-building-names-20260918.sqlite3` 검증 후 동기화 24건, 충돌 0. 두 시대 name, 한영 안내 제목, 회동서관의 불확실성 설명 유지 확인. 문서 제목 변경으로 안내 비교 차이는 기존 7에서 55로 늘었지만 기존 DB 본문은 보존된다. `git diff --check` 통과.

운영 배포·버전 변경은 하지 않았다.
