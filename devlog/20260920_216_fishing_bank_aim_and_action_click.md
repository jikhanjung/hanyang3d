# 청계천 낚시 개선·액션바 우클릭·지도 이동 유지

## 요청과 변경

낚시꾼이 청계천에서 멀고 낚싯대가 지나치게 길었다. 다리 길이로 물가를 추정하던 배치를 실제 수면 메시의 북쪽 가장자리 기준으로 바꾸었다. 지면 높이·마른 땅·충돌을 확인한 가장자리 밖 0.8~3m 후보를 선택하며, 찌는 가장자리 안쪽 3m 수면에 놓는다. 낚시꾼 낚싯대는 최대 2.4m, 플레이어 낚싯대는 최대 4m로 제한한다.

플레이어는 사용 순간 카메라 시선의 수평 방향으로 던진다. 몸 방향과 별도인 우클릭 둘러보기도 반영한다. 전방 3~14m 안에서 실제 수면과 지면·충돌을 확인하고, 마른 땅을 향하면 시작하지 않는다. 투척 지점을 시작 시 고정해 이후 시선을 돌려도 찌가 따라 움직이지 않게 한다.

낚시꾼 반경 12m 제한을 없애 청계천 전체에서 낚시가 가능하게 했다. 투척 거리 안에 실제 청계천 수면이 있어야 하며 낚시꾼의 안내 대사도 수정했다.

공통 액션바에서 우클릭도 좌클릭·숫자 키와 같은 사용 경로로 연결했다. 기존 연결 해제는 Shift+우클릭으로 옮기고 툴팁에 표시한다. 두 시대에 공통 적용한다.

M 지도를 열 때 이동 입력을 초기화하지 않는다. 지도에 포커스가 있어도 이동 키·달리기·점프를 처리하며, 키를 놓으면 정상 정지한다. 지도 아래에서 자동 달리기도 유지하고 W/S 또는 Alt+W로 중지할 수 있다.

## 채집물 확장과 재생

약초 4종(쑥잎·질경이·민들레·도라지뿌리)과 물고기 4종(피라미·미꾸라지·붕어·잉어)을 각각 별도 아이템으로 추가했다. 약초는 잎의 높이·폭·색과 꽃/이삭으로 구분한다. 종류별 판매가는 약초 3·4·6·8문, 물고기 3·6·9·14문이다. 문헌 출처·페이지와 게임 설정의 범위는 [낚시·약초 문서](../docs/fishing_and_herbs.md)에 기록하고 출처 페이지에도 연결했다.

약초의 기존 5분 재생을 유지하면서 잎·줄기·꽃 모두 즉시 숨기고, 남은 커서를 지우며 재생 안내를 표시한다. 만료된 클라이언트 쿨다운 항목은 제거한다. 계정별 서버 쿨다운은 새로고침·시대 변경에도 유지한다. 기존 산약초·민물고기 아이템과 보유 수량은 보존한다.

낚시 대기는 10초 고정, 성공률은 30%다. 성공 후 피라미/미꾸라지/붕어/잉어를 40/25/25/10 가중치로 고른다. `FishingCast.item`에 결과 종류를 저장해 재요청 때 종류를 바꾸거나 중복 지급하지 않는다. 화면에 진행 막대와 남은 초를 표시한다. 운영 반영에는 `0010_fishing_catch_item` migration과 `seed_fishing`(없는 물품만 추가)이 필요하다.

## 확인

- JavaScript 구문 검사 및 `git diff --check` 통과.
- 기존 로컬 브라우저 검사: 두 시대 낚시 서버 대기·결과, 모바일 쓰기·이동 취소, 약초 채집 확인.
- 추가 검사는 실제 액션바 우클릭, 몸과 다른 카메라 방향의 투척, 물가 근접·낚싯대 길이 및 우클릭 후 연결 보존을 두 시대 모두 통과했다. 수평 시선과 투척 방향 내적 1, NPC와 찌 간 수평 거리 1750년 3.8m / 1907년 4.2m, 낚싯대 최대 2.4m를 확인했다.
- 두 시대 M 지도 열기·닫기 중 W 이동/자동 달리기 유지, 지도 안에서 키 해제·재이동·자동 달리기 정지를 확인했다.

- Django 전체 80개 테스트 통과. 10초·30% 경계, 물고기 4종 결과 재요청 일관성, 약초 4종 보상·쿨다운, 8종 판매 가격과 중복 지급 방지를 확인했다.
- 두 시대 브라우저에서 진행 막대·낚시 결과, 모바일 쓰기·취소, 약초 잎/꽃/줄기 소멸과 재생을 확인했다. 재생은 로컬 클라이언트 만료 시점을 앞당겨 확인하고, 서버 만료·재채집은 서버 테스트에서 별도로 검증했다.
- 낚시꾼에서 각각 약 2.2km/2.8km 떨어진 물가에서도 서버 낚시가 시작됨을 확인했다.

운영은 v0.5.28 상태이며 이 변경은 아직 배포하지 않았다. 별도 다운로드 작업의 AKS 목록·manifest 수정은 포함하지 않는다.
