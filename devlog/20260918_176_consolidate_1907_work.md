# 176 — 누적 1907년 작업 기록과 Git 정리

사용자가 지금까지 작업한 내용의 devlog 작성과 commit·push를 요청했다. 기존 main 이후 누적된 1907년 지도·건물 66개·도로/성곽/물길·보행/멀티플레이·인물/이야기·전차·선택/이름표·자료조사 변경을 함께 커밋 대상으로 정리했다.

- 작업·배포 기록 143~175의 devlog 인덱스 등록 누락 없음.
- 음악 조사와 다음 건물 후보 문서도 포함.
- 마지막 건물·이름표 클릭 시 시점 유지 수정은 개발 소스에 포함되지만 운영 v0.5.14에는 아직 미반영이다. 이 Git 정리 자체는 새 배포가 아니다.
- `HANYANG_CONTENT_SOURCE=files .venv/bin/python manage.py test webapp --verbosity 0`: 63개 통과.
- `npm test`(multiplayer): 통과.
- PC·모바일 전차/건물 브라우저 검사: 카메라 위치·회전 유지, 이동 목록 동작, 전차·가림·회피 등 통과.
- `git diff --check`: 통과. 새 JSON 파싱 확인. 원본 지도·DB·환경 파일·배포 묶음은 기존 ignore 정책에 따라 제외.
