# 050 — 모바일 1인칭 조이스틱과 상시 나침반

## 요청 및 조작 방식

모바일 1인칭 이동이 불편하다는 피드백에 따라 게임에서 사용하는 조작 방식을 확인하고, 왼손 가상 조이스틱 + 화면 드래그 시선 조작을 도입했다. 이어 요청한 보정점 체크박스 숨김, 지도 우상단 상시 나침반, 1인칭 미니맵 반투명 표시도 반영했다.

참고한 공식 문서:

- [Minecraft Control Schemes](https://learn.microsoft.com/en-us/minecraft/creator/documents/controlschemes?view=minecraft-bedrock-stable): 1인칭의 locked player relative strafe는 조이스틱으로 전후·옆걸음 이동, 스와이프로 좌우 회전·상하 시선을 조작한다.
- [Unity On-screen Controls](https://docs.unity3d.com/Packages/com.unity.inputsystem@1.11/manual/OnScreen.html): 화면 스틱의 pointer-down/move/up과 이동 범위를 참고했다. 외부 라이브러리를 추가하거나 코드를 복사하지 않고 Pointer Events로 구현했다.

## 구현

- 모바일·터치 화면에 지름 120px 고정 조이스틱. 중심 12% 데드존, 바깥으로 밀수록 최대 1.5m/s까지 아날로그 이동. 대각선도 최대 속도를 넘지 않는다.
- 조이스틱 포인터와 시선 드래그 포인터를 별도로 추적한다. 버튼 입력도 키보드와 분리해 캔버스 포커스 이동이 터치 이동을 지우지 않게 했다.
- 손을 떼거나 터치 취소/캡처 해제, 창 포커스 이탈, 앱 숨김, 1인칭 종료, 조이스틱 화면 크기 변경 시 입력을 정리한다.
- PC WASD·방향키와 화면 방향 버튼을 유지한다. 모바일에는 손가락 조작 안내를 표시한다.
- 보정점 체크박스를 숨기고 기본 off를 유지한다. JS에서 참조하는 input은 보존한다.
- 나침반은 전체 지도와 1인칭에서 항상 우상단에 표시한다. 카메라의 실제 시선 벡터에서 방위각과 북쪽 바늘을 계산한다. 모바일 컨트롤과 겹치지 않게 너비를 확보한다.
- 1인칭 미니맵 패널에 opacity 0.7을 적용한다. 미니맵은 터치 입력을 가로막지 않는다.

## 검증

`scripts/terrain/check_mobile_walk_browser.py`는 Chromium 모바일 터치 에뮬레이션으로 실제 CDP 터치 이벤트를 전달하며 물리 시간만 일정하게 전진시킨다. 방향별 이동, 아날로그 속도·데드존·대각선, 이동+시선 멀티터치, 한 손가락 해제, 포커스 전환·취소·재진입, 키보드 회귀를 검사한다. 실물 iOS/Android 기기 검사는 수행하지 않았다.

Django 테스트 11개와 JS 구문 검사를 수행했다. 배포 버전은 `honestjung/hanyang3d:v0.0.8`이다.

모바일 검증 통과: 상하좌우 각 1초에 약 1.5m 이동, 중앙 정지·반쯤 밀기·대각선 속도 제한, 멀티터치 중 한 손가락만 떼기와 포커스 전환, 취소·재진입·키보드 정상 동작. 보정점 숨김과 미니맵 opacity 0.7, 나침반 북/동/남/서 0/90/180/270도 표시 및 상단 컨트롤과 겹침 없음도 확인했다.

Docker 내부 테스트 및 기동 검사 통과: v0.0.8, 공개 리소스 54개.
