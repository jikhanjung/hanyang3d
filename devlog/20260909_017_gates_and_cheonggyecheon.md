# 017: 성문 개념 모형·원도 청계천과 다리

- 사용자 요청으로 성문 박스를 통로·석축·문루·지붕의 단순 모형으로 변경했다. 기존 위치·개략 크기·지형 받침을 유지한다.
- 추가 요청으로 전체도에서 청계천 본류 37점을 판독하고 부분도에서 모전교·광통교·장통교·수표교 글자를 대조했다.
- 원도 픽셀 판독을 기존 TPS 격자로 변형해 수로와 다리를 표시했다. 원본 체크섬·글자 확인 창·좌표·구조 가정을 JSON에 기록했다.
- 물길·다리 전환과 확대, 다리 이름 선택, 원도 판독선을 제공한다. 수면과 다리는 현대 지형 위 개념 표현이며 하상·수위·교량 구조의 복원이 아니다.
- Django 7개와 경사지 받침 수치 검사 통과. Tailscale Chromium에서 성문 통로의 빈 공간을 ray 검사하고 다리 4개 클릭·표시 전환·높이 변경·원도 판독 표시를 확인했다. 페이지 오류 없음.
