# 배재학당 본당과 자료 사진 보관

사용자 요청: 1907년 배재학당 건물을 만들고 자료 사진은 자료 폴더에 정리.

1887년 본당의 단층 벽돌 외관을 구현하여 정동교회 남쪽 추정 구획에 배치. 아치형 창·중앙 현관·박공·기와지붕·굴뚝을 표현하고 원거리 LOD와 건물 충돌, 클릭 설명을 연결했다. 1916년 동관은 시대에서 제외했다.

[재현 범위·출처·배포 방법](../docs/paichai_1907_model.md). 사진은 `data/photos/paichai/main-hall-1887-undated.jpg`에 원본 보관, checksum과 촬영일 미확인 상태를 기록. 원본 바이너리는 Git/웹 배포 제외, 사진 목록과 README는 버전 관리.

브라우저 검증: 모델 생성·지도 위치(교회와 약 166m)·건물 충돌·클릭 설명·LOD 근/원거리 전환·1887~1929 연대 확인 통과. 스크린샷 `/tmp/paichai-model.png` 외관 확인.

Django 1907 장면·콘텐츠 DB 회귀 테스트 26개 통과. 개발 로그 및 소스 커밋/푸시, 운영 배포는 별도.
