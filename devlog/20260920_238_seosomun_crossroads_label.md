# 238 — 서소문 밖 네거리 이름 표시

1907년 원도의 문 밖 교차로 추정 중심 [389,2645]에 ‘서소문 밖 네거리’ 이름만 추가했다. 기존 건물 이름과 같은 글꼴·테두리 스타일이며 기호·건물·설명 패널·클릭 동작은 없다. 영어 이름과 이름표 설정·실내 숨김·거리/가림 처리를 연결했다.

지명은 infrastructure1907의 place_labels 데이터로 분리했다. 형장의 정확한 처형 지점이나 경계를 확정한 표시는 아니다. 다음 배포에 JS와 `gis/updates/1907_seosomun_place_label.json`을 함께 반영해야 한다(운영 미반영).

격리 DB·Chromium에서 지명 텍스트/좌표·SPAN·포인터 비활성·클릭 핸들러 없음 확인. 기존 이화학당·소의문 통행·취객 회귀 검사도 통과.
