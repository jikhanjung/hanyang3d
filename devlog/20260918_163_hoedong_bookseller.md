# 163 — 회동서관과 1907년 책방 이야기꾼

## 요청과 결과

1907년 중심 이야기꾼으로 제안한 책방 주인을 구현하고, 사용자가 추가로 준 회동서관 자료를 바탕으로 건물도 추가했다. 1907년 건물은 65→66개, 전체 건물 seed는 179→180개다. 회동서관 앞의 가상 책방 주인 1명이 새 문물·나라 소식·거리 생활 세 주제로 16편을 들려준다. 실존 경영자 고제홍·고유상으로 묘사하지 않는다.

## 자료와 배치

- 사용자 제공 DH Edu 회동서관 터 페이지의 1906년 ‘광통교 동변’ 광고 설명, 1907-09-07 회동서관 광고 설명과 현대 표석 좌표를 확인했다. 학생 편집 자료이며 신문 원본을 독립 대조했다고 주장하지 않는다.
- 표석 역변환 [988,2352]와 원도 확대 이미지를 비교하여 길 동쪽 [1001,2337]로 조정. 필지 경계·건물 중심은 추정이다.
- 본문 1897년 창업과 표석 1880년대 설명이 달라 존재 시작연도는 미확정. 묘사 구간 1907–1908을 별도로 둔다.
- 동아일보에 소개된 사진은 1915년경이므로 1907년의 확정 외관으로 소급하지 않았다. 기와지붕, 목조 점포, 책 더미와 匯東書館 간판을 프로젝트 코드로 제작했다. LoD 지원. 텍스처가 있는 간판은 정적 메시 병합에서 제외해 UV를 보존한다.

## 구현

- `gis/buildings/1907_landmarks.json`, 개별 모델 manifest, 건물 안내/영문 안내, DB 검증 개수 갱신.
- `gis/characters/seoul1907.json`: 16편의 한·영 각색 대사, 조사 이야기 ID·사건 연대·출처, 창작/비목격 서술 구분. 원본 24편 조사 JSON 및 이야기 DB 49편은 보존한다.
- 책방 주인은 갓·회색빛 두루마기와 책 소품. 인물 클릭 및 회동서관 건물 설명의 ‘책방 주인과 이야기하기’로 대화 진입.
- 기존 공통 대화 창과 모바일 선택지, 출처 링크, 닫기/돌아가기 사용. 별도 전문 이야기꾼(전차 직원 등)은 아직 추가하지 않았다.
