# 140 — 언어 선택(KO | EN) 1단계: 화면 문구와 서버 응답

사용자 요청: 설정에서 언어를 선택할 수 있게. 영어를 추가하고, 내용을 모두 번역해 영어 사용자도 쓸 수 있게(KO | EN).

두 단계로 나눈다. 이 기록은 1단계(화면 문구·서버 응답)다. 2단계(건물·안내·이야기·NPC 대사·물건·지명)는 141에서 다룬다.

## 구조

- `webapp/i18n.py`: 한국어 원문을 키로 하는 사전 `webapp/locale/en.json` 하나를 서버와 브라우저가 함께 쓴다. `t(text, lang, **values)`는 영어일 때 사전 값을, 없으면 원문을 돌려주고 `{placeholder}`를 채운다.
  - `msgfmt`가 개발 호스트·이미지에 없어 Django의 .po/.mo 대신 이 방식을 택했다. 도구 없이 동작하고, 번역이 빠진 문구는 한국어로 남아 화면이 깨지지 않는다.
- 언어 선택: `?lang=en`·`?lang=ko` 링크(설정 패널의 KO | EN, 안내·출처 페이지 상단). `LanguageMiddleware`가 값을 1년 쿠키 `hanyang3d_lang`에 기억하고 `request.lang`을 정한다. 응답에 `Vary: Cookie`.
  - 기본은 한국어다. 브라우저 `Accept-Language`는 일부러 쓰지 않는다. 자동 감지를 켜면 영어 브라우저의 Playwright 검사가 모두 영어로 바뀌고, 방문자마다 첫 화면이 달라진다.
- 템플릿: `{% load i18n_ko %}`와 `{% t "문구" %}`(짧은 문구·속성), `{% tblock %}…{% endtblock %}`(문단, 안쪽 `<a>` 같은 인라인 HTML 포함). 7개 템플릿의 한국어 문구를 스크립트로 감쌌다. `<html lang="{{ lang }}">`.
- 브라우저: `webapp/static/i18n.js`가 페이지에 심은 사전(`#i18n`, 영어일 때만)과 `<html lang>`으로 `t()`를 제공한다. `terrain3d.js`, `shop.js`, `walk_together.js`, `walk_chat.js`, `npc_dialogue.js`, `compass3d.js`의 한국어 문자열을 `t()`로 감쌌다. 자료 키로 쓰는 분류 이름(`'궁궐'` 등)은 남기고, 화면에 보일 때만 `t(f.category)`로 번역한다.
- 서버 응답: 거래(`economy.trade(..., lang)`), 계정(`accounts.register/login`은 `request.lang`), 뷰의 메시지를 요청 언어로 낸다.
- 멀티플레이 서버는 손대지 않았다. 그 메시지도 한국어 원문 그대로 사전 키가 되어 브라우저가 번역한다. 정원 안내처럼 숫자가 든 메시지는 숫자를 `{n}`으로 바꿔 찾는다(`tMsg`).
- 번역은 조사 에이전트가 사전 390개 항목을 영어로 옮겼고, 고유명사는 로마자 표기(도성대지도 → Doseong Daejido 등), 엽전은 coins·nyang·mun, NPC의 옛 말투는 평이한 영어로 했다.

## 고친 것

- 스크립트가 감싼 템플릿에서 `tblock` 안에 `<b>{% tblock %}…{% endtblock %}</b>`가 중첩된 곳(소개 문단 2곳)과 `tblock` 안에 `{% t %}` 속성이 든 곳(현황 페이지 그림 링크)이 있었다. 렌더링 때 안쪽이 먼저 바뀌어 키가 사전과 맞지 않게 되므로, 바깥 문단 하나로 묶거나 텍스트만 감싸도록 고치고 사전 키를 맞췄다(번역 에이전트가 짚어 준 문제).
- 제목 옆 `1750년경`은 템플릿 변수와 붙어 있어 스크립트가 건너뛴 것을 손으로 감쌌다(`c. 1750`).
- Django 개발 서버는 템플릿을 캐시하므로 템플릿을 고친 뒤 재시작해야 검사에 반영된다.

## 범위 밖(2단계)

- 건물 이름·소개·존재 시기, 안내 문단(45,000자), 장소 이야기 49편, NPC 대사, 물건·가게, 지명 399개, 다리·산 이름.
- 백오피스(관리자 화면)와 3D 간판의 한글은 번역하지 않는다.

## 검증

- Django `test_i18n`: 영어 브라우저도 기본 한국어, `?lang=en`으로 쿠키·`<html lang="en">`·영어 문구, 모든 페이지에서 기억, API 오류 메시지 영어, 사전 항목 300개 이상과 `{placeholder}` 일치, 없는 키는 원문.
- `check_language_browser.py`: 영어 브라우저 기본 한국어 → EN 전환 → 설정·소개·명부·가게 창 영어, 서버 오류 영어 → KO 복귀.
