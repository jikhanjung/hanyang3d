# 047 — 도로 표면을 기준으로 1인칭 눈높이 수정

2026-09-12. 사용자가 FABDEM 교체 뒤 1인칭 눈높이가 낮다고 지적했다.

## 원인과 측정

기존 카메라는 DEM·옛지도 표면 최고점에서 1.65m를 더했지만, 도로 표시 메시의 높이는 포함하지 않았다. 도로는 원도 표면보다 약 0.7m 높아서 실제 보이는 도로 기준 눈높이는 약 0.95m였다. FABDEM 자체의 고도 문제가 아니라 기존 지면 선택 로직의 누락이다.

수정 전 운영 페이지에서 실제 삼각형에 수직 광선을 쏘아 확인했다. 시작 위치의 카메라 Y=33.3516m, 옛지도 표면 Y=31.6979m, 도로 Y=32.3979m로, 옛지도 기준 1.6537m·도로 기준 0.9537m였다.

## 수정

`groundAt`에서 표시 중인 도로 표면도 최고 지면 후보에 포함했다. DEM·원도는 이미 높이 강조가 적용된 좌표이고 도로 받침 값은 원래 높이이므로, 도로에만 강조 배율을 곱한다. 카메라는 선택된 지면에서 1.65m를 유지한다. 도로 숨김과 옛지도 불투명도 전환도 반영한다.

공개 브라우저 검사에 실제 DEM·원도·도로 메시 광선 교차를 사용한 눈높이 확인을 추가했다. 1·1.5·2배, 원도 표시/숨김, 도로 표시/숨김을 확인한다. 기존 1인칭 검사도 도로를 포함하도록 보강했다.

## 배포

Django 11개 검사와 JavaScript 구문 검사를 통과했다. 배포 버전은 `honestjung/hanyang3d:v0.0.5`다.

v0.0.5 이미지는 게시했으나 추가 요청을 반영하기 위해 운영 배포는 보류했다. 실제 배포는 [048 지면 통일](20260912_048_unified_ground_surface.md)을 포함한 v0.0.6으로 진행한다.
