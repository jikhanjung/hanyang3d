# 053 — 수평 3D 나침반과 모바일 햄버거 메뉴

## 변경

모바일 좌상단에는 `한양3D vX.Y.Z`와 햄버거 아이콘만 한 줄로 표시한다. 메뉴 안에 1인칭/전체 시점 전환, 옛지도 불투명도를 둔다. 시점을 전환하면 메뉴가 닫힌다. PC에서는 기존처럼 조작 항목을 바로 표시한다.

PC·모바일 공통 나침반을 실제 Three.js 메시로 교체했다. 빨간 N 북침, 회백색 S 남침, 중심축, 얇은 수평 테두리로 구성하며, 바늘에는 위아래 두께와 삼각 면을 주었다. 투명한 별도 캔버스에 렌더링하므로 흰 패널이나 숫자 패널은 없다.

북침 끝은 세계 좌표 -Z(북쪽), 남침은 +Z에 고정한다. 모형의 수평 자세는 바꾸지 않는다. 나침반 카메라에 지도 카메라의 quaternion을 그대로 복사하고 일정 거리에서 원점을 바라보게 하여 yaw·pitch가 반영된다. 카메라의 높이를 강제로 보정하거나 바늘을 화면에 평평하게 붙이지 않는다. 수평 시선에서는 테두리가 선처럼 보이고, 위에서 내려다보면 원으로 보이는 것이 의도한 동작이다. 방위·기울기는 접근성 라벨과 진단용 dataset으로 제공한다.

## 검증

- Django 11개 테스트, 변경 JS 구문·Python 검사 및 diff 검사.
- 모형 단독으로 위·비스듬한 시점·수평 시점을 렌더링해 형태 확인.
- `scripts/terrain/check_compass_browser.py`: 16개 yaw/pitch에서 카메라 방향 일치, 북쪽 끝 -Z 고정과 수평 자세, 투명 배경, PC·모바일 표시, 모바일 제목·햄버거 한 줄, 메뉴를 통한 1인칭 진입/복귀와 자동 접힘을 검사한다.
- 기존 브라우저 검사의 메뉴 진입 및 나침반 진단값 참조도 새 UI에 맞게 갱신했다.

배포 버전: `honestjung/hanyang3d:v0.0.11`.

브라우저 검증 통과: 16개 시선 방향, PC·모바일 모형 표시, 메뉴 자동 접힘 및 시점 전환. 실제 화면에서 두께 있는 바늘과 시선에 따른 수평 테두리 모양을 확인했다.

추가 요청으로 기존 초기화면 링크를 PC·모바일 공통 조작부에서 제거했다. v0.0.11 이미지 게시 이후 요청이므로 최종 배포는 v0.0.12를 사용한다.
