# 116 — 마지막 걷기 위치 복원과 NPC 무작위 시작

사용자가 1인칭 재접속 시 마지막 위치에서 시작하고, 새 공간의 NPC에는 무작위 변화를 주도록 요청했다. 두 변경을 v0.2.3으로 묶는다.

## 사용자 위치

- 이름·지도 정렬별 localStorage에 좌표 x/z와 방향을 저장한다. 메뉴·Escape로 나갈 때, pagehide와 문서 숨김 때 저장하고, 걷는 동안에는 변경된 위치를 최대 초당 한 번 기록한다.
- 같은 브라우저에서 다시 접속하면 마지막 위치·방향을 복원하고, 높이는 현재 지형에 맞춘다. 출시 버전이 바뀌어도 경로 좌표 키가 같으면 사용할 수 있다.
- 데이터 형식·유한 좌표·범위·경로 좌표 키를 검사한다. 지도 밖이나 현재 건물 안이면 기본 출발점으로 돌아간다. 브라우저 저장이 차단돼도 현재 페이지에서는 메모리로 기억한다.
- 계정 DB나 기기 간 동기화는 추가하지 않았다.

## NPC

- Colyseus 공간 생성 시 NPC 130명의 왕복 경로상 출발 위치·방향과 속도(0.8~1.3 m/s)를 무작위로 정한다. 같은 공간에 새로 접속해도 NPC를 다시 초기화하지 않는다.
- 위치뿐 아니라 초기 진행량과 속도도 스냅샷에 담아 브라우저의 걷기 동작을 맞추고, 연결 종료 후 로컬 이동도 그 상태에서 이어간다.
- 지도 둘러보기의 로컬 초기값은 기존대로이며, 함께 걷기의 무작위 결정과 이동 계산은 서버에서 수행한다.

## 검증

- 서버 6개 검사 통과: 같은 난수 입력은 같은 이동 결과, 다른 입력은 다른 위치·속도, 경로 범위와 130명 유지.
- 실제 클라이언트 검사 통과: 새 공간끼리 초기 진행량이 다르고, 같은 공간의 접속자는 동일한 NPC 틱·위치·속도를 받는다. 이름·채팅·퇴장 검사도 통과했다.
- Django 15개 검사 통과. 두 브라우저에서 손상된 저장값의 기본 위치 진입, 나가기·재접속 시 위치·방향 복원, 페이지 이동 후 새 문서에서 복원, 무작위 NPC 스냅샷 일치를 확인했다.
