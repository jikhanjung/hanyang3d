# 207 — 웹 v0.5.25 운영 배포

요청에 따라 dolfinid의 웹을 `honestjung/hanyang3d:v0.5.25`로 배포했다. 멀티플레이는 서버 로직 변경이 없어 v0.5.24를 유지했다. 빌드 소스는 `ec99272`, 이미지 digest는 `sha256:dd28a5a51251998a1fab2cc736d0cc2f66b15cb051530b548d943e18f8905f90`다.

포함 사항: 채팅 왼쪽 배치와 설정 메뉴 정리, 두 시대의 M 키 큰 지도·현재 위치 표시, 1907년 청계천 하도 보행, 단성사 문지기와 주요 건물 관리인 13명, PC 봇짐 쓰기 버튼 숨김. 연구용 사진·AKS 원본 모델은 배포 이미지에 포함하지 않는다.

첫 이미지 검사에서는 Resource 개수 테스트가 이전 133개에 고정되어 실패했다. 새 모듈 2개에 맞춰 135개로 수정하고 재빌드했다. 웹 테스트 71개와 이미지 초기화·운영 편집 보존·백업 무결성 검사를 통과한 이미지만 게시·배포했다.

설정 백업: `/srv/hanyang3d/backups/config/pre-v0.5.25/`. `.env.django` 전체와 `.env`의 릴리스 키 외 내용을 배포 전후 비교하여 보존을 확인했다. 웹 배포 전 검증 DB 백업은 `backups/content/pre-deploy/content_v0.5.25_20260919_133010.sqlite3`다. 새 migration은 없으며 기존 건물·이야기 콘텐츠 동기화도 추가·갱신·충돌 0건이다.

운영 SceneDataset은 seed 재실행으로 덮어쓰지 않는다. `1907_caretakers.json`의 비교 해시를 먼저 검사하고, 별도 검증 백업 `backups/content/pre-deploy/data_20260919_133041.sqlite3`를 만든 뒤 people1907 1건만 적용했다. 멀티플레이 재시작은 불필요했다.

운영 healthcheck 정상: 웹 v0.5.25, 멀티플레이 v0.5.24, routeKey1907 `7fd23b91`. 공개 사이트에서 PC·모바일의 1907년 관리인·단성사 대화·큰 지도·하도·설정 링크와 1750년 M 지도를 확인했다.

배포 완료 뒤 별도 개발 PC에 물품·음식 다운로드 예약을 등록했다. [208 기록](20260919_208_aks_dated_download_jobs.md).

배포 후 사용자가 청계천 바깥 지형과 지도 누락을 보고했다. 앞선 검사는 하도·큰 지도에 집중해 전체 지형 좌표의 NaN을 놓쳤다. 하도 검색 실패 시 보정 계산을 건너뛰도록 수정하고 전체 지형·법선 및 하천 외부 높이를 검사하는 v0.5.26 후속 배포를 진행한다.
