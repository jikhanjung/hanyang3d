# 020 — 돈의문 원도 보정점 교정

2026-09-10

사용자가 모형뿐 아니라 calibration 지점도 옮겨야 한다고 지적했다. 잘못 판독한 원도 점 (703, 1493)을 성벽과 길의 교차점 (766, 1481)로 교정하고 현대 돈의문 터 좌표는 유지했다. 재생성 스크립트와 3점 affine 행렬을 함께 갱신했다.

돈의문 모형은 별도 원도 좌표 배치에서 현대 보정점 위치 배치로 되돌렸다. 원도 판독 근거는 source_reading에 남긴다. TPS 입력 수정으로 원도의 문 기호가 해당 현대 위치에 맞춰지므로 문 모형과 파란 점이 일치한다. 다른 4개 점은 유지한다.

검증: TPS 단위 검사, Django 7개 검사 통과. 실제 데이터의 5점 보간 오차 <0.00001 m, 평면 32×28·3D 128×112 격자의 접힘 0개. 이전 TPS 대비 원도 문 기호 이동은 지상 환산 약 107.5 m. 청계천 예시 3점 이동은 14.3 / 46.2 / 7.3 m이며 전체 물길과 다리는 기존 판독 픽셀을 새 TPS에 적용한다.

브라우저 검증은 check_gate_orientation_browser.py를 사용한다. 기존 돈의문 모형이 보정점 동쪽에 있어야 한다는 019 검사를 두 위치의 일치 검사로 교체했다. 문 방향은 기존 판독 진입로를 새 TPS로 계산한다.

브라우저 검사 통과: 네 문 진입로·통로 및 석축, 돈의문 모형과 보정점의 정확한 위치 일치, 하도 보정 전환·높이 강조 시 받침 유지, JavaScript 오류 0개. 돈의문 확대 스크린샷도 확인했다.
