# 095 — 건물 LoD: 멀리서는 단순한 모형으로

사용자가 이름표처럼 건물도 LoD 개념으로 멀리서는 단순하게 보여 주면 어떠냐고 했다.

## 측정 (변경 전, v0.1.25)

같은 기기(llvmpipe)에서 종루 위 먼 시점 기준:

- 장면 전체 914 draw call, 567만 삼각형.
- draw call은 주요 건물 모형이 대부분이었다. 96곳 모형이 작은 메시 14,660개로 이루어져 먼 시점에서도 약 700 call을 썼다(육조 관청 한 곳에 400~570개).
- 삼각형은 추정 주택·상가가 대부분이었다. 약 3,000동이 격자 벽과 기와 줄 지붕으로 367만 삼각형을 썼다. 인스턴싱이라 call은 4개뿐이다.
- 나머지는 작다: 나무 32만, 성벽 7.7만, 시전과 걷는 사람도 적다.

## 한 것

### 추정 주택·상가

- 카메라에서 800 m보다 먼 집은 상자 벽과 두 경사 지붕(약 20삼각형) 모형으로 바꾼다. 가까운 집은 기존 격자 벽·기와/초가 지붕·차양 모형 그대로다. 벽·지붕 색은 같다.
- 인스턴스 메시마다 그리는 집만 앞쪽 칸에 모으고 `count`를 줄였다. 처음에는 안 쓰는 칸을 크기 0으로 두었는데, GPU가 그 칸도 계속 처리해 삼각형이 줄지 않았다.
- 멀고 가까운 구분은 카메라가 60 m 넘게 움직였을 때만 다시 계산한다.

### 주요 건물

- 카메라에서 1.6 km보다 먼 상세 모형은 건물마다 한 덩어리로 합친 낮은 모형으로 바꾼다. 담장이 있는 구역형(육조 관청, 궁궐, 사당, 훈련원, 집터, 관상감)은 바닥판+가운데 건물+지붕, 나머지(성문, 종루, 석탑 등)는 건물 덩어리+지붕이다. 색은 건물 분류 색을 따른다.
- 낮은 모형 벽색은 처음에 분류 색(관청 파랑 등)을 그대로 써서 먼 시점 육조거리가 파란 덩어리로 튀었다. 상세 모형의 흙벽 베이지(#c9bb9f)에 분류 색을 25%만 섞도록 바꿨고, 지붕은 짙은 회색이다.
- 경계에서 깜빡이지 않게 1.5 km 안으로 들어오면 상세, 1.7 km 밖으로 나가면 단순으로 바꾼다.
- 낮은 모형은 같은 건물 객체 안에 있어 누르기·강조·이름표·충돌은 그대로다.

## 결과 (같은 기기, 같은 시점)

| 시점 | v0.1.25 call / 삼각형 | 변경 후 call / 삼각형 |
| --- | --- | --- |
| 먼 시점 | 914 / 567만 | 303 / 190만 |
| 중간 시점 | 876 / 566만 | 322 / 190만 |
| 가까운 시점 | 365 / 556만 | 337 / 242만 (가까운 집 737동 상세) |

한 프레임 그리기 시간은 먼 시점 11.2 ms → 7.6 ms였다(llvmpipe, 참고값).

## 검사

- `check_walk_collision_browser.py`: 먼 시점에서 낮은 모형 60곳 넘게 보이고 종루가 단순 모형이며 상세 집이 거의 없음, 가까운 시점에서 종루가 상세 모형이고 상세 집이 있음을 확인한다.
- `check_settlement_browser.py`는 집 인스턴스를 기록 순서로 읽는데, 이번에 칸을 앞으로 모으면서 그 가정이 맞지 않게 됐다. 이 검사는 084에 적은 대로 이미 옛 주소·설정 때문에 돌지 않던 검사라 이번에 고치지 않았다.
