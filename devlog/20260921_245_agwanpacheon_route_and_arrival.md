# 245 — 아관파천 이동 속도·도시 경관·교량·공사관 도착

## 요청과 변경

가마 체험이 느리고 빈 벌판처럼 보인다는 피드백을 반영했다. 가마 속도는 1.65m/s에서 2.8m/s로 높여 일반 걷기(3m/s)로 따라갈 수 있게 했다. 뒤처질 때 기다리는 기능은 유지한다.

경로는 영추문 → 금천교 추정 교량 → 내수사 앞길 → 새문고개(현재 새문안교회 앞 부근) → 정동 → 러시아공사관 앞마당으로 변경했다. 교량 양안 진입점을 직접 경유하고, 경로 탐색에서 수면 아래 지점을 제외한다. 회상에만 교량을 추가한다.

경로 주변에 고정 시드의 초가·기와집 266동, 일부 가게 처마, 낮은 담장과 흙길을 배치했다. 상세 모델은 180m 이내에서 표시하는 LoD를 사용한다. 집·담장은 충돌 대상으로 등록하고 가마 통행 공간, 물길, 궁궐 담장, 기존 건물과 떨어뜨렸다. 특정 1907년 건물을 1896년까지 소급하지 않는다.

공사관 입구·앞마당에 러시아 수병 4명을 배치했다. 도착하면 휘장이 열리고 고종·왕세자가 하차하여 출입구로 들어가는 약 21초의 장면을 보여준다. 맞이하는 인물은 “폐하, 이쪽으로 드시옵소서.”라고 말한다. 입장 연출 종료 후 완료를 저장한다. 회상 전용 공사관 출입구와 진입 경사로를 추가했다.

## 역사 자료

동북아역사재단의 경로·공사관 경비 설명, 국사편찬위원회의 1894년 ‘대군주 폐하’ 호칭 변경 자료를 확인했다. 내수사 위치는 내수동·경희궁의 아침 3단지 주변으로 설명했다. 현대 새문안교회는 경로를 잡는 위치 참고점이며, 현대 교회 건물을 과거 장면에 넣지 않는다.

정확한 금천교 위치·규모, 민가 위치, 의복·수병 제복의 세부, 가마 하차 동작, 공사관 출입구와 대사는 추정·창작이다. 근거와 구분은 `docs/agwanpacheon_route_reconstruction.md` 및 체험의 출처 설명에 기록했다.

## 저장·검증

경로 정의는 버전 2로 변경했다. 이전 경로 진행은 다시 시작하도록 안내하고 기존 최초 완료 시각은 유지한다. 새 계정의 진행 레코드는 현재 정의 버전으로 생성하도록 수정했다.

- Django 전체 기존 87개 통과, 추가된 구버전 경로 재시작 검사를 포함한 역사 이벤트/액션바 5개 통과.
- Playwright: 776개 경로점, 총 1,538.84m, 민가 266동. 0.5m 간격 검사에서 수면 아래 경로 0, 집·담장 충돌 0, 수로 위 교량 통과 표본 43.
- 가마 중간 정지·재개, 끝까지 진행, 도착 연출·‘폐하’ 말풍선·수병 4명, 완료 저장을 검사.
- 일반 1907년으로 복귀한 위치, 다른 브라우저의 계정 액션바, 기존 액션바 이관도 검사.
- 이동만 약 9분 10초, 도착 장면 약 21초. 대기·탐색 시간은 별도.

운영 배포는 이 작업에 포함하지 않았다. AKS 백그라운드 다운로드 카탈로그/매니페스트 변경은 별도 작업으로 유지한다.
