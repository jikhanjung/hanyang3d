# 이미지 교체 없는 장면 데이터 갱신

SceneDataset 모델과 0007 마이그레이션, 최초 누락 항목만 채우는 seed_scene_data를 추가했다. 1907년 기반시설·민가·보행·인물·전차를 DB에서 읽고, 건물 map_config도 같은 갱신 번들에 담는다. export/apply 명령은 현재 값의 SHA256으로 충돌을 검사하고 전체 검증 후 단일 트랜잭션으로 적용한다. 공개 API는 읽기 전용이며 ETag로 재검증한다.

update_data.sh는 사전 검사, 검증 백업, 적용, 상태 확인을 수행한다. 보행 경로 변경은 같은 멀티플레이 이미지 재시작으로 반영한다. 최초에는 새 코드·마이그레이션·compose 배포가 필요하며 이후 데이터만 갱신한다. 1750년 정적 자료와 모델 생성 코드는 이번 DB 전환 범위가 아니다.

Django 전체 71개 테스트, 검증 강화 후 관련 7개 테스트, 기존 멀티플레이 13개 및 라이브 보행 경로 1개 테스트를 통과했다. 상세 절차는 docs/scene_data_updates.md에 기록했다.
