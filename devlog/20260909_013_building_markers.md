# 013: 주요 건물·시설의 박스 표시

- 사용자 요청에 따라 3D 화면에 궁궐·제례·교육·관청·상업 시설 8개의 위치 표시 박스를 추가했다.
- 현대 위치의 대략적 좌표, 시설명·시기 설명·출처와 기호 크기를 별도 JSON으로 보존했다. 실제 건물 footprint나 높이 복원으로 표시하지 않는다.
- hover 이름, 클릭·탭 설명 고정, 선택 해제, 전체 표시 전환과 지형 높이 변경에 따른 배치를 구현했다.
- 기존 5점 TPS 및 원도 배치를 유지했다. 경덕궁은 1760년 이전 명칭을 사용하고 경복궁 전각은 추가하지 않았다.

- 검증: Django 7개 검사 통과. Tailscale Chromium에서 8개 모두 hover·클릭, 선택 고정·표시 전환·높이 변경·모바일 가로폭 검사 통과, JavaScript 오류 없음.
