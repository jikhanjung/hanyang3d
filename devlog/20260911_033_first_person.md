# 033 — 지면을 따라 이동하는 1인칭 시점

2026-09-11. ‘1인칭으로 걷기’ 버튼을 추가했다. 종로의 보행 경로 위에서 시작하며 지면 기준 눈높이는 1.65 m다.

- WASD 또는 방향키: 앞·뒤·좌·우 이동
- 마우스/터치 드래그: 둘러보기
- Shift: 빠르게 이동
- Esc 또는 전체 지도 시점 버튼: 원래 시점 복귀
- 화면 아래 방향 버튼: 터치 이동

일반 이동은 1.5 m/s, 빠른 이동은 4 m/s이며 대각선 속도를 정규화한다. 준비된 지형과 원도 표면 높이를 따라가고, 원도 0%에서는 DEM을 따른다. 높이 강조는 지형에만 적용하며 눈높이 1.65 m는 유지한다. 짧은 이동에서 고도 차가 0.7 m 이상인 절벽 및 준비된 표면 밖으로는 진입하지 않는다.

1인칭 동안 OrbitControls 갱신을 중단하고 카메라 근평면을 0.08 m, 시야각을 70도로 바꿔 가까운 모형을 볼 수 있게 했다. 복귀 시 진입 전 위치·방향·대상점·시야각·근평면을 복원한다. 다른 확대/처음 시점 버튼을 누르면 1인칭을 종료한 뒤 해당 시점으로 이동한다. 입력창·선택 상자에 입력 중인 키는 이동으로 처리하지 않으며 포커스 이탈 시 눌린 키를 해제한다.

현재는 지형을 따라가는 자유 탐색이다. 건물·성벽의 충돌, 계단·문 통로 탐색, 교량 상판을 통한 보행이나 물길 진입 제한을 구현한 게임 이동 시스템은 아니다. 별도 포인터 잠금이나 HTTPS가 필요한 입력 방식에 의존하지 않아 기존 Tailscale HTTP 주소에서도 드래그로 사용할 수 있다.

검사: `scripts/terrain/check_first_person_browser.py`에서 이동 거리, 드래그 시선, 높이 추적, 원도 표시 전환, Esc 및 다른 시점 버튼 복귀와 JavaScript 오류를 확인한다.
