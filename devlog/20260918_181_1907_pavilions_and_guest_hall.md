# 181 — 1907년 기념비전·팔각정·돈덕전·정관헌 추가

## 작업

추가 후보 연구에 이어 네 건물을 구현했다. 1907년 랜드마크는 66개에서 70개, 전체 콘텐츠 건물 seed는 180개에서 184개가 되었다.

- 칭경기념비전: 열린 기둥 사이의 비석·귀부, 기와지붕과 만세문을 단순화.
- 탑골공원 팔각정: 팔각 기단·여덟 기둥·팔각 지붕. 후대 공원 기념물은 추가하지 않음.
- 돈덕전: 2층 영빈관, 반복되는 아치 베란다와 창문·지붕. 장식과 색채는 추정.
- 정관헌: 7×5칸 열주 배열, 내부 벽돌 공간, 열린 베란다·난간.

모든 항목에 한·영 이름·안내·출처, 존속/표현 연대, 추정 위치 설명을 넣었다. 지도 클릭과 라벨은 기존 공통 동작을 이용한다. 각 유형의 원거리 모형을 추가하여 실루엣을 유지하고 재질별로 병합한다. DB 신규 import와 기존 데이터 sync 양쪽에서 상세 안내를 사용할 수 있도록 안내 문서도 갱신했다. 운영 DB는 건드리지 않았으며 다음 배포에서 동기화한다.

## 지도 판독과 한계

2667×3750 정규화 원도의 황토현 사거리·파고다공원·경운궁을 확대 확인했다. 개별 건물 기호로 확정한 좌표가 아니라 각 구역 안의 추정 좌표다. 초기 기념비전 좌표가 법관양성소 추정 모형과 겹쳐 (764,2205)로 조정했다. 기존 건물은 이동하지 않았다. 나머지 좌표와 근거는 `docs/seoul1907_next_landmarks.md` 구현 기록에 있다.

칭경기념비전 1902/1903년 이설을 안내에 유지하고 완공형 시작은 1903으로 설정했다. 돈덕전 종료 1926은 1921–1926년 훼철 범위의 상한이며 정확한 철거 연도로 단정하지 않는다. 정관헌 실측 OBJ·외부 사진 파일은 사용하지 않았다.
