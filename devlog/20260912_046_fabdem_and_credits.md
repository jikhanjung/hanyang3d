# 046 — 전체 FABDEM 지형과 출처·저작권 페이지

2026-09-12. 모전교·광통교 주변의 높은 언덕을 검토한 뒤 사용자 요청으로 표시 지형 전체를 FABDEM V1.2로 교체하고 출처·저작권 안내 페이지를 추가했다.

## 자료와 구현

사전 비교는 [FABDEM 검토](../docs/fabdem_review.md)에 기록했다. 기존 Mapzen 자료는 `data/terrain/pre-fabdem`에 보존했다. FABDEM 공식 ZIP의 N37E126·N37E127 GeoTIFF에서 표시 범위와 보간 여유를 덮는 8개 블록을 부분 다운로드했다. 원본 블록과 해시를 보존하며 전체 ZIP CRC 검증은 하지 않았다.

`scripts/terrain/build_fabdem.py`는 Float32 DEFLATE/Predictor=2를 libtiff로 해독한다. 이전 수동 정수 차분 복원과 동일한 결과를 확인했다. GeoTIFF PixelIsPoint 기준으로 동경 127도 경계를 넘는 연속 격자를 구성하고, 기존 전체 표시 범위를 401×401로 재표본화했다. 보간에 필요한 영역 모두 유효하며 임의 평활화나 결측 메우기는 하지 않았다. 원자료 수직 기준은 EGM2008이다.

새 격자의 높이 범위는 3.00–523.62m다. 타일 경계 인접 열의 차이는 중앙값 1.5m·최대 10.64m이며 자연 경사도 포함하므로 수직 오차 수치로 간주하지 않는다. 원도 변환상 모전교·광통교 위치의 기초 고도는 각각 약 28.27m·27.76m다. 새 지형에 하천 절삭·교량 받침·건물과 수목 접지 계산을 그대로 다시 적용한다.

## 출처 안내

`/credits/`에 FABDEM 저자·DOI·CC BY-NC-SA 4.0·가공 내역과 가공 고도 자료 링크를 표시한다. 옛지도·지적자료의 개별 권리 기록, OSM/OpenTopoMap, Three.js/Leaflet 저작권 및 라이선스 전문도 제공한다. 지도 오른쪽 아래 `출처·저작권` 링크로 접근하며 1인칭 미니맵과 겹치지 않도록 간격을 확보했다.

## 검사·배포

Django 11개, 고도 자료 검사 2개, 하천 수치 검사, 컨테이너 기동·누락/버전 불일치 차단·자료 응답 검사를 통과했다. 버전은 `honestjung/hanyang3d:v0.0.4`, digest는 `sha256:655b353e81cf3526c6c04c96050cd07d238dac7d5be855b949dad729a34d0011`이다.

운영 배포 완료 후 HTTPS 브라우저 검사를 통과했다. FABDEM 자료 제공, 4개 다리의 양안 접촉·진입 경사로 연결·받침 접지, 1440×1080 및 390×844 전체 화면, 확대·슬라이더·보정점·1인칭 진입과 복귀를 확인했다. 지도 모서리 링크로 `/credits/`에 이동해 출처 표시를 확인했다. 보행자 130명·나무 2,467그루·산 이름 3개·화강암이 로드됐고 페이지 오류는 없었다. 나무 수는 새 지형의 배치 필터 결과로 이전 2,468그루에서 1그루 줄었다. 전체 지형 캡처도 시각 점검했다.
