# 025 — foothill_mountain_alignment

2026-09-10

평지 보호 다각형 내부의 기존 5점 TPS 좌표를 그대로 유지하고 산기슭부터 점진적으로 남산·인왕산·백악 위치를 보정. 고도 범위 확장.

구현·원도 판독·좌표 출처·가정과 검증은 [상세 문서](../docs/doseong_walls_and_mountains.md)에 기록했다. 통합 브라우저 검사에서 성벽 2,131구간, 세 문 개구부, 평지 이동 0, 산지 목표 오차 0, 다리 진입로 오차 0.09 m 미만, 지형 전환과 JS 오류 0개를 확인했다.

보정 전후 토글과 남산 확대 시각 검토 완료. 평면 지도에서 같은 산지 좌표를 사용하는 검사도 통과했다. Django 7개, DEM 2개, TPS 및 산지 보존·접힘 단위 검사를 통과했다.
