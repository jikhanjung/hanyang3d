# 인접 도엽 추가 확인과 픽셀 정합 검토 도구

2026-09-08. 사용자 요청에 따라 1908 관인방도와 1912 인사동·낙원동 자료의 대응을 검토했다.

- 기존 육안 유사성만으로는 같은 지점을 확정할 수 없었다. 확정 control/check는 각각 0개이며 실제 변환 행렬·GCP·파일럿 GeoJSON은 만들지 않았다.
- 인사동 기록이 여러 철에 걸쳐 있음을 확인하고 6호·13호 도면의 JPEG 2건을 추가 확보했다. src-0015–0016 / asset-0010–0011로 등록, 현재 총 사료 16건·파일 11건이다.
- 6호의 다운로드 오류 후 공식 뷰어 표시 스트림을 확보했다. 해당 파일은 다운로드 원본이 아닌 표시용 제공본으로 기록했다.
- 7호 철의 두 건은 공식 뷰어에서 원문 없음 응답을 받았다. 응답 HTML과 checksum을 로컬 보존했다. 자료군 전체 접근 불가로 일반화하지 않았다.
- 프로젝트 `.venv`에 NumPy 2.5.3과 Pillow 12.3.0을 설치하고 의존성을 고정했다.
- 로컬 지도 선택·확대·회전·좌표 표시·대응점 CSV 입출력 화면과 affine CLI를 구현했다.
- control과 독립 check를 분리했다. 실제 점 수집 전 후보 판별 기준을 4 control / 2 check / 20 target pixel RMSE로 기록했다. 지리 정확도나 복원 허용 오차가 아니다.

검증: 합성 좌표 단위 테스트 3개(거부 사례는 5개 하위 조건)와 실제 카탈로그를 읽는 합성 좌표 CLI 검사 통과. 브라우저용 JavaScript는 Node 구문 검사 통과. 브라우저 엔진이 없어 실제 브라우저 UI 자동화는 수행하지 않았다. 이미지와 스냅샷 checksum·카탈로그 외래키·로컬 문서 링크 확인.

[현재 판단과 실행 방법](../docs/pixel_registration_review.md), [기계 판독 상태](../gis/control_points/insadong_review.json)를 다음 작업의 출발점으로 삼는다. 검토 HTML·도엽 비교 이미지는 `gis/georeferenced/review/`의 로컬 생성물이며 Git 제외다. 화면에서 편집한 점은 CSV로 저장해야 보존된다.
