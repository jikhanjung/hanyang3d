# 208 — 물품·음식 다운로드 날짜 예약

사용자의 “운영 배포 후 내일 물품, 모레 음식” 요청에 따라 v0.5.25 배포 완료 뒤 m710q에 사용자 systemd 타이머를 등록했다. 물품 609개는 2026-09-20 09:00, 음식 180개는 2026-09-21 09:00, 모두 한국시간이다.

복식 수집기를 category 옵션으로 확장해 같은 검증·3초 간격·재개·디스크 여유 규칙을 사용한다. 카테고리 간 잠금을 공유해 한 파일씩 요청하며, 날짜별 실행기는 NAS 검증까지 끝난 뒤에만 완료 상태를 기록한다. 로그아웃 실행(Linger), 놓친 날짜 실행(Persistent), 재부팅 때 미완료 재개, 실패 시 15분 후 재시도, 이미 완료한 작업의 재실행 방지를 적용했다. 다운로드 완료 후 NAS만 실패했으면 원본을 다시 요청하지 않는다.

날짜 이전 실행 방지, 개별 실패 기록 후 NAS 보관과 완료 재실행 방지, 중단 판별, NAS만 재시도하는 네 검사를 통과했다. systemd unit 검증과 실제 다음 실행 시각·active 상태를 확인했다. 타이머 등록 때의 부팅 점검은 “Not due”로 종료하여 예정일 전에 모델을 받지 않았다.
