# 008 — 1908 도로·하수구 판독과 1912 비교 재개

사용자의 이전 작업 계속 요청으로 1908–1912 비교를 재개했다. 새 경행방도와 기존 인사동·경운동·낙원동 도면을 대조했지만 시대 간 확정 대응점은 얻지 못했다. 자동 특징과 수동 분기 가설 모두 판독 근거가 부족해 채택하지 않았다.

도록 192쪽의 황토색 도로·푸른색 하수구 설명을 확인하고 경행방도 일부에 도로 3개 선·하수구 2개 선을 원본 픽셀 좌표로 작성했다. 원본 체크섬·기호 해석·미확정 상태를 JSON에 남기고 Django 첫 화면에서 접근하는 판독 비교 화면을 생성했다. 선들은 임시 판독이며 지리 좌표 데이터나 완성된 도로망이 아니다.

도록 192쪽의 경운동·낙원동 범위 설명이 기관 상세와 일치함도 확인했다. 7쪽의 관훈동 설명은 내부 불일치로 보존했다. [판독·비교 기록](../docs/1908_road_drain_reading.md)에 남은 검증과 재생성 절차를 정리했다.

검증: 원본 SHA-256과 모든 좌표의 이미지 범위를 확인하고 판독선을 원도에 겹쳐 시각 점검했다. Django 테스트 6개가 통과했다. Tailscale IP에서 Chromium으로 HTTP 200, 원본 표시, 판독선 5개, 표시 켜기·끄기, 전체 범위 전환을 확인했다. Django 서버는 8000번 포트에서 계속 실행한다.
