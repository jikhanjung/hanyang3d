# 203 — 채팅 왼쪽 배치와 설정 메뉴 정리

- 두 시대의 PC 채팅창을 화면 왼쪽 12px, 액션바 위로 이동했다. 모바일에서 열린 채팅창도 왼쪽에 놓는다.
- 1907년 ‘최신경성전도 · 지형 위 추정 배치 · 현대 FABDEM 고도’ 안내를 설정 메뉴 안으로 이동했다. 원본 지도 전환 시 안내가 바뀌는 기능은 유지한다.
- 1750/1907년 모두 출처·저작권 링크를 설정 메뉴 안으로 이동했다. 모바일에서도 메뉴 안에서는 글자로 표시한다.
- 시대 선택 드롭다운과 ‘1인칭 시점’ 버튼을 한 줄에 묶었다. 접속 종료 후 버튼 이름도 같은 문구로 돌아온다. 활성 상태의 전체 지도 시점/접속 취소 동작은 유지한다.
- 1907년 말 장수 보기·전차 보기 버튼과 시점 이동 핸들러를 제거했다. 말 장수를 포함한 인물과 전차의 표시는 기존 사람·전차 체크박스로 제어한다. 원본 지도/전체 보기 버튼은 유지한다.

검증: 실제 채팅 모듈의 PC 1280/800px·모바일 390px 왼쪽 배치와 액션바 간격, 두 시대 템플릿의 PC/모바일 메뉴 개폐에 따른 안내·출처 링크 표시, 시대/1인칭 버튼의 같은 줄 배치를 브라우저에서 확인했다. 기존 말 장수 대화·거래 데이터 테스트 1개, JavaScript 구문 및 diff 검사를 통과했다. 메뉴 레이아웃 검사는 렌더링한 템플릿을 사용했으며 지도 전체를 기동한 검사는 아니다.

아직 운영 배포 전이다.
