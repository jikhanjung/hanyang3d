# 175 — 건물 설명 선택 시 시점 유지와 추가 후보

1907년 건물과 이름표를 클릭하면 시점과 1인칭 상태를 유지하고 설명만 열도록 변경했다. `showBuilding`의 기본 동작은 설명 표시이며, 설정의 ‘건물로 이동’ 선택에서만 `focus:true`로 이동한다. 다리 이름표도 같은 규칙을 따른다.

앞서 요청한 추가 건물 검토는 기존 66개 객체와 대조하고 [후속 후보 문서](../docs/seoul1907_next_landmarks.md)에 기록했다. 전차 차고·발전소, 단성사, 손탁호텔, 배재학당, 도동 세브란스병원, 이화학당을 제안하고 대한의원 공사 단계·대한매일신보 사옥 이전 문제는 별도 확인 대상으로 남겼다.

브라우저 검사에 건물 클릭·이름표 선택 후 카메라 위치·회전·1인칭 상태 불변과 이동 목록의 이동 동작을 추가했고 PC·모바일에서 통과했다. 실제 카메라 위치·방향은 유지되며 기존 줌 기준점 보정은 유지한다. 아직 추가 건물 구현·배포는 하지 않았다.
