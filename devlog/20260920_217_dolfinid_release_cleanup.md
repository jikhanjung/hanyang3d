# dolfinid 한양3D 구버전 배포 파일 정리

사용자가 요청한 운영 서버 디스크 정리. `dolfinid-2`에서 실행 중인 모든 컨테이너 이미지와 bind mount를 확인한 후 한양3D의 생성물만 정리했다.

- 제거 버전: v0.5.9, v0.5.20, v0.5.21, v0.5.22, v0.5.23, v0.5.25, v0.5.26.
- 범위: 해당 웹/멀티플레이 이미지(존재하는 태그만, 강제 삭제 없음), `/srv/hanyang3d/data/<version>`, `~/hanyang3d-release/`의 해당 data/host 압축파일 및 체크섬.
- 보존: 운영 웹 v0.5.28·직전 v0.5.27, 현행 멀티플레이 v0.5.24 및 대응 데이터. DB·설정·백업·Docker 볼륨·다른 서비스에는 변경 없음.
- 삭제 전에 정리할 데이터 디렉터리가 어느 컨테이너에도 마운트되지 않았고 이미지가 사용되지 않음을 검사했다.
- 디스크: 58GB 중 사용량 약 47GB → 41GB, 여유 약 11GB → 17GB, 사용률 82% → 72%.
- 정리 뒤 한양3D 웹·멀티플레이 healthy 확인. 다른 서비스 컨테이너도 계속 실행 중.

현재 DB는 migration 0008/0009가 적용돼 있으므로 v0.5.27 이미지만 교체하는 롤백은 거부된다. 롤백을 수행할 때는 그 버전의 검증 DB 백업을 포함한 별도 복원 절차가 필요하며, 이번 작업은 복원을 수행하지 않았다.
