# 012: 도성 전체 3D 지형 오버레이

- 앞선 누적 작업을 `33ffef0`으로 커밋하고 origin/main에 푸시했다.
- 사용자 요청대로 기존 5점 TPS를 유지한 3D 지형 화면을 `/gis/terrain/3d/`에 구현했다.
- 공개 Terrarium 고도 타일 4개를 취득하고 257 × 257 격자를 생성했다. 원본·출력 체크섬은 별도 manifest에 보존한다.
- 회전·기울임·확대·이동, 원도 투명도, 높이 강조, 기준 위치, 위에서 보기, OSM 배경 전환을 제공한다. 첫 화면과 기존 평면 화면에 진입 링크를 추가했다.
- Django 7개·고도 2개·TPS 검사 통과. Tailscale Chromium에서 실제 렌더링과 조작, 5개 점의 수평 위치 일치, OSM 요청 성공, 모바일 가로폭과 페이지 오류 없음을 확인했다.
- 고도 원본과 파생 격자는 로컬 Git 제외 파일이다. 현대 지형의 개관이며 역사 지형·건물은 복원하지 않았다. 다음은 사용자 화면 검토와 주요 길·하천·성곽 판독이다.
