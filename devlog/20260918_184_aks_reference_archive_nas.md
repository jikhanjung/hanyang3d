# 184 — AKS 원본 모델·PDF 확보와 NAS 복사

사용자가 제공한 세 건축물 표에서 중복 제거한 GLB URL 1,034개를 발견했다. 한 파일씩 완료 후 최소 3초 간격으로 요청했고 실패 시 최소 10초 후 한 번 더 시도했다. GLB 1,015개(178.41GiB) 검증 완료, 19개는 HTTP 404로 실패했다. GLB 헤더·길이·청크·JSON과 SHA-256, 외부 참조·필수 확장을 기록했다. 이는 건물 수가 아니라 담장·문·부분 모델을 포함한 파일 수다.

대문에서 연결된 복식·물품·음식 목록도 수집했다. 고유 URL은 각각 414·609·180개, 합계 1,203개다. 이 세 분야는 CSV/JSON 목록과 단계별 수집 계획만 작성했으며 바이너리 수집을 시작하지 않았다.

한양도성 타임머신 2022 소개 및 2022 참고문헌 페이지에 직접 연결된 PDF 92개(10.37GiB)는 건축 GLB 작업 종료 후 직렬 수집했다. 모든 PDF의 헤더·pdfinfo·SHA-256 검증을 완료했다.

NAS `/nas/JikhanJung/hanyang3d_backup/research/aks-hanyang/`에 원본·HTML·목록을 복사했다. 임시 파일을 제외하고 복사본 해시가 원본 manifest와 같은 파일만 채택했다. 최초 완료 시 1,128개 약 188.79GiB이며, 검증된 GLB/PDF 1,107개 전부가 NAS 상태 기록과 일치하고 누락이 없었다. 이후 문서 갱신도 다시 복사한다. 확인 시 개발 PC 여유 411GiB, NAS 여유 약 12.5TiB다. 기존 운영 DB 백업은 변경하지 않았다.

원본은 Git·Docker에서 제외하고 수집 도구·출처·해시·실패 기록을 커밋한다. 제작 연도와 역사적 존속·형태는 별개다. 실측·복원·재현을 일괄 스캔으로 부르지 않으며 개별 라이선스를 확인하기 전 앱 배포 자산으로 쓰지 않는다.

자세한 경로·재개 절차·실패 목록은 [보관 안내](../docs/aks_archive_storage.md), 후속 계획은 [수집 계획](../docs/aks_3d_collection_plan.md)을 따른다.
