# 144 — 1907년 건물 제작 목록과 첫 세 정전

## 요청과 범위

1907년 건물을 중요도 순으로 정리하고, 옛지도에서 위치를 찾아 하나씩 만든다. 후보 16곳의 우선순위·위치 판독 상태를 `docs/seoul1907_landmarks.md`에 기록하고, 첫 묶음으로 근정전·중화전·인정전의 개념 모형을 구현했다. 다음은 경회루·광화문이다.

## 구현

- 최신경성전도의 전각 기호 중심을 직접 읽어 북쪽 위 정규화 이미지 좌표로 저장. 현대 위치를 그대로 복사하지 않고 원도 affine 정합 사용.
- 근정전 5×5칸·중층, 중화전 1906년 중건 단층, 인정전 1804년 중건 중층. 월대·기둥·창호·회랑·문·품계석을 공통 정전 생성기로 단순화했다. 치수와 상세 배치는 추정이며 실측 복원이 아니다.
- `gis/buildings/1907_landmarks.json`과 `models/landmarks/seoul1907/*.json`에 위치·연대·근거·치수·좌표축·라이선스·불확실성 기록. 1907년 미완공 석조전은 후보 연구로 보류.
- 기존 콘텐츠 DB에 세 건물 추가. `scene_year`로 1750년과 1907년 화면 분리. `import_content` / `sync_content`가 두 시대 seed를 취급하고, 전체 콘텐츠 건강 검사는 양쪽 시대를 확인한다. DB schema migration 없음.
- 원도 해시 검증을 시대별로 분리. 1907년에는 EXIF 회전을 정규화한 이미지 해시와 asset-0024를 요구한다.
- 이름표·건물 선택 메뉴·가까이 보기·연대/출처 패널. 모바일에서 선택 후 메뉴 접기와 관찰 거리 조정. 원본 지도 모드에는 3D 이름표·모형을 겹치지 않는다.
- 조정 중심과 전각 중심의 차이를 생성기 `hallCenterZ`로 보정. 지형 위 기단을 만들어 건물이 뜨지 않게 지지하며 지도 opacity와 독립된 고도 유지.
- 건물 안내 KO/EN 및 출처·저작권 페이지에 실제 사용한 건축 설명 자료 추가.

## 데이터 안전과 확인

로컬 콘텐츠 DB를 SQLite backup API로 `/tmp/hanyang3d-before-1907-buildings.sqlite3`에 백업하고 integrity_check=ok를 확인했다. sync 미리보기에서 추가 3·영문 안내 갱신 3·충돌 0을 확인한 뒤 적용했다. 총 건물 117개 중 1750년 114개, 1907년 3개다. 재실행 미리보기는 추가·갱신·충돌 0이다. 기존 안내 문서와 DB의 문단 차이 2건은 편집 내용 보존 정책에 따라 강제 동기화하지 않았다.

- Django 관련 테스트 45개 통과(시대 분리, 원도 해시 교차 거부, DB 편집 보존, 번역, 기존 지도 포함).
- 마지막 메타데이터·출처 수정 후 관련 테스트 10개 재통과.
- Django system check, migration 변경 없음, git diff --check 확인.
- 브라우저 검사: `scripts/georeference/check_seoul1907_browser.py --url http://127.0.0.1:18029 --serve`. 별도 테스트 서버가 도중 종료된 첫 실행은 시대 전환에서 실패했으며, 서버 생명주기를 검사 스크립트에서 관리하도록 보완했다. 재실행은 PASS: 세 모형·지붕 층수 2/1/2, opacity 0%에서 위치 불변, 원본 전환, 모바일 건물 이동, 1750년 화면 전환 및 JS 오류 없음 확인. PC·모바일 스크린샷을 육안 검토했다.

운영 배포·이미지 빌드·commit/push는 이번 작업에서 실행하지 않았다. 운영은 기존 v0.5.0 그대로다.
