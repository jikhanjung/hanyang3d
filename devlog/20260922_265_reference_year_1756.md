# 265 — 1750년 장면의 기준 연도를 1756년으로

도성대지도의 제작 시기는 서울역사박물관 유물 설명대로 **1753~1760년**이다(육상궁 1753년 승격 표기로 상한, 북한산성 암문의 1760년 대남문 개칭 전 표기와 1760년 준천 뒤 수표 미표시로 하한). 그동안 '1750년경'으로 부르던 기준을 제작 창의 가운데인 **1756년**으로 옮기고, 화면 표기는 **"1750년대 중엽"**(영어 mid-1750s)으로 바꿨다. 장면 키(`scene_year: 1750`, 파일 이름, URL)는 그대로 두어 DB·동기화에 영향이 없다.

## 바뀐 것

- `gis/buildings/1750_landmarks.json`: `period`·`reference_year: 1756`·`reference_note` 추가, 추정 모형 14개의 `depiction.reference_year` 1750→1756. 1750년에 상대적으로 적었던 문구("세운 지 8년째", "막 중건한 무렵")를 1756년 기준으로 고쳤다.
- **육상궁**: 지도 표기 그대로 '육상궁'으로 되돌렸다(1753년 승격 뒤). 기록 253에서 1750년 기준으로 '육상묘'로 바꾼 것을 되돌린 것이다.
- 화면: 제목·시대 선택의 '1750년경' → '1750년대 중엽', 건물 팝업의 '1750년 무렵' 소제목 → '1750년대 중엽'. `Building.in_1750` 필드는 이름을 유지하고 표시 이름만 바꿨다(migration 0015, 데이터 이동 없음).
- 창덕궁 수문장 대사(기록 263)를 1756년 시점으로 다시 썼다: 대리청정 일곱 해째, 왕 예순 넘김·세자 스물둘, 1752년 첫 원손 요절과 둘째 원손(뒷날 정조) 출생, 이제 다섯 살.
- `SceneYearTests`는 1750년 목록을 1756년 기준으로 검사한다. `docs/landmarks.md`·`docs/seoul1907.md`·재검토 문서에 기준 연도를 적었다.

## 검증

Django 테스트 95개 통과. 임시 서버 한·영에서 제목·시대 선택 표기와 육상궁 이름, 돈화문 수문장 대화를 확인했다.

운영 반영 전이다. 배포 시 육상궁 이름·설명이 동기화 갱신으로 잡힌다.
