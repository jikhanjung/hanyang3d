# 156 — 1907년 걷기·거리 인물과 모바일 봇짐 사용

2026-09-18. 운영 v0.5.6 이후 로컬 구현. 배포·commit/push는 수행하지 않았다.

## 변경

- 1750년의 걷기 코드를 `first_person.js`로 분리하고 두 시대에서 사용한다. 키보드·모바일 조이스틱, 시선 회전, 자동 걷기, 점프, 말 타기, 지면 접지, 저장 위치를 유지한다. 1907년에는 지도 정합을 반영한 반투명 미니맵을 추가했다.
- 1907년 행인 128명, 종로 상인 12명, 대한문·돈화문·근위대대 권역 경비병 6명을 추가했다. 멀리 있는 상인·경비병은 숨기고 보행자는 인스턴싱한다. 조감도에서는 카메라나 UI 변화가 없을 때 연속 렌더를 피한다.
- 1907년의 실제 도로 중심선에서 경로를 만들고 지도 변환을 브라우저·Node에서 공유한다. 흥인지문 옹성 및 일부 상점과 겹치는 경로는 왕복 구간 끝을 제한했다. 원도 도로 판독선 자체는 변경하지 않았다.
- 계정·봇짐·물건·거래 API를 공유한다. 행인·상인·경비병 클릭 대화와 사실 설명의 출처 링크를 연결했다. 대사는 창작, 인물·업종 배치는 추정, 가격과 엽전은 놀이 설정이라고 구분했다.
- 멀티플레이 `seoul1907` 공간을 추가하여 1750년과 방·NPC 경로·마지막 위치가 섞이지 않게 했다. 인증·채팅·서버 NPC 동기화는 기존 기능을 사용한다.
- 모바일 봇짐의 사용 가능한 물건에 44px 이상의 **쓰기** 버튼을 추가했다. PC 오른쪽 클릭 사용도 유지한다. 1750년과 1907년 모두 공통 적용된다.

## 복식 근거

[복식 조사와 구현 범위](../docs/seoul1907_people_and_walking.md)에 자료별 판단을 기록했다. 국립민속박물관 1906년 남경세·성진 여성 사진을 직접 확인하고 밝은 두루마기·갓, 저고리·치마 형태를 단순화했다. 서울의 인구·착용 비율을 이 사진으로 일반화하지 않는다. 군복 자료는 의식용 예복이므로 근무복의 세부 제식 확정 근거로 사용하지 않았다. 경비병은 1907년 하반기 근위 병력의 개념 모형으로 부대 표장·정확한 색·초소·인원은 미확정이다. 참고 사진을 서비스 텍스처로 복제하지 않았다.

자료와 대화는 `gis/characters/seoul1907.json`, 경로는 `gis/roads/seoul1907_walking_routes.json`. 연대·출처·추정 상태를 기록했으며 계정과 거래는 기존 DB에서 관리한다.

## 검증

- Django 전체 테스트 62개 통과. 새 공개 리소스가 6개 증가하여 리소스 개수 기대값을 127개로 갱신했다. 1907년 화면이 계정·상품 DB를 사용하므로 기존 SimpleTestCase를 TestCase로 변경했다.
- 1907년 CSRF·걷기 데이터 삽입 검사를 보강한 뒤 해당 테스트 6개 재검증 통과.
- Node 단위 테스트 13개 통과. 처음 추가한 테스트에서 반환 오류를 예외로 오인한 기대값을 실제 계약에 맞게 수정했다.
- 기존 1907년 지도 브라우저 검사 통과: 65개 모델, 지형·원본 지도·투명도·PC와 모바일 메뉴·시대 전환.
- 임시 DB와 로컬 Node 서버를 사용하는 `scripts/terrain/check_1907_walk_browser.py` 통과: 시대별 방 분리, NPC 128명 동기화, 채팅, 1907년 로그인·걷기·점프·눈높이·성문 충돌·상인 클릭과 실제 구매·경비병 대화 출처.
- 모바일 실제 터치: 조이스틱 이동과 동시 시선 회전, 미니맵/점프 버튼 분리, 말고삐 구매 후 봇짐의 **쓰기**로 타기·내리기 검증. 처음 거래 대기 검사는 시간 초과했고 거래 응답을 관찰하는 재검사에서 서버 잔액·보유 물건과 사용 결과를 확인했다.
- 공통화 이후 기존 1750년 컨트롤 회귀 검사 통과: 우클릭 시선, 좌클릭 방향, 자동 걷기, 반복 점프. 검사 계정은 임시 DB에서만 생성한다.
- 경로 충돌 감사: 10m 간격 표본에서 건물·성벽 충돌 0건. 세부 보행자 차선·회피는 시각화 모델이다.
- `/tmp/1907-mobile-pack.png`, `/tmp/1907-mobile-walk.png`, `/tmp/1907-merchant-dialog.png`를 육안 확인했다.

운영 반영에는 **웹과 멀티플레이 이미지 모두 갱신**해야 한다. 기존 멀티플레이 v0.3.14는 1907년 공간을 지원하지 않는다. 현재 배포 버전은 그대로 v0.5.6이다.
