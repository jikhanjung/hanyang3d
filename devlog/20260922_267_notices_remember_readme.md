## 채팅창의 놀이 알림

말에 오르거나 내릴 때, 물건을 쓰거나 꾸러미를 받을 때의 문구가 봇짐 창과 액션바에만 잠깐 보였다. 이제 같은 문구를 걷기 채팅창의 기록에도 조용한 회색 줄로 남긴다(`walk_chat.js`의 `system()`). 함께 걷기에 접속하지 않았을 때도 PC에서는 채팅창이 기록만 보여 주는 상태로 열리고(입력칸 없음), 휴대폰에서는 채팅 버튼에 읽지 않은 수가 붙는다. 1인칭을 나가면 기록을 비운다. `shop.js`의 `onMessage` 훅으로 1750·1907년 두 시대에 같이 연결했다.

## 로그인 기억하기

- 놀이 계정(이름·비밀번호): 대화상자에 「이 기기에서 기억하기」(기본 켬). 켜면 서명된 플레이어 쿠키를 1년 유지(기존과 같음), 끄면 브라우저를 닫을 때까지만 유지한다. `/api/account/login`·`register`의 `remember` 값으로 서버가 쿠키 수명을 정한다.
- 도성도감(운영진): 로그인 화면에 「기억하기 (30일 동안 로그인 유지)」(기본 켬). 끄면 브라우저 종료 시 세션이 끝난다.

놀이 계정은 원래도 1년짜리 쿠키였다. 다시 로그인을 요구받았다면 쿠키가 지워졌거나 다른 브라우저·기기였을 가능성이 크며, 이번 변경은 그 동작을 명시적으로 고를 수 있게 한 것이다.
