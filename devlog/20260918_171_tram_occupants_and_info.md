# 171 — 전차 운전수·승객, 속도 조정과 차량 정보

사용자 후속 요청 세 가지를 반영했다.

- 운전수 1명·남녀 승객 4명 추가. 승객은 개방 좌석에 앉고, 운전수는 진행 방향 조종대에서 차량 역방향 전환에 맞춰 이동한다. 차체의 경사·이동과 LoD를 그대로 따른다.
- 시각화 속도를 3→3.6m/s(약 13km/h)로 20% 올렸다. 인원·제복·색상·속도는 추정 표현이라고 명시했다.
- 전차 클릭/탭 시 노선·1907년 운영 회사·모형 설명·추정 범위와 지도 및 문헌 출처 링크가 열린다. 드래그는 선택으로 처리하지 않고, 가려지거나 숨긴 차량은 선택하지 않는다. ‘전차 보기’ 버튼과 같은 정보창을 사용한다. 한영 번역도 추가했다.

`gis/transport/seoul1907_trams.json`에 출처 제목과 인원 설정, 속도를 기록했다. 기존 자료 조사 문서에 후속 기록을 추가했다. `scripts/terrain/check_1907_trams_browser.py` PC/모바일 통과: 차량 이동·왕복·운전수 전환·승객 수와 부착·레일·투명도 높이 불변·보행자 회피·정지와 재출발·직접 클릭과 터치 정보창·출처 링크. 화면 캡처로 인물 배치를 확인했다. JavaScript 오류 없음. `git diff --check` 통과. 배포는 하지 않았다.
