# devlog 인덱스

오늘 수행한 작업과 확인 결과, 미완료 사항을 기록합니다.

## 파일명 규칙

- 작업 결과: `YYYYMMDD_{nnn}_{title}.md` — 001부터 저장소 내 단조 증가 번호
- 계획 문서: `YYYYMMDD_P{nn}_{title}.md` — P01부터 별도 번호
- title은 영문 snake_case로 작성합니다.

`fsis2026/devlog/`의 규칙을 따르되 번호는 이 저장소에서 독립적으로 부여합니다. 지속적으로 갱신하는 프로젝트 실행 계획은 `docs/plan.md`에서 관리합니다.
