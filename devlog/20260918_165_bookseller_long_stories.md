# 165 — 책방 주인의 16편을 긴 대화로 확장

사용자가 이야기들이 지나치게 짧다고 지적하여 한 장면 요약이었던 1907년 책방 주인 대사를 16편 × 4장면, 총 64장면으로 늘렸다. 한국어 본문은 편당 638–705자, 평균 685자이며 영문도 같은 구조로 확장했다.

## 구성과 근거

짧은 도입 → 구체적 배경/전개 → 방문객의 질문 → 거리 생활·다른 장소와의 연결 순서로 대화를 이어 간다. 질문별 다음 장면, 이전 장면, 주제 목록, 이야기 목록, 닫기를 둔다. 제목과 1/4–4/4 진행 표시, 장면 전환 시 스크롤 초기화로 모바일에서 읽는 위치를 잃지 않게 했다. 다른 NPC의 기존 대화에는 진행 표시가 생기지 않는다.

전차 도입, 군대 해산, 국채보상운동, 관민공동회는 우리역사넷 원문·해설을 다시 확인했다. 나머지는 기존 조사 초안의 출처·확인 범위 안에서 확장했다. 중명전→신문 논설, 헤이그→강제퇴위·군대 해산처럼 연결되는 장면에는 해당 출처를 추가했다. 북묘 왕실 동선의 미확정, 수도의 미완공 상태와 모금 운동의 아직 알 수 없는 결과를 유지한다. 가정 장면과 책방 주인의 생활 비유는 기록된 목격담과 구분했다.

런타임 `gis/characters/seoul1907.json`과 검토용 `docs/seoul1907_bookseller_script.md`에 저장했다. 대화 틀은 `webapp/static/npc_dialogue.js`. 16개의 도입 story_id를 유지하고 48개 후속 장면은 parent_story_id를 사용한다. DB·건물·거래 기능 변경 없음.
