# 241 — 기술 현황·Steam 전환 보고서

사용자 요청으로 [기술 보고서](../docs/technical_report_steam_feasibility_20260920.md)를 docs/에 작성했다.

- 코드 기준 `3efb678`, 배포 설정 웹 v0.5.35·멀티플레이 v0.5.31을 구분했다.
- 기술 스택, 구현 기능, 190개 건물 레코드, 연구 GLB·PDF 수량과 로컬 저장 규모를 조사했다. 런타임과 연구 보관소, 구현된 대사와 이벤트 설계를 분리했다.
- 계정·경제의 SQLite, 위치의 localStorage, 실시간 상태의 Colyseus 메모리 경계를 설명했다. 오래된 README의 정원·로그인 설명 대신 실제 코드를 확인했다.
- Steam·Electron·FABDEM 공식 문서를 확인하고 FABDEM 상업 이용 권리와 외부 GLB 미확정 권리를 선행 조건으로 기록했다.
- Windows 프로토타입 5~10인일, 온라인 출시 40~70인일, 오프라인 포함 70~120인일, 엔진 이전 160~280인일을 가정·제외 범위·불확실성과 함께 제시했다. 검증된 견적이나 출시일 보장이 아니다.
- 문서의 로컬 링크 존재 여부 및 diff 공백 검사 완료. 실행 코드는 바꾸지 않았으며 성능·부하 시험을 새로 수행했다고 주장하지 않는다.
- 다운로드 진행으로 변경된 AKS manifest/CSV는 읽기만 했고 이 커밋에는 포함하지 않는다. 운영 배포 없음.
