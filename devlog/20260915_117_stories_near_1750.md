# 117 — 1750년 전후의 사건을 장소 이야기로 추가

## 요청과 반영

이벤트 자료집에서 1750년 인근 사건을 골라 지도에서 읽을 수 있는 이야기로 추가했다. 기존 29개에 4개를 더해 총 33개(건물 29, 다리 2, 동네 2)다.

| 장소·연도 | 제목 | 직접 확인한 사료 |
|---|---|---|
| 종묘 · 1749 | 세자가 정무를 맡는다는 소식 | [영조 25년 음력 1월 27일 제1기사](https://sillok.history.go.kr/id/kua_12501027_001) |
| 홍화문 · 1750 | 궁문 앞에서 군역의 부담을 묻다 | [영조 26년 음력 5월 19일 제1기사](https://sillok.history.go.kr/id/kua_12605019_001) |
| 비변사 · 1751 | 우리 동네는 어느 성벽을 지킬까 | [영조 27년 음력 9월 11일 제2기사](https://sillok.history.go.kr/id/kua_12709011_002) |
| 흥인지문 · 1760 | 공사에 나온 사람과 집을 잃은 사람 | [영조 36년 음력 2월 20일 제1기사](https://sillok.history.go.kr/id/kua_13602020_001) |

자료집 E043/H17, E044/H18, E046/H19, E049/H21에 대응한다. 공개 실록 국역·원문 페이지를 열어 확인하고 짧은 문장으로 새로 썼다. 이야기 JSON을 기존 카드와 안내가 함께 사용하므로 UI 코드는 변경하지 않았다.

## 서술 판단

- 종묘 고유를 왕이나 세자가 직접 종묘를 방문한 것으로 바꾸지 않았다.
- 홍화문의 의견 청취와 함께 주민 답변을 유도했다는 사관의 비판을 명시했다.
- 수성윤음은 방어 준비이며 실제 전투 기록으로 쓰지 않았다. 비변사는 규정 보완 담당 기관으로 연결하고, 하교 장소나 개별 성벽 배당은 특정하지 않았다.
- 1751년·1760년은 1750년으로부터 각각 한 해·10년 뒤라고 본문에 밝혔다.
- 흥인지문에서는 기존 수표교 이야기와 중복되는 공사 규모보다 부역민 지원과 철거된 냇가 주택 주민의 구휼을 다뤘다. 명령이 있었다는 사실과 지원이 실제 완료되었다는 주장을 구별했다.

## 다음 구조 개선

사용자가 콘텐츠 DB 관리와 멀티플레이 독립 배포 필요성을 제기했다. 현재는 웹·멀티플레이·데이터가 같은 릴리스 버전을 사용한다. 후속 설계에서는 이야기·출처·장소 연결을 Django 관리 화면과 DB로 옮기고, 공개 콘텐츠의 캐시 갱신, 초기 JSON 가져오기, 운영 편집 데이터 보존·백업·복구를 함께 다룬다. 지도·지형 파일은 버전 묶음으로 유지할 수 있다. 멀티플레이 이미지 태그와 방의 지도/통신 호환성 키를 웹 콘텐츠 버전에서 분리해야 한다. 이번 배포에서는 DB 도입이나 배포 구조 변경을 하지 않았다.
