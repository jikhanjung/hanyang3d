# 005 — 1908 공통 경계 도엽 연결과 독립 검사

사용자의 계속 진행 요청에 따라 경행방 제3호를 추가 확보했다. 총 사료 17건·파일 12건이며 1908 지도 JPG는 4건이다.

관인방 제1호와 경행방 제3호의 공통 방 경계에서 원본 대응점 9개를 판독했다. control 5개로 affine을 계산하고 계산에 사용하지 않은 check 4개에서 RMSE 3.3098 px, 최대 5.0054 px를 얻었다. 역할은 계산 전에 고정했으며 결과에 맞춰 점을 재조정하지 않았다.

원본과 대응점 체크섬을 검증하는 겹침 화면 생성기를 추가했다. 지도 투명도·범위 전환, 대응점·잔차·근거, 원본 점별 확대 비교를 제공한다. 입력 CSV와 수치 요약은 Git 관리, 원본과 재생성 가능한 결과는 Git 제외다. [재현 명령과 해석 범위](../docs/1908_sheet_join.md)를 참고한다.

1908–1912 자동 특징 대응도 탐색했으나 동일 대상점에 집중되는 퇴화 변환이 나와 채택하지 않았다. 국가기록원 BJCA000141의 docid 0014177159 뷰어에서 색인 원문 취득도 시도했으나 스트림은 빈 응답, 다운로드는 오류 HTML이어서 asset으로 등록하지 않았다. 색인 도면을 실제로 확인한 것으로 간주하지 않는다.

성과는 같은 해의 두 도엽 사이 상대 픽셀 정합이다. 현대 좌표 정합과 1908–1912 대응점 확정은 여전히 남아 있다. 다음 작업은 연결된 1908 가로망의 분기를 판독해 1912 도면과 비교하는 것이다.

검증: 카탈로그 17개 출처의 식별자와 파일 12건의 SHA-256·크기·JPEG 치수를 대조했다. affine 단위 테스트 3개 통과, 실제 결과 재계산 시 JSON 일치, 입력 변조 거부 및 알려진 평행이동으로 이미지 역변환 방향을 확인했다. 대응점 원본 확대와 겹침 결과를 시각 검토하고 JavaScript 문법 검사를 통과했다. 실제 브라우저의 클릭 동작은 미검증이다.
