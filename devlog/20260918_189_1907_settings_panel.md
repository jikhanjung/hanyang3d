# 189 — 1907년 설정 패널 정리

1750년 설정 패널처럼 PC는 두 열, 모바일은 한 열로 표시한다. 1인칭 버튼과 옛지도 투명도를 위쪽에 놓고 건물, 길·물길·성벽, 사람·이름, 전차 체크박스를 묶었다. 건물 선택, 말 장수·전차 보기, 원본 지도·전체 보기는 아래에 배치했다. 반투명 배경과 기존 기능은 유지한다.

좁은 화면에서는 세로로 스크롤할 수 있으며 슬라이더·건물 선택 상자가 패널 너비에 맞춰 줄어든다. 투명도 슬라이더에 접근성 이름을 추가했다.

검증: Django 시대·번역 테스트 14개 통과. Chromium 1100×800 한국어, 390×844 한국어, 320×568 영어에서 가로 넘침 없음, 패널이 화면 높이 안에 표시됨, 체크박스 8개 토글, 투명도 값 반영, 1인칭 로그인 진입 확인. PC·모바일 스크린샷 확인.

이 변경은 v0.5.18 배포 이후 작업이며 아직 운영에 반영하지 않았다.
