# 172 — 1907년 건물 직접 선택과 이름표 가림

v0.5.14 배포 진행 중 사용자 추가 요청을 반영했다. 전차 선택에 사용한 화면 raycast를 건물에도 적용하여, 건물 모형을 클릭·탭하면 이름표 선택과 같은 건물 안내가 열린다. 드래그와 숨긴 물체는 선택하지 않으며, 눈앞 물체가 가린 건물을 관통해서 선택하지 않는다.

1907년 이름표는 HTML 요소라 3D 깊이 검사 없이 전면에 표시되고 있었다. 카메라에서 이름표 기준점까지 다른 건물이 막는지 검사해 이름표를 숨긴다. 앞 건물을 숨기거나 시점을 바꾸면 다시 판단한다. 자기 건물은 가림 대상에서 제외한다. 미리 계산한 건물 바운딩 박스로 후보를 좁힌 후 현재 보이는 LoD 메시만 정밀 검사한다. 1750년 Sprite 이름표는 이미 depthTest를 사용하므로 변경하지 않았다.

`check_1907_trams_browser.py`에서 PC·모바일 건물 클릭/탭, 드래그 무선택, 다른 건물에 의한 가림과 건물 숨김 후 재표시, 자기 건물 제외를 검증했다. 기존 전차 탑승 인물·속도·정보창·왕복·회피 검사도 통과했다. v0.5.14에 함께 포함한다.
