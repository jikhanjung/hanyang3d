# 158 — 1907년 로딩 진행 표시 통일

1750년과 1907년이 동일한 로딩 패널 템플릿·스타일을 사용하도록 `scene_loading.html`, `scene_loading_style.html`로 추출했다. 기존 1750년 8단계는 유지하고, 1907년은 실제 작업 완료에 따라 6단계 프로그레스바를 갱신한다. 바이트 다운로드 비율이나 예상 시간이 아니다.

1907년은 고도 자료 → 지형·옛지도 → 주요 건물·문 → 성벽·길·물길 → 사람·상인 → 마무리 순서로 표시한다. 지형부터 화면에 그리고 다음 단계를 시작하기 전에 브라우저에 그리기 시간을 준다. 로딩 중에도 지도 조작이 가능하며 이름표는 배치가 끝난 뒤 표시한다. 완료하면 패널을 숨기고 실패하면 현재 화면을 유지하며 다시 불러오기 버튼을 제공한다. 새 상태 문구의 영어 번역도 추가했다.

확인: Django 시스템 검사, 1907년 테스트 6개, PC·모바일 실제 브라우저 단계 진행·완료·65개 건물 유지, 고도 요청 실패 시 모바일 패널 크기·다시 불러오기 성공. 운영 배포는 아직 하지 않았다.
