# 022 — 서촌·인왕산 방향 상류와 종단 고도

2026-09-10

사용자가 광화문사거리 근처에서 끝난 물길의 북쪽 연장을 요청했다. 원도 asset-0001의 수로를 판독하고 기존 첫 4점 대신 서촌과 인왕산 동쪽 골짜기로 이어지는 42점을 넣어 총 75점으로 연장했다. 시작 (790, 917), 북쪽 굴곡 (1127, 1440), 기존 본류 (1264, 1515)로 연결한다. 원도 위 판독선을 직접 검토했다. 4개 다리의 픽셀은 유지하고 line_index를 다시 지정했다.

상류 반폭 2.5 px에서 본류 8 px까지 보간하고 물길·하도 폭에 함께 적용했다. 기존 하류 방향 수면 기준에 최대 종단 경사 8%의 역방향 제한을 추가해 급격한 DEM 낙차를 낮추는 방식으로 완화한다. 역사적 수위·실측 폭·발원점 복원이 아니다. 다른 합류 지류와 상류 교량은 미판독 상태다.

‘서촌 상류 확대’ 버튼 및 전체 구간 원도 판독 SVG를 추가했다. 단위 검사에서 하류 방향, 최대 경사, 절토 조건을 확인했다. 브라우저 검증은 check_bridge_connections_browser.py에 상류 높이·폭·다리 인덱스 일치를 추가하여 수행한다.

브라우저 검사 통과: 75점, 수면 기준 상류 50.53 m→하류 24.48 m(실제 수면 표시는 +4.35 m 오프셋), 상류 반폭 5.51 m→하류 15.91 m, 모든 구간 하류 방향·8% 이내 경사, 다리 4개 인덱스 일치. 깊이 2/5 m, 강조 1/2배, 보정 전환, 다리 양안 접촉·경사로 hover 검사와 JS 오류 0개 확인. 확대 스크린샷 /tmp/hanyang-seochon-upstream.png 시각 검토 완료. 기본 최대 지형 낮춤은 현재 약 41.3 m이며 역사적 수심이 아니다.
