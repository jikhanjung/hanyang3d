# 284 — 광화문·육조거리 사진 자료 추적

광화문광장 140년을 사진으로 다룬 영상(대한여지도 Korean Geographic)의 설명란 이미지 출처를 기관별로 추적해 [docs/gwanghwamun_photo_sources.md](../docs/gwanghwamun_photo_sources.md)에 정리했다. 영상 화면은 볼 수 없어 설명란 제목·날짜와 기관 기록을 맞췄고, 항목마다 기록 번호·주소·이용 조건·확실도를 적었다.

1907년 장면에 바로 쓸 만한 것은 Moffett 소장 1890년대 육조거리 사진(Princeton), 『조선고적도보』 10권의 광화문 전경(도판 4544)과 경복궁 배치도(4542), 국립민속박물관의 1906년 「광화문 거리」(민속028449, 공공누리 1유형)다. 앞의 두 장은 직접 보고 육조거리 폭, 해태 대좌, 동쪽 행각·담, 서쪽 깃대를 확인했다. 호프 박물관(1903·1908 보조끼), USC(1917–19), NARA(1945–53) 사진과 국립고궁박물관 전차선로 사진은 누리집 차단이나 온라인 목록 부재로 찾지 못했다.
