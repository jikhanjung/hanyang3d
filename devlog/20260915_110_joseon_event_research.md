# 110. 조선왕조 주요 사건과 한양 도성 조사 자료집

- 날짜: 2026-09-15
- 요청: 조선왕조 전 시기의 중요한 사건을 조사하고, 한양 도성의 사건은 더 자세히 기록하여 재사용할 문서로 정리.

## 결과

[조선왕조 주요 사건과 한양 도성의 역사](../docs/joseon_major_events.md)를 작성했다. 1392년 건국부터 1910년 강제 병합까지를 다루되 1897년 이후 대한제국기를 구분한다.

- 시대별 선별 연표 79건: `E001`~`E079`.
- 한양 관련 상세 해설 37건: `H01`~`H37`.
- 출처 각주 101개: 실록 개별 기사, 국사편찬위원회 우리역사넷, 국가유산청, 서울시·서울역사박물관 등의 자료. 한 각주에 여러 자료를 연결하거나 같은 자료를 다시 참조하는 경우가 있으므로 고유 자료 101건이라는 뜻은 아니다.
- 장소별 색인, 1750년 장면과의 관계, 사건 데이터로 옮길 때 필요한 날짜·장소·근거 필드 제안.

문서 색인과 장소 이야기 문서에서 자료집으로 연결한다. 웹 화면이나 실제 이야기 JSON에는 이번 조사 항목을 추가하지 않았다.

## 조사와 편집 기준

왕조 전 기간을 가로지르는 대표 사건을 선정한 조사이며 실록 전체 기사 전수 독해 결과는 아니다. 궁궐 정변 외에 도성 건설·화재·기근·진휼·시장·준천·박해·집회·교통을 포함했다.

음력·양력·윤달, 기사 날짜·발생 날짜, 도성 안·밖, 시설명 확인·현대 좌표 확인을 구분했다. 창경궁 조성 연도와 전차 개통일처럼 자료 간 표현이 다른 경우는 차이를 남겼다. 제2차 왕자의 난의 개경 배경, 서소문 밖 처형장, 병합 관련 어전회의와 조인 장소를 구분했다. 을사늑약의 조약 표기일과 다음 날 새벽까지 이어진 경과도 분리했다.

## 검증과 한계

- 연표 ID 79개와 상세 ID 37개의 순서·중복 여부 확인.
- 본문 각주와 정의 101개의 누락·미사용·중복 여부 확인.
- 문서 변경에 대해 `git diff --check` 확인.
- 코드 변경이 없으므로 런타임 테스트는 수행하지 않았다.
- 공공 해설만 연결한 항목의 실록 원문 확대, 사건별 정확한 필지·동선, 의궤와 발굴 자료를 이용한 외형 고증은 후속 작업이다. 문서의 사건 정보만으로 건물 존속 기간이나 좌표를 자동 확정하지 않는다.

## 검토 후 수정

실록 원문과 대조해 확인했다. H18 홍화문(1750년 5월 19일 ‘五部坊民及禁軍等五十餘人’, 박문수의 사전 지시와 사론)·7월 3일, H19 수성윤음, H21 준천(4월 9일 오간수문 관찰, 2월 20일 헐린 집 주민 진휼청 구휼, 2월 23일 동성 밖 전답·식수), H09 계유정난(숭례문·서소문 폐쇄)은 문서 서술과 일치했다.

- 각주 58 제목 ‘준천 완료 관련 기사’ → ‘오간수문에 나가 준천 공사를 관찰하다’. 이 기사에 완료 표현은 없고 준천은 4월 중순까지 이어졌다.
- H36·각주 90: 해산식 장소 ‘훈련원’을 자동 연결하지 말라던 주의를 고쳤다. 우리역사넷 군대해산이 ‘동대문 근처에 있는 훈련원’으로 적어 지도의 훈련원 터와 같은 곳이며, 주요 교전(서소문 일대)과는 나누어 표시한다.
- 각주 55·57의 실록 링크를 다른 링크와 같은 `kua_` 형식으로 맞췄다(같은 기사).
- `devlog/README.md`에서 094 항목을 제자리로 옮겼다.
