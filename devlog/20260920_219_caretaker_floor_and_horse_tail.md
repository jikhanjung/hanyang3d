# 관리인 발밑 높이와 말 꼬리 방향 수정

## 관리인이 계단 아래에 묻히는 문제

명정전에는 대화 가능한 관리인 데이터와 모형이 모두 있었지만, 실외 인물은 DEM 높이만 사용해 계단 아래에 묻혔다. 기존 실내 인물의 보행면 검사를 실외 고정 인물에도 적용했다. 해당 건물의 명시적 `walkSurfaces`(계단·기단·바닥)에 수직 광선을 쏘아 지형과 보행면 중 높은 곳에 발을 놓는다. 지붕은 이 검사에 포함하지 않는다. 앉아 기도하는 인물의 좌석 높이는 유지한다.

실외에서 보정된 곳은 근정전(약 2.87m), 중화전(2.80m), 인정전(7.51m), 명정전(3.17m), 명동성당(4.03m)이다. 수치는 DEM 대비 발 높이이며 4cm 표시 여유가 포함된다. 나머지 서 있는 인물도 전수 확인했다. 1750년 인물은 별도의 기존 지면 지지 계산을 사용하며 이번 결함은 1907년 고정 인물 경로에 있었다.

## 말 꼬리

말의 전방은 로컬 +Z인데, 아래로 달린 꼬리에 음수 X 회전을 주어 달리기·점프 시 몸 안쪽으로 들어갔다. 양수 회전으로 고치고 뿌리를 엉덩이 바깥으로 4cm 옮겼다. 달릴 때는 뒤쪽으로 뻗으며 작은 상하·좌우 흔들림을 주고, 공중에서는 뒤로 뻗은 자세를 유지한다. 공통 말 모형이므로 1750·1907년 승마와 말 장수의 말에 함께 적용된다.

## 검증

- `scripts/terrain/check_caretakers1907_browser.py`: 서 있는 고정 인물 35명 모두 보행면 위 4cm, 수평 충돌 없음. 기도 중인 3명의 좌석 배치는 유지.
- 실제 ‘관리인과 이야기하기’ 버튼으로 명정전 대화 화면을 열어 인물이 계단 위에 보이는 것을 캡처·확인.
- 공통 말 모형의 달리기·점프 10개 시점에서 꼬리 끝이 뿌리보다 뒤쪽으로 35cm 이상 나와 있음을 검사.
- JavaScript 구문 검사 및 `git diff --check` 통과.
