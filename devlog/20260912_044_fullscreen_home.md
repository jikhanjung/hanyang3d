# 044 — 첫 화면을 전체 화면 한양 3D로 변경

2026-09-12. 기본 주소를 열면 대시보드나 메뉴를 거치지 않고 한양 3D만 보이도록 요청받았다.

## 변경

`/`를 3D 뷰에 연결하고 canvas_only 모드를 추가했다. 헤더·도구·건물 정보·푸터를 숨기며 캔버스를 화면 너비와 동적 뷰포트 높이에 맞춘다. 기존 JavaScript의 DOM 참조를 유지하도록 숨겨진 제어 요소는 남겨두었다. 로딩 상태와 실패 시 재시도는 캔버스 안에서 표시한다.

작업 현황은 `/gis/`, 도구가 있는 3D 화면은 `/gis/terrain/3d/`에서 제공한다. 편집 화면의 작업 현황 링크도 `/gis/`로 변경했다.

## 배포

`honestjung/hanyang3d:v0.0.2`를 빌드하고 Docker Hub에 게시한 뒤 dolfinid에 배포했다. 이미지 digest는 `sha256:de25e03e99c0adb242f74104c466580a9ecb6d970a317da2dd40f8336217bc2d`다. 일치하는 데이터 묶음을 `/srv/hanyang3d/data/v0.0.2`에 설치했다. 이전 버전의 이미지와 데이터는 롤백용으로 보관한다.

운영 주소: https://hanyang3d.nopeoplestime.info/

## 확인

로컬 및 컨테이너 Django 테스트 10개를 통과했다. 데이터 누락·버전 불일치 시작 차단, 이미지 내 원본 자료 제외, Gunicorn 응답, 비-root 실행을 확인했다. 운영 컨테이너는 healthy이며 `/healthz`는 v0.0.2와 공개 자료 51개 정상 상태를 반환했다.

운영 Chromium에서 기본 주소의 1,440×1,080 캔버스와 메뉴·정보·푸터 숨김을 확인하고 실제 렌더링 화면을 점검했다. 보행자 130명, 나무 2,468그루, 산 이름 3개와 화강암 표현도 로드됐다. 공개 브라우저 검사 도구는 `deploy/check_public_browser.py`에 추가했다. 최초 실행에서 검사 도구의 `mouse.wheel` 인자 누락을 발견해 수정했다.

수정 후 브라우저 검사 전체 통과: 휠 확대, 390×844 모바일 뷰포트의 화면 채움과 세로 스크롤 없음, 페이지 오류 없음. 이후 사용자가 요청한 조작 UI·표시 기본값 변경은 045에서 기록한다.
