# 약초 채집 범위와 성문 한자 현판

- 공통 herbs.js: 약초 중심 높이 0.4m의 화면 좌표 주변 26 CSS px까지 잡기 커서와 우클릭 채집 허용. 직접 잎/꽃을 맞히는 기존 판정도 유지. 5m 접근 제한, 비활성/화면 뒤 제외, 채집 후 재생성 대기 유지.
- 공통 gate.js: 광화문 光化門, 숭례문 崇禮門, 흥인지문 興仁之門, 돈의문 敦義門, 숙정문 肅靖門 현판. 숭례문은 세로, 가로 현판은 오른쪽부터 읽는다. 검은 목판과 테두리를 실제 Mesh로 붙여 가려짐/원근 적용.
- 서체·치수는 시각화용 단순화. 문루 없는 기존 모델에는 석축 상단에 표시하며 문루를 새로 만들지 않음. 1750 광화문과 1907 숙정문 등의 표시는 당시 실제 편액의 존재를 입증한 복원이 아니다. 1750 숙정문의 기존 문루 자체도 이번 작업의 고증 범위 밖이다.
- [서울역사박물관 숙정문 복원사](https://museum.seoul.go.kr/www/board/NR_boardView.do?bbsCd=1159&seq=20230705145630777&sso=ok), [한국민족문화대백과 숙정문](https://encykorea.aks.ac.kr/Article/E0031852), [숭례문 세로 현판](https://www.yna.co.kr/amp/view/AKR20080211109700917), [광화문 현판 색](https://www.korea.kr/multi/visualNewsView.do?newsId=148968170&pWise=main&pWiseMain=R6).
- 브라우저: 양 시대 10개 성문 현판/출입 아치 유지, 작은 식물에서 23px 벗어난 위치 채집 성공, 대기 중/5m 밖/1인칭 종료 시 판정 제외 통과. `/tmp/gate-plaques.png` 시각 검토.
