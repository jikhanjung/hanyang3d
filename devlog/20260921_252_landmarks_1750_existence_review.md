# 252 — 1750년 건물 존재 여부 재검토

1750년 장면의 건물 114개가 당시 실제로 있었는지 `gis/buildings/1750_landmarks.json`의 연혁·출처 기록과 대조했다. 결과는 [docs/landmarks_1750_existence_review.md](../docs/landmarks_1750_existence_review.md)에 등급별로 정리했다.

- 없었던 건물을 모형으로 표시한 항목 1개: 경모궁(1764년 건립). 데이터의 설명은 "없었다"고 적고 있으나 코드에 연도 필터가 없어 궁묘 모형이 그대로 보인다. 함춘원(1484)으로 대체하거나 숨기기를 권고했다.
- 존재가 불확실해 표시 방식을 재검토할 항목 5개: 사온서(속대전 혁파 관서), 태평관(임란 후 잔존 규모 미확인), 숙정문 문루(원도 도상 판독 필요), 만리창(설치 연도 미확인), 송시열 집터(사후 60년, 집 모형).
- 존재는 맞으나 이름·근거를 보완할 항목 12개: 육상궁(1750년 이름은 육상묘), 활인서 명칭, 육조거리 배치의 1863년 자료 의존, 도화서 소재지 등.
- 나머지 96개는 이상 없음으로 판단했다.

기존 데이터의 `in_1750` 설명이 대부분 정확해, 문제는 설명과 화면 표시가 어긋나는 경우에 집중됐다. 데이터나 코드는 바꾸지 않았고, 경모궁 처리와 C 등급 항목은 사용자 결정 후 반영한다. 검토는 기존 출처 기록과 일반 연혁 지식에 근거하며 새 1차 사료 대조는 아니다.
