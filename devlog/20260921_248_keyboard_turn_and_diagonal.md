# 248 — 공통 A/D 회전·Q/E 대각선 이동

사용자 요청에 따라 공통 first_person.js에서 A/D를 좌/우 회전으로 변경했다. 회전은 초당 117도이며 보행·승마 속도와 독립적이다. Q/E는 각각 왼쪽 앞/오른쪽 앞 45도 대각선 이동이다. 기존 벡터 정규화로 대각선에서도 속도가 빨라지지 않는다. W/S 전후 이동, 방향키 좌우 이동, 모바일 조이스틱은 유지한다.

A/D와 전진·대각선 이동을 동시에 사용할 수 있다. 창 포커스를 옮겨도 기존 방식대로 이동·회전을 계속하며, M 지도에서 Q/E 입력이 차단되지 않도록 허용 키도 갱신했다. 1750년·1907년·아관파천 회상이 같은 모듈을 사용한다.

검증: JavaScript 구문 검사, git diff --check. 임시 DB의 Playwright 실키 입력으로 세 화면에서 A/D 제자리 회전·동시 입력 상쇄, Q/E 방향·속도, W+E 속도 제한, W+A 이동 중 회전, M 지도 중 Q 이동과 포커스 이탈 회전 검사를 모두 통과했다. 재현 스크립트는 scripts/terrain/check_keyboard_turn_browser.py.

운영 배포는 별도다.
