# 145 — 1907년 건물 16개 추가, 총 19개

## 요청과 결과

가능한 건물은 재확인 질문 없이 계속 제작하라는 요청. 기존 제작 목록을 조사·원도 판독하고 16개를 추가했다.

경회루, 광화문, 대한문, 숭례문, 흥인지문, 명정전, 종묘 정전, 영녕전, 환구단, 황궁우, 명동성당, 정동교회, 돈화문, 홍화문, 숭정전, 러시아 공사관. 첫 세 정전을 포함해 1907년 19개, 1750년 114개로 DB 총 133개다.

## 표현과 고증

- 자체 절차적 모형 `landmarks1907.js`, 기존 정전·성문·궁문 생성기 재사용. 상자 위치표시가 아니라 전각 유형별 지붕·기둥·문·창·제단·연못을 표현한다. 치수·세부 평면·재료 색과 장식은 추정이다.
- 경회루 48개 하층 돌기둥(외곽 사각·내부 원형), 누각·연못·섬·다리. 수면은 직사각형으로 단순화.
- 광화문 3홍예, 숭례문 우진각, 흥인지문 외측 옹성. 성벽 철거 전후를 확정하지 않아 인접 성벽은 생략.
- 1836년 이후 종묘 정전 19칸·영녕전 16칸(중앙 4칸 높은 지붕). 연속된 지붕 면으로 합쳐 표현. 기존 1750년 15칸 모형은 그대로 유지.
- 환구단 원형 제단과 황궁우 팔각 삼층은 별도 객체. 명동성당·정동교회는 십자형 평면·종탑·첨두 창, 정동교회는 1926년 증축 전 유형.
- 러시아 공사관은 2층 본관·측면 탑·연창의 문헌상 특징만 반영. 전체 평면·색상·지붕·탑 위치는 추정. 숭정전은 원도에 전각 기호가 없어 궁궐 구역·현대 참고 위치를 이용한 추정.
- 황궁우·정동교회도 원도 개별 기호 확정이 아니며 낮은 위치 신뢰도를 설명에 명시. 근거와 좌표는 `docs/seoul1907_landmarks.md`, seed, 19개 manifest에 기록.
- 독립문·독립관은 현 지도 서쪽 범위와 1979년 이전 원위치 검증이 남아 보류. 석조전 완성형도 1907년에는 넣지 않았다.

## 연대와 콘텐츠 관리

존속 기간과 표현 기간을 분리한다. 환구단은 존속 종료 1913년. 대한문 1970년 이전, 정동교회 1926년 증축, 숭정전 1926년 매각·이전은 건물 소멸과 구별해 표현 종료로 기록했다. 러시아 공사관은 1890년경 착공/완공 자료 차이와 전쟁 중 파괴 연도의 불확실성을 남겼다. 광화문도 공식 자료의 1865/1867년 차이를 기록하고 1867년을 표시 기준으로 사용한다.

새 renderer는 개발자 허용 목록에서만 등록하며, `sync_content` 트랜잭션 안에서 필요한 Resource를 생성한다. 미리보기에서는 Resource도 롤백된다. 기존 운영 Resource와 건물 편집을 덮어쓰지 않는다. `0006_landmark_1907_renderer`는 선택지 추가에 대한 Django 상태 migration이며 데이터 삭제·재수입은 없다. ASCII-safe migration 파일로 보관한다.

로컬 DB는 SQLite backup API로 `/tmp/hanyang3d-before-more-1907.sqlite3`에 백업하고 integrity_check 통과 후 적용했다. 최초 동기화 추가 16·영문 안내 16·충돌 0. 후속 광화문 연대 근거 보강 1건 갱신, 충돌 0. 기존 안내 문단 차이 3건은 강제 덮어쓰지 않았다.

## 화면과 검증

- 이름표의 시대 접두어를 줄이고 겹치면 위치 조정·숨김. 메뉴에서는 항상 전체 19개 선택 가능.
- 건물 선택 시 해당 건물 정면 쪽에서 관찰하고 큰 구역·모바일 화면에 맞춰 거리 조정. 원본 보기·지도 투명도와 모델 좌표 분리 유지.
- 정적 새 모형을 재질별로 병합해 그리기 호출 최소화.
- Django 전체 60개 통과. 추가한 업그레이드 Resource 등록·미리보기 롤백·연대/이전 구분 검사를 포함한 관련 12개 추가 실행 통과.
- 최초 Chromium 검사 통과: 19개 모형, 정점 유한값, 48개 돌기둥, 신실 19/16칸, 광화문 3홍예, 옹성, 지도 0%에서 위치 불변, 원본·모바일·시대 전환, JS 오류 없음. 대표 모형 PC·모바일 스크린샷 육안 확인.
- 지붕과 정면 시점 변경 뒤 최종 Chromium 검사도 PASS. 대표 성당 정면·모바일 화면 재확인.
- 시스템 검사·migration 추가 변경 없음·git diff --check 확인. 0006 sqlmigrate 결과 no-op. 최종 sync 미리보기 추가·갱신·충돌 0.

이번 작업은 개발 코드·로컬 DB 반영이다. 운영 배포와 commit/push는 실행하지 않았으며 운영 버전은 v0.5.1이다. 이후 배포에는 새 모형 코드와 0006 migration, 콘텐츠 sync가 함께 필요하다.
