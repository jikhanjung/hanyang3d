# 169 — 1907년 종로 전차와 보행자 회피

초기 전차 운행 기록과 1907년 원도의 붉은 전기철도선을 확인하고, 종로 내부 약 2.99km에 단선 레일·가선·전차 한 대를 추가했다. 한미전기회사라는 당시 명칭과 초기 개방차 형태를 반영했다. 판독 픽셀, 지도 해시, 연대와 참고 자료는 `gis/transport/seoul1907_trams.json`, 조사와 구현 한계는 `docs/seoul1907_streets_and_trams.md`에 기록했다.

전차 보기 버튼과 켜기/끄기, 지형 경사에 따른 차체 높이·방향, 양 끝 대기·역방향 운행, 거리별 상세 생략을 구현했다. 이용자 추가 요청에 따라 보행자가 미리 측면으로 비켜나고 전차는 앞에 사람이 있으면 기다린다. 회피는 건물·성벽 충돌을 검사하며, 기존 1750년에는 적용되지 않는다. 지도 투명도와 무관하게 레일 높이는 유지된다. 도로 깊이 오프셋에 가려졌던 레일은 수정 후 화면에서 확인했다.

1907년·일반 Django 검사 24개, 멀티플레이 Node 검사 및 PC/모바일 브라우저 검증을 통과했다. 경로 5m 간격의 차량 폭 충돌 검사 통과. 회피·정지·재출발, 왕복, 숨김 정지, 투명도 높이 불변을 확인했다. 차량 치수·색·배차·회차는 재현 설정이며 실제 시각표·종점으로 안내하지 않는다. 차량 사진 원본은 다운로드 오류로 정밀 판독하지 못했으며 문헌 설명을 따른 개념 모형이다. 멀티플레이 전차 동기화와 탑승은 이번 범위 밖이다. 배포는 수행하지 않았다.
