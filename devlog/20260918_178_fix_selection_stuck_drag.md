# 178 — 건물·전차 선택 후 드래그가 풀리지 않는 문제

운영 v0.5.15에서 건물을 클릭한 뒤 버튼을 놓아도 마우스를 따라 화면이 움직인다는 제보를 확인했다. 실제 설명창은 pointerup에서 열렸지만, 선택 처리의 `stopImmediatePropagation()`이 같은 이벤트를 뒤에 등록된 OrbitControls 종료 처리에 전달하지 않았다. OrbitControls는 pointerdown 때 pointerup 리스너를 추가하므로 건물·전차 선택 리스너가 먼저 실행되었다. 그 결과 포인터 캡처와 드래그 상태가 남았다.

선택 처리에서 이벤트 전파를 막지 않도록 고쳤다. 선택한 이벤트는 `preventDefault()`로 NPC 선택기에만 구분시키고, 지도 컨트롤이 pointerup을 모두 처리한 다음 다음 작업에서 설명창을 연다. NPC 선택기는 이미 건물·전차에 처리된 이벤트를 무시하면서 자체 누름 상태를 해제한다. Three.js 라이브러리와 드래그 설정은 변경하지 않았다.

브라우저 회귀 검사에서 수정 전 전차 클릭 후 무버튼 마우스 이동이 카메라를 바꾸는 현상을 재현했다. 수정 후 PC·모바일 모두 통과: 건물·전차 클릭/탭 뒤 마우스 이동 시 시점 유지, mousedown 동안 설명창 미표시, 드래그 무선택, 이름표 선택 시 시점 유지, 이동 목록 동작 및 기존 전차·회피·가림 검사. `git diff --check` 통과.

기존 기록·commit/push 요청에 따라 수정과 검사·devlog를 Git에 반영한다. 이 수정은 아직 운영 배포하지 않았다.
