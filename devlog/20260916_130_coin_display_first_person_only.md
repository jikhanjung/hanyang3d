# 130 — 이름·엽전 표시는 1인칭에서만

사용자 요청: 1인칭이 아닐 때는 상단 중앙의 ‘이름 · 엽전 · 나가기’를 보여 줄 필요가 없다.

## 변경

- 엽전 표시(`#money-hud`)는 로그인했고 1인칭일 때만 보인다. 전체 지도 시점에서는 로그인해 있어도 숨긴다.
- `shop.js`에 `showHud(shown)`을 더했다. `terrain3d.js`의 1인칭 `enter()`는 `showHud(true)`, `exit()`는 `showHud(false)`를 부른다. 1인칭 중에 로그아웃하면 1인칭에서 나오므로 표시도 함께 사라진다.
- 전체 지도 시점에서 상인 가게를 열면 가게 창 안의 엽전 줄로 잔고를 볼 수 있다(표시 조건은 128과 같다).

## 검증

- `check_npc_browser.py`: 로그인한 채로 1인칭에서 나오면 표시가 숨는지 확인하는 단언을 더했다. 통과.
