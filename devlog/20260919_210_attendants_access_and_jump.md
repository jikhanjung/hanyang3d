# 210 — 공사관 문지기·성당 신부, 계단과 충돌, 말 점프·정보 패널

1907년 러시아 공사관 앞 문지기와 명동성당 실내 신부를 추가했다. 두 사람 모두 특정 실존 인물을 지칭하지 않는 가상 안내인이다. 공사관은 아관의 뜻, 1896년 피신, 외교적 의존, 1897년 환궁을 4부로 말한다. 성당은 1898년 완공, 고딕 공간, 순교자 기억을 3부로 말한다. 출처·영문·1907~1908년 표시 범위를 데이터에 둔다.

실내 NPC는 건물 로컬 좌표와 `indoors` 속성으로 배치하고 실제 바닥 메시에서 발 높이를 얻는다. 입구와 의자 사이를 비킨 측랑에 배치했으며 외부에서는 벽 너머로 신부를 클릭할 수 없다. `id`로 실외 관리인과 키를 구분한다. 검은 수단·흰 칼라와 별도 대화 초상은 개념 표현이다.

대한문은 닫힌 목제 문이 보이는데 충돌 코드가 궁궐 문 전체를 열린 중앙 통로로 취급하던 문제였다. 궁궐 문 모델의 문짝·벽·기둥 밑동에 맞춰 충돌 사각형을 제공한다. 기단과 계단 메시를 병합 대상에서 분리해 보행 표면으로 등록하고 지형 받침 측면도 막는다. 닫힌 문은 통과할 수 없고 계단으로 기단에 올라설 수 있다.

환구단은 전체 사각형 충돌 때문에 계단에 진입할 수 없었고 기존 계단의 끝 높이도 각 단의 높이에 못 미쳤다. 제단 전체 충돌을 제거하고 원형 단·계단을 보행 표면으로 등록했다. 네 방향에 각 단까지 이어지는 27.5cm 단차 계단을 둔다. 배치·치수는 이동 가능한 개념 모델이며 실측 복원이 아니다.

말에 타면 점프 초기 속도를 4.5→6.3m/s로 높인다. 같은 중력에서 실제 프레임 검사 결과 보행 약 1.0m, 승마 약 1.97m였다. 무릎 관절을 나누어 공중에서는 앞·뒷다리를 접은 고정 자세를 취하고 지면에 닿으면 달리기 애니메이션으로 돌아간다. 1750·1907 공통이다.

정보 패널은 채팅창의 실제 높이를 ResizeObserver로 받아 12px 위에 놓는다. 입력창·화면 크기 변화도 반영하며 1750 팝업과 1907 건물·전차 패널에 공통 적용한다. 모바일 채팅 열기 버튼의 레이어도 올려 정보 패널에 가려지지 않게 했다.

손탁호텔 사진 두 장을 3초 간격으로 저장하고 SHA-256·소장처 표기·연대 미상을 기록했다. 사진을 보고 본관의 아치형 창·발코니·현관 계단을 확인했다. 기존 운영 모델을 임의로 바꾸지는 않았다. [자료와 이야기 후보](../docs/sontag_hotel_photos_and_stories.md).

검증: `check_1907_access_attendants_browser.py`에서 대한문 문 충돌·기단 높이, 환구단 실제 연속 보행(지면→3단 꼭대기 3.3m), 실내 신부의 바닥·실내 영역·장애물 회피·고유 키, 보행/승마 점프 높이와 공중 무릎 자세 고정, PC·작은 PC·모바일 채팅/건물 패널 비중첩을 검사한다. 1750 정보 패널과 성당 실내 스크린샷도 포함한다.

배포 대상은 웹 v0.5.27, 멀티플레이 v0.5.24 유지. 인물 데이터는 `gis/updates/1907_legation_priest.json`의 이전 데이터 해시를 확인하여 별도 적용한다.

추가 요청: 공통 1인칭에서 좌우 마우스 버튼을 동시에 누르면 전진한다. 어느 순서로 눌러도 동작하고 한 버튼을 놓으면 멈추며, 이동을 마친 버튼 해제를 건물/NPC 클릭으로 처리하지 않는다. Pointer Events는 첫 버튼에서만 pointerdown을 보내므로 두 번째 버튼은 mousedown으로 추적한다. 모든 시대의 이동·UI를 함께 변경한다는 원칙을 CLAUDE.md에 기록했다.
