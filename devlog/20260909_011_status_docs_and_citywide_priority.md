# 011: 현황 문서 갱신과 도성 전체 개관 우선순위

- 날짜: 2026-09-09
- README·계획·인계·범위의 오래된 초기 단계 설명을 실제 구현 상태로 갱신했다.
- 파일 수를 JPG 11개·PDF 1개로 통일하고, 상대 픽셀 정합·미검증 TPS·미채택 시대 간 가설의 검증 범위를 구분했다.
- 사용자 요청에 따라 도성 전체를 대략 보는 작업을 우선한다. 도성대지도를 고도 데이터로 만든 3D 지형에 입혀 회전·기울임으로 보는 것이 다음 시각화 목표다. 현재는 평면 TPS 화면까지 구현되어 있다.
- 관인방–경행방 및 1908–1912 세부 정합은 참고 실험으로 보존하고 전체 개관의 선행 조건에서 제외했다. 건물 복원은 후속으로 둔다.
- 사용자가 기존 5점 배치의 사대문 안 정확도를 시각적으로 확인했다. 이를 3D 화면의 개관용 기준 배치로 이어가며 수치 검증과는 구분한다.
- 결정 0002를 작성하고 초기 결정의 변경 관계를 명시했다. 기존 실험 기록·수치·원본은 변경하지 않았다.
- 인계 문서에 전체 원본 보존 경로, 파생 화면 재생성 안내, Tailscale 상태와 재시작 방법을 정리했다.
- 검증: 수정 문서의 로컬 링크 대상 존재와 git diff --check 확인. 문서만 변경하여 앱 테스트는 재실행하지 않았다.
