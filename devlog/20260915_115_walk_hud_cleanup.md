# 115 — 걷기 안내 패널 제거와 접속자 표시

사용자 요청에 따라 1인칭 화면의 방향 키 버튼·조작 안내 패널을 제거했다. 메뉴의 ‘전체 지도 시점’과 Escape로 복귀하며, 실제 키보드 이동·모바일 조이스틱은 유지한다. 모바일 조이스틱은 안내 패널에서 분리해 걷는 동안만 표시한다.

인원 표시는 ‘함께 걷는 중 · 나 포함 N명’에서 ‘접속자 N명’으로 바꿨다. 본인을 포함한 현재 공간의 인원 수다. 후속 버전은 v0.2.2다.

설정 패널도 PC에서는 340px 안에 두 열, 모바일에서는 250px 안에 한 열로 배치해 과도한 가로 여백을 줄였다. 작은 화면에서는 기존 화면 폭 제한을 따른다.

검증: JavaScript 구문 검사, 1440/390/320px에서 패널 폭 340/250/196px 및 내용 넘침 없음, 기존 모바일 다중 터치·이동·재진입·채팅 검사 통과. 화면에서 ‘접속자 1명’과 독립 조이스틱 표시를 확인했다.
