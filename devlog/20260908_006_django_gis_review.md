# 006 — Django GIS 검토 서비스

사용자의 웹서버 실행 요청과 Django 선택에 따라 Django 5.2.17 서비스로 구성했다. 첫 화면은 파일 카탈로그와 정합 실험 기록에서 현황 수치를 읽고, 기존 오프라인 도엽 연결·지도 비교 화면으로 연결한다. 원본은 카탈로그에 등록된 파일만 제공하며 검토 산출물은 명시 목록으로 제한한다. DB와 서버 편집 기능은 아직 없다.

`manage.py check`와 Django 테스트 4개가 통과했다. 첫 화면, 지도 도구, 원본 제공, 비공개·누락 경로 차단, POST 거부를 검증했다. 0.0.0.0:8000에서 개발 서버를 실행하고 실제 HTTP로 첫 화면과 PNG 응답 200을 확인했다. 브라우저의 시각·클릭 검증은 수행하지 않았다.

[실행 방법](../webapp/README.md)에 재시작과 Git 제외 원본·파생 파일 준비 절차를 남겼다.
