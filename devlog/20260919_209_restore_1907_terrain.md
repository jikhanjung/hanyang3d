# 209 — 1907년 하천 밖 지형·지도 누락 수정

v0.5.25 배포 후 사용자가 “청계천 주변만 보이고 지도 오버레이·지형이 안 보인다”고 보고했다. 운영 브라우저에서 지형 정점 212,455개 중 높이 좌표 173,572개가 비정상 수치인 것을 확인했다.

`ChannelTerrain.nearestWithin()`은 검색 반경 밖에서 `{distance: Infinity}`만 반환한다. 새 하도 보정 루프는 `distance >= width`만 비교했는데, width가 없는 경우 비교가 false여서 보정 계산으로 넘어갔다. 이후 undefined 값과의 계산으로 원래 지형 높이가 NaN으로 바뀌었다. 같은 geometry를 쓰는 지형·옛지도 모두 영향을 받았다.

거리 값이 유한하지 않으면 보정 자체를 건너뛰도록 수정했다. 하천 바깥은 원래 FABDEM 지형을 유지하고, 유효한 하천 범위 안에서만 낮춘다.

기존 검증은 물길 62점·다리 7개·M 지도·UI에 집중해 지형 전체의 수치 손상을 놓쳤다. 회귀 검사에 전체 정점·법선의 유한성, bounding sphere, 하천에서 떨어진 지형 1,636곳의 원래 DEM 높이 일치를 추가했다. 전체 지형과 지도 오버레이가 보이는 실제 화면도 확인했다. 하도·다리·관리인·큰 지도·모바일 봇짐·1750 M 지도 검사도 통과했다.

수정 코드는 `b34a93f`이며 웹 v0.5.26으로 운영 배포했다. 웹 이미지 digest는 `sha256:e46ee2fbe4bd724952b4aff8ac2df049965555a6fc8fdef02bc507c776997067`이다. 운영 PC·모바일 브라우저에서 전체 정점과 법선의 유한성, 전체 지형·지도 화면, M 지도와 관리인 대화를 확인했다. 운영 환경설정 보존 비교도 통과했다. 멀티플레이 v0.5.24와 이전에 적용한 인물 데이터는 유지한다. 예약한 물품·음식 다운로드는 개발 PC의 독립 타이머다.
