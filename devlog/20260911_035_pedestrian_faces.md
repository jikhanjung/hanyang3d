# 035 — 보행자의 간단한 얼굴·머리카락

130명 모두에게 어두운 머리카락, 두 눈, 작은 코를 입체 모형으로 추가했다. 얼굴은 보행 방향으로 회전한다. 머리카락은 머리 윗부분을 덮는 단순한 형태이며 당시 머리모양·신분·복식의 복원이 아니다.

기존 인스턴스 렌더링에 머리카락·양쪽 눈·코 네 묶음을 더해, 사람마다 별도의 렌더링 호출을 늘리지 않는다. 모델의 키와 보행 속도는 유지한다.

확인 스크립트: `scripts/terrain/check_people_faces_browser.py`.

브라우저 검사 통과: 130명 모두 얼굴 요소가 있고, 코가 진행 방향 앞쪽에 놓이며, 확대 화면에서 눈·코·머리카락을 확인했다. JavaScript 오류 없음.
