# 239 — 취객 무작위 대사와 무응답

종로 뒷골목 취객의 순차 반복을 제거했다. 대사는 기존 5개에서 한영 12개로 늘리고, 실제 말을 걸 때 20%는 무응답, 나머지는 12개 중 균등 무작위로 선택한다. 무작위 선택이므로 같은 말이 우연히 반복될 수는 있다.

선택 후보를 판정하는 hit test에서는 난수를 소비하지 않고, 최종 대화 시작 때만 선택한다. 무응답이면 기존 말풍선도 숨기고 대화 상태를 해제하며 빈 말풍선·말줄임표를 보여주지 않는다. 공유 말풍선 모듈은 선택 콜백이 없는 기존 1750/1907 NPC의 인사를 그대로 사용한다.

데이터는 people1907에서 관리하며 `gis/updates/1907_tipsy_random_lines.json`으로 다음 배포 시 갱신한다. JS 변경도 필요하므로 데이터만 먼저 적용하지 않는다. 운영 미반영.

검증: 1907 Django 검사 및 격리 브라우저의 난수 분기 제어로 서로 다른 대사·무응답·기존 말풍선 제거·talking 상태 해제 확인. 이화학당·소의문 회귀 포함.
