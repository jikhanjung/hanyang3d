# 282 — 을미사변 광화문 앞 경비병·무리의 말

- 광화문 앞: 연대장 혼자 막아서던 장면에 병사 여덟을 더했다. 문 앞에 연대장(검은 군복·칼)을 가운데로 소총·창을 든 병사들이 한 줄로 서고 둘은 문 가까이에 선다. 사격 뒤 연대장과 병사 둘이 쓰러지고, 나머지 여섯은 돌아서 광화문 안으로 달아나 사라진다. 안내: "앞에 선 이와 병사 몇이 쓰러지고, 남은 병사들은 문 안으로 흩어져 달아난다." → "쓰러진 이는 훈련대 연대장 홍계훈이었다고 한다." 병사 수·배치·쓰러진 수는 해석이다(광화문 앞에서 홍계훈이 막다가 죽고 궁을 지키던 병력이 흩어졌다는 서술을 따름).
- `shadow` 모듈 멈춤의 수비자에 `role`(commander)·`weapon`(rifle)·`fate`(fall/flee)와 `flee_pixel`, 박자 `flee`를 더했다. 이전 정의(`gate.defender_pixel` 하나)도 그대로 동작한다.
- 무리의 말: 잡담 7 → 23마디, 의심 5 → 10마디. 섞은 순서로 뽑아 한 바퀴 돌 때까지 되풀이하지 않는다. 육조거리부터는 "문이 코앞이다", "장전은 했나?", "신호를 기다려." 같은 말이, 궁 안에 들어서면 "안쪽이다, 안쪽으로 서둘러.", "연못 건너편이다." 같은 말이 절반쯤 섞인다(`chatter.phases`). 대사는 창작이다.

확인: `check_eulmi_browser.py`에서 광화문 멈춤의 수비자 9명 중 3명 쓰러짐·6명 달아나 사라짐, 연대장 쓰러짐과 홍계훈 안내, 따라가는 동안 서로 다른 말 24마디가 나오는지 확인하고 전체 회상(골목 시작·미행·건청궁·저잣거리·1907 진입)이 통과했다. `test_historical_events` 통과.
