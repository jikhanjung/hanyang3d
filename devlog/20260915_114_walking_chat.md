# 114 — 1인칭 진입 통합, 옷 색깔·중복 이름·문자 채팅

v0.2.0 배포 후 사용자가 기존 혼자 걷기 기능 제거, 함께 걷기 버튼을 ‘1인칭’으로 변경, 접속자별 옷 색깔·이름 중복 검사·문자 채팅을 요청했다. 후속 릴리스는 v0.2.1이다.

## 변경

- 혼자 걷기 버튼을 제거하고 ‘1인칭’ 하나로 이름 입력과 멀티플레이 접속을 시작한다. 접속 중 같은 버튼은 ‘전체 지도 시점’이며 걷기와 연결을 함께 종료한다.
- 서버가 첫 위치 메시지 전부터 이름을 예약한다. 정규화한 이름을 영문 대소문자 구분 없이 공간 내에서 비교하고, 중복이면 입력창에서 수정한다. 퇴장 시 예약을 해제한다.
- 공간의 32개 색 중 사용하지 않는 옷 색을 서버가 배정한다. 위치 메시지로 이름·색을 위조할 수 없으며 자신과 다른 화면에 같은 옷 색이 나타난다. 영구 캐릭터 설정은 아니다.
- 공간 내 문자 채팅: 이름·옷 색 표시, 1~200자, 초당 1회, 최근 50개 메모리 보관. HTML을 실행하지 않고 문자로 표시한다. 서버가 발신자·시각을 지정한다.
- 채팅 버튼/Enter로 열고 Escape로 닫는다. 입력 중 이동 키를 차단하며 한글 조합 중 Enter로 전송하지 않는다. 퇴장하면 채팅 UI와 받은 내역을 비운다.

## 검증

- Django 15개, 서버 5개 검사 통과.
- 실제 두 클라이언트 검사 통과: 이름 동시 예약·대소문자 중복·퇴장 후 재사용, 서로 다른 색·위조 거부, 채팅 전달·기록·길이·빈도 제한, 기존 NPC 동기화.
- 두 브라우저 검사 통과: 단일 진입 버튼, 중복 이름 수정, 자신의 색과 상대 화면의 색 일치, HTML 문자 표시, 입력 중 이동 방지, 채팅 Escape, 재접속 기록, NPC 동기화.
- 모바일 검사 통과: 실제 다중 터치 이동·시선·재진입·키보드와 채팅 열기·입력·전송·닫기. 390px 화면의 입력창·패널 배치를 스크린샷으로 확인했다.
