# 246 — 아관파천 새벽 하늘·조명

1896년 2월 11일 새벽 이동에 맞춰 회상 장면의 하늘을 밝은 회청색에서 어두운 남색(#101827)으로 변경했다. 반구광과 방향광도 차가운 색으로 낮춰 동트기 전 분위기를 표현하되 길과 가마를 구분할 수 있는 조명을 유지했다. 일반 시대 장면에는 적용하지 않는다.

새벽 이동 근거는 앞선 경로 조사에서 확인한 동북아역사재단 자료: https://www.nahf.or.kr/web/portal/webzine/774/56075

JavaScript 구문 검사와 git diff --check 통과. 조명 색·세기만 변경했으며 운영 배포는 별도다.
