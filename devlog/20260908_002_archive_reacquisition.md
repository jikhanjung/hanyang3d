# 현재 서버의 도성대지도 재취득 및 부분도 추가

2026-09-08. Git 인계 후 원본 JPG·상세 HTML·JSON이 없는 것을 확인했고, 사용자 요청에 따라 현재 서버에서 새로 취득했다.

| 사료 / 파일 | 이미지 크기 | 파일 크기 | 결과 |
|---|---|---|---|
| src-0001 / asset-0001 도성대지도 | 3124 × 2743 | 2,836,782 bytes | 기존 SHA-256과 동일하여 기존 ID 유지 |
| src-0002 / asset-0002 운종가·청계천 부분도8 | 2854 × 2000 | 2,313,888 bytes | 새 파일 등록 |

각 상세 페이지에서 다운로드 폼의 hidden 필드와 공공누리 제1유형 표시를 확인했다. 개인 / 기타 / 조선시대 한양 모습 탐구로 각각 1회 목적 제출 후, 해당 세션과 상세 페이지 Referer로 정상 다운로드했다. 다운로드 URL과 파일별 권리 조건은 assets.csv에 기록했다.

원본은 `data/maps/src-0001/`, `data/maps/src-0002/`에 보관한다. 각 폴더에는 JPG 및 `detail-2026-09-08.html`, `detail-2026-09-08.json`이 있다. 상세 페이지 원문은 기존 추출 스크립트로 보존했으며 HTML SHA-256은 JSON에 기록했다. 세션 쿠키는 저장소 밖 /tmp에만 두었다.

부분도의 아카이브 번호는 `srd-415256`, 유물번호는 `서14165`, 시기는 `18세기`이다. 페이지 설명은 운종가·청계천 일대의 부분도라고 명시한다. 상세 식별 정보는 sources.csv에 추가했지만 정확한 제작연대와 전체 도엽 검증은 남아 있으므로 사료 상태는 unverified로 유지했다.

## 검증과 한계

- file로 두 파일의 JPEG 형식과 해상도 확인, FFmpeg로 전체 이미지 디코딩 성공.
- 전체도 SHA-256이 이전 기록과 일치. 두 파일의 크기·SHA-256을 카탈로그와 대조.
- CSV 구조·ID 중복·사료 외래키 및 상세 JSON의 원본 HTML checksum 확인.
- 원본 디렉터리는 Git 제외 유지. 문서·카탈로그만 변경.
- Pillow는 설치되어 있지 않아 FFmpeg로 이미지 디코딩 검사 수행. 의존성 설치는 하지 않음.

현재 파일이 최고 해상도인지, 지명·골목의 정밀 판독에 충분한지는 미평가다. 다른 지적도·실측도 원본은 아직 확보하지 않았다. 다음 작업은 1908·1912 지적자료 도엽 조사와 파일럿 범위 확정이다.
