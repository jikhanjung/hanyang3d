# 아관파천 회상 이벤트 — 두 대의 가마

작성: 2026-09-20. 상태: 전체 6단계 설계안. 영추문 문루와 출발→가마 따라가기→도착 해설→복귀의 첫 체험을 구현했고([구현 기록](20260920_243_agwanpacheon_first_visit.md)), 2026-09-21 밀서·서쪽 문 연락책·통역·이웃 소문·후일담을 붙였다([기록 251](20260921_251_agwanpacheon_letter_gate_aftermath.md)). '길을 살펴라' 답사와 검문 회피는 후속 범위다.

## 경험과 시대

1907년 러시아공사관 문지기의 이야기에서 1896년 2월 11일 회상으로 들어간다. 플레이어는 가상의 연락 심부름꾼이자 목격자다. 국왕을 직접 조종하거나 역사적 결과를 바꾸지 않는다. 시작 화면에 날짜와 ‘기록을 바탕으로 구성한 창작 체험’을 표시한다.

## 역사 확인과 공간

- 고종과 왕세자가 경복궁에서 러시아공사관으로 옮긴 사건이다. [한국민족문화대백과 아관파천](https://encykorea.aks.ac.kr/Article/E0034214)은 1896년 2월 11일 새벽 궁녀의 가마를 이용해 **영추문**으로 나왔다고 설명한다.
- **영추문은 서문, 건춘문은 동문으로 서로 다른 문**이다. [영추문 항목](https://encykorea.aks.ac.kr/Article/E0076898), [서울시 영추문 소개](https://mediahub.seoul.go.kr/archives/1202968). 전달받은 구상의 건춘문 경유설은 출처 원문을 추가 대조하기 전 확정하지 않는다.
- [고종실록 해당 날짜 기사](https://sillok.history.go.kr/id/kza_13302011_005)는 원문 대조 대상으로 남긴다. 이번 설계에서 장안당 출발, 가마 수·탑승 구성, 세부 도로 및 통과 시각을 1차 사료로 확정했다고 주장하지 않는다.
- 사용자가 지정한 기준은 **경회지 남쪽 끝에서 서쪽으로 가다가 경복궁 담을 만나는 지점**이다. 현재 `gis/walls/seoul1907_infrastructure.json`에는 `yeongchu-opening-1907`, 원도 픽셀 `[660,1783]`, 폭 10m의 개구부가 이미 있다. 반대편 건춘문 개구부는 `[900,1779]`다. 현재 데이터 주석도 두 문은 통로만 두었고 문루는 별도 작업이라고 명시한다.
- 영추문 통로를 출발 후보로 사용한다. 문루를 만들 때 원도·경회지와의 정합을 다시 확인하고 담장 접합, 홍예 통과, 가마 충돌을 검증한다. 현대 영추문은 복원 때 위치가 달라졌다는 위 백과 설명이 있으므로 현대 좌표를 그대로 적용하지 않는다.
- 제안 경로는 **영추문 → 내수사 일대 → 새문고개 → 정동 러시아공사관**. 금천교를 포함한 세부 경유지와 이름은 추가 검증 대상이다. 1907년 도로를 1896년 실제 탈출 동선으로 단정하지 않으며 좌표는 아직 확정하지 않는다.

## 여섯 단계

아래 임무·연락책·대사는 창작이다. 두 가마 연출도 세부 사료 검증 전의 제안이다.

| 단계 | 플레이어 행동 | 연출·완료 조건 |
| --- | --- | --- |
| 새벽의 밀서 | 정동 연락책에게 봉인된 편지 전달 | 공사관 주변을 익히고 서쪽 궁문으로 가라는 지시를 받는다. 편지는 거래 불가 임무 물품이다. |
| 궁궐의 서쪽 문 | 영추문 밖 연락책 만나기 | 국왕의 이름을 밝히지 않고 조용히 기다리라는 부탁을 받는다. |
| 길을 살펴라 | 골목의 지정 지점들을 답사하고 보고 | 길 찾기와 대화가 중심. 검문·장애물은 창작임을 기록한다. |
| 두 대의 가마 | 문 밖으로 나오는 가마 목격 | 목표: ‘가마가 정동에 도착하는지 확인하십시오. 눈에 띄지 않게 거리를 유지하십시오.’ |
| 정동까지 | 가마와 거리를 두고 따라가기 | 전투 없음. 너무 가까우면 경고, 놓치면 마지막 확인 지점에서 재개한다. 플레이어 실패가 국왕 체포로 이어지지 않는다. |
| 아관 | 공사관 도착 후 관계자와 대화 | 탑승자의 정체를 밝히고 역사 설명·출처를 열어 준다. 이후 소문 장면을 거쳐 1907년으로 돌아온다. |

대사의 예: “가마 안을 들여다보려 하지 마시오. 앞길에 사람만 몰리지 않게 살펴주면 되오.” 실제 인물의 발언으로 인용하지 않는다.

## 회상과 공유 세계의 구분

- 1896년 회상은 플레이어별 공간 또는 별도 방으로 격리한다. 다른 1907년 플레이어에게 가마·순찰·변경된 대사가 보이지 않게 한다.
- 전차와 레일, 1896년 이후 건립·완공된 건물, 이후 시점의 인물·상점·간판을 회상에 그대로 노출하지 않는다. 건축 연대만으로 당시 외형을 보장할 수 없으므로 구간별 검수가 필요하다.
- 현재 1907년 장면을 연도 숫자만 바꾸면 되는 것으로 취급하지 않는다. 회상용 가시성·도로·복식·조명 프로필이 필요하다. 지도에도 1907년 원도를 소급 참고했다는 한계를 밝힌다.
- ‘다음 날 도시 변화’는 회상 후일담 안에서 표현한다. 경운궁 환궁과 대한제국 선포 등은 각각 날짜를 표시한 후속 이야기로 분리한다. 1907년 공유 세계를 1896년의 정치 상황으로 되돌리지 않는다.
- 출입 시 위치·시점·탑승 상태를 저장/복구한다. 기존 공통 이동·지도·채팅 UI를 재사용하고 회상 중 말의 사용 조건을 명시한다.

## 구현 순서

1. 영추문 문루와 통과 가능한 출입구, 공사관 진입 지점, 추정 도보 경로를 먼저 만든다. 지형·담장·건물과 가마가 충돌하지 않는지 확인한다.
2. 최소 체험: 문지기 대화 → 날짜 전환 → 영추문 가마 출발 → 따라가기 → 공사관 도착·해설 → 1907년 복귀. 가마·가마꾼·대기/이동 애니메이션이 필요하다.
3. 밀서·사전 답사·검문 회피와 후일담을 붙여 여섯 단계로 확장한다. 전체 체험 목표 10~15분은 설계값이며 실제 이동 시간으로 조정한다.
4. 공통 이벤트 진행기를 마련한다. 기존 `npc_dialogue.js`, `walk1907.js`와 대화·진행 조건을 연결하고 경로·대사·사료·연대를 데이터로 분리한다. 기존 P01 심부름 계획은 구현 완료 기능으로 가정하지 않는다.
5. 서버에 계정별 이벤트 ID·정의 버전·단계·체크포인트·최초 완료 시각을 저장한다. 보상을 도입하면 서버 검증과 1회 지급을 적용한다. 재접속·중도 이탈·재관람도 지원한다. 클라이언트 완료 메시지만으로 보상하지 않는다.

수락 기준: 시작/중단/복귀 시 위치 복구, 재접속 재개, 반복 보상 방지, 다른 플레이어와 진행 격리, 시대에 맞지 않는 전차·건물 숨김, 가마의 담장 통과와 경사 이동, 대화·지도 조작과 이동 입력 충돌 없음. 경로와 출처 설명에서는 확정·추정·창작을 구분한다.
