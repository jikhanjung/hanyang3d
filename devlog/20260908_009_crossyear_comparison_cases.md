# 009 — 1908–1912 비교 후보 구간과 직접 연결

사용자의 다음 작업 요청에 따라 경행방도에서 서쪽 골목·하수구 분기, 동쪽 골목·붉은 구획 남측, 서남쪽 계단형 방 경계의 세 비교 구간을 기록했다. [후보 데이터](../gis/control_points/1908_1912_comparison_cases.json)에 원본 범위, 연결된 판독선, 관찰 내용과 확인 조건을 보존했다. 1912 목표 범위·대응점은 null이고 확정점 수는 0이다.

기존 판독 화면에 원본 확대 카드 3개와 1912 제5·6·12·13호로 가는 비교 링크를 추가했다. 지도 비교 도구는 URL에서 자료 쌍과 후보를 선택하고 원본 구간을 확대한다. 후보 전환과 재확대 버튼을 제공하며 실제 대응점을 자동 생성하지 않는다. 기존 CSV 입출력과 자유 비교는 유지한다.

생성 시 원본 체크섬·확대 범위를 검증했다. JavaScript 문법 검사 및 실제 Chromium에서 후보 카드 수, 선택된 자료 쌍, 원본 확대, 후보 전환, 전체 보기·재확대, 다른 목표 도엽 선택, 잘못된 URL의 기본값 복귀, 대응점 0개 유지가 통과했다. 생성 HTML만 갱신하여 실행 중인 웹서버 재시작은 필요하지 않았다.

이번 성과는 재현 가능한 비교 구간과 검토 동선이다. 1908–1912 지리 정합이나 동일 지점 검증 성공으로 세지 않는다.
