# 164 — v0.5.10 회동서관·책방 이야기꾼 배포

사용자의 배포 요청에 따라 m710q에서 빌드한 웹 v0.5.10을 Docker Hub에 push하고 dolfinid-2의 `/srv/hanyang3d`에 배포했다. 멀티플레이는 v0.5.9를 유지한다.

- 웹 이미지: `honestjung/hanyang3d:v0.5.10`
- digest: `sha256:0320151c37f6cd3c57b82c8153b4b374f321a0e03bdc8ce7a985a144e9a56ca2`
- 주소: https://hanyang3d.nopeoplestime.info/1907/
- 변경: 회동서관 1개(1907년 총 66개), 가상 책방 주인과 16편의 한·영 대사, 건물 안내에서 대화 진입. NPC 대사는 파일 기반이며 기존 이야기 DB 49편은 유지.

## 배포 절차와 보존

`bash deploy/build.sh v0.5.10 --web-only`로 데이터 34파일 해시 검사·묶음, 이미지 빌드, 컨테이너 테스트 63개, 실제 HTTP·비루트·누락/버전 불일치 차단, DB 초기화·재시작 편집 보존·비덮어쓰기 import·검증 백업 검사를 통과했다. 이미지의 APP_VERSION은 명시 빌드 인자로 v0.5.10을 전달했다.

Docker Hub push와 운영 pull의 digest 일치, 전송 묶음 체크섬 검증 후 새 데이터 디렉터리에 설치했다. 운영 deploy.sh 및 Compose 두 파일은 로컬과 SHA-256이 같아 교체하지 않았다. 설정 파일은 `backups/config/pre-v0.5.10/`에 접근 제한 백업했다.

운영 배포는 `bash deploy.sh v0.5.10 v0.5.9` 실행. 웹 중지 후 검증한 DB 스냅샷은 `/srv/hanyang3d/backups/content/pre-deploy/content_v0.5.10_20260918_043304.sqlite3`. 새 migration 없음. 동기화 추가 1(회동서관), 갱신 1(영문 안내), 충돌 0. 기존 안내 문단 차이 7개 보존. `.env.django`는 바이트 비교로 동일하며 `.env`의 릴리스 외 설정도 비교하여 보존 확인했다.

## 운영 검증

웹 v0.5.10과 멀티플레이 v0.5.9 컨테이너 healthy. HTTPS healthz 정상. 공개 브라우저에서 PC와 390px 모바일의 버전 표시, 회동서관 선택, 대화 진입, 세 주제의 이야기와 출처 링크, 돌아가기와 닫기를 확인했다. 인물 위치 충돌 없음, 간판 모형과 인물 표시 정상, JS 오류 없음.

Git commit/push는 이번 요청에 포함하지 않았다. 작업 파일로 빌드되어 revision은 dirty 표기다. 웹 롤백 시 직전 v0.5.9와 데이터 묶음이 남아 있지만, 새 회동서관 모형 종류를 이해하지 못하므로 새 건물을 유지한 채 단순 코드 롤백하면 안 된다. 먼저 새 건물을 비공개 처리하거나 해당 renderer 호환성을 확보해야 한다. DB를 과거 스냅샷으로 임의 복원하지 않는다.
