{% tblock %}지면 고도 — FABDEM V1.2{% endtblock %}

{% tblock %}Copernicus DEM에서 건물·수목 높이 영향을 줄인 약 30m 간격의 지면 고도 추정 자료입니다. Hanyang 3D에서 서울 구간을 추출하고 좌표 변환·격자 재표본화를 했으며, 화면에서는 물길 주변의 개념 지형 보정을 적용했습니다.{% endtblock %}

{% tblock %}원본 FABDEM과 이를 가공한 본 서비스의 고도 격자·지형 자료는{% endtblock %}{% tblock %}Creative Commons 저작자표시–비영리–동일조건변경허락 4.0 국제(CC BY-NC-SA 4.0){% endtblock %}{% tblock %}에 따라 제공합니다. 출처와 변경 사실을 표시해야 하며, 영리 목적 이용은 이 라이선스에 포함되지 않습니다. 변경 자료를 공유할 때에는 동일한 조건을 적용합니다.{% endtblock %}

{% tblock %}경덕궁·창덕궁·창경궁은 한국민족문화대백과사전의{% endtblock %}{% tblock %}숭정전{% endtblock %}, {% tblock %}인정전{% endtblock %}, {% tblock %}명정전{% endtblock %}{% tblock %}설명에서 지붕 층수와 전각 형태를 참고했습니다. 기단·기둥·지붕·앞뜰을 직접 만든 개념 모형이며, 특정 연도의 궁궐 전체를 복원한 것은 아닙니다. 창덕궁{% endtblock %}{% tblock %}돈화문{% endtblock %}{% tblock %}과 창경궁{% endtblock %}{% tblock %}홍화문{% endtblock %}{% tblock %}은 같은 사전의 설명에서 중층 문루와 삼문 구성을 참고한 개념 모형입니다.{% endtblock %}

{% tblock %}광화문 앞 관청들은{% endtblock %}{% tblock %}서울 S-MAP 오픈랩 「조선시대의 육조거리 시간여행」{% endtblock %}{% tblock %}에 수록된 1863년경 배치도와 복원 이미지를 참고했습니다. 담장·문·마당·전각을 직접 단순화하여 제작했으며, 18세기의 정확한 건물 배치를 복원한 것은 아닙니다.{% endtblock %}

{% tblock %}송시열 집터는 담장과 기와집을 단순화한 개념 모형이고, 정도전 집터는 1750년에 집이 없었으므로 작은 표석 모형으로만 표시합니다. 실제 가옥 배치나 범위를 복원한 것이 아닙니다. 도성대지도에 그려진 대상이 아닙니다. 정도전 집터는 이용자가 알려 준 what3words 주소 ///축구공.정성껏.연말을 위경도로 변환한 지점이고, 송시열 집의 화면 위치는 성균관 북동쪽 성곽 안으로 잡은 표시 지점이며, 실제 터는{% endtblock %}{% tblock %}국가유산포털의 우암 송시열 집터{% endtblock %}{% tblock %}지정 소재지(명륜1가)를 기준으로{% endtblock %}OpenStreetMap{% tblock %}의 동 지명 좌표를 빌린 개략 지점으로, 수백 m 오차가 있을 수 있습니다. 두 지점의 판단 근거는 배치 자료에 함께 기록했습니다.{% endtblock %}

{% tblock %}운종가 시전 행랑은 원도에서 판독한 길 선형과 폭을 따라 양쪽에 늘어놓은 표시용 모형입니다. 행랑 한 채씩의 위치는 원도에 그려져 있지 않으며, 칸 크기와 깊이는 시각화 가정입니다. 구간은{% endtblock %}{% tblock %}우리역사넷의 시전 행랑 설명{% endtblock %}{% tblock %}을 참고했습니다. 간판의 시전 이름과 순서는{% endtblock %}{% tblock %}우리역사넷 육의전{% endtblock %}{% tblock %}의 위치 설명을 따랐으며, 간판을 단 가게와 모양은 표시용입니다. 훈련원은 청사 남쪽에 활쏘기와 무과 시험을 보던 마당을 두었다는{% endtblock %}{% tblock %}서울시 소개{% endtblock %}{% tblock %}를 참고해 연병장을 함께 표시했습니다.{% endtblock %}

{% tblock %}종루는 1440년 정면 5칸·측면 4칸 누각으로 지었다가 임진왜란 뒤 1619년 1층 종각으로 중건했다는{% endtblock %}{% tblock %}보신각 터{% endtblock %}{% tblock %}설명과,{% endtblock %}{% tblock %}국가유산포털의 옛 보신각 동종{% endtblock %}{% tblock %}(1468년, 높이 3.18 m·입지름 2.28 m)을 참고해 1층 종각으로 단순화한 개념 모형입니다. 건물별 소개와 존재 시기는 지도에서 건물을 누르거나{% endtblock %}{% tblock %}건물 안내{% endtblock %}{% tblock %}에서 볼 수 있습니다.{% endtblock %}

{% tblock %}종묘 정전은{% endtblock %}{% tblock %}국가유산청 궁능유적본부의 종묘 연혁{% endtblock %}{% tblock %}에 따라 1726년 증축 이후의 15칸 규모를 참고했습니다. 건물·담장·사람·수목 모형은 한양3D에서 직접 만든 단순화된 표현이며, 실측 복원 모형은 아닙니다.{% endtblock %}
